## 数据存储

- **数据库**：PostgreSQL 14+ + TimescaleDB 2.10+
- **关系表**：47 张（PostgreSQL 标准表）
- **时序超表**：21 张（TimescaleDB hypertable）
- **索引策略**：按查询热点建立 B-tree / 复合 / 部分索引

## 各表详细说明

### 1. 系统模块（15 张关系表）

#### sys_users — 系统用户表
| 列 | 类型 | 说明 |
|:---|:---|:---|
| id | VARCHAR(36) PK | 用户ID（UUID） |
| username | VARCHAR(50) UNIQUE NOT NULL | 用户名 |
| password | VARCHAR(100) NOT NULL | 密码（BASE64加密） |
| email | VARCHAR(100) | 邮箱 |
| phone | VARCHAR(20) | 手机号 |
| real_name | VARCHAR(50) | 真实姓名 |
| role | VARCHAR(20) DEFAULT 'user' | 角色：admin/user/guest |
| is_active | BOOLEAN DEFAULT TRUE | 是否激活 |
| last_login | TIMESTAMPTZ | 最后登录时间 |
| created_at | TIMESTAMPTZ | 创建时间 |
| updated_at | TIMESTAMPTZ | 更新时间 |

#### sys_roles — 系统角色表 ★
| 列 | 类型 | 说明 |
|:---|:---|:---|
| id | VARCHAR(36) PK | 角色ID（UUID） |
| role_code | VARCHAR(50) UNIQUE NOT NULL | 角色编码 |
| role_name | VARCHAR(100) NOT NULL | 角色名称 |
| description | TEXT | 描述 |
| is_default | BOOLEAN DEFAULT FALSE | 是否默认角色 |
| permissions | JSONB DEFAULT '[]' | 权限列表（JSON） |
| created_at / updated_at | TIMESTAMPTZ | 时间戳 |

#### sys_user_roles — 用户角色关联表 ★
| 列 | 类型 | 说明 |
|:---|:---|:---|
| id | VARCHAR(36) PK | 关联ID |

## 与原设计文档的关键变更

| 变更 | 说明 |
|:---|:---|
| ★ sys_roles / sys_user_roles | 原文档遗漏，SQL 中存在完整的 RBAC 三表 |
| ★ system_logs | 独立于 sys_operation_logs 的系统日志表 |
| ★ position_snapshots | 持仓快照表，与 positions 不同 |
| ★ blacklists | 独立黑名单表，与 risk_rules 分开 |
| ★ financial_statements | 完整财务报表表（50+字段） |
| ★ index_basic / index_daily | 指数基本信息和日行情 |
| ★ factor_research | 独立的因子研究任务表 |
| ★ data_quality_issues | SQL 表名为 data_quality_issues，COMMENT 为 data_quality_metrics |
| 命名差异 | 设计文档 sys_configs → SQL system_configs；设计文档 sys_scheduled_tasks → SQL scheduled_tasks（同时又有 sys_scheduled_tasks） |
| 账户表 | 设计文档写"positions"作为账户持仓表，SQL 中账户模块使用 accounts 主表 |
| 分析模块 | SQL 中 financial_statements 和 index_basic 归入分析模块数据源 |
