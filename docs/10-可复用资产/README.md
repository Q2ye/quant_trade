## 三、使用方式（新策略立项时）

1. **先查失败清单**：要做的方向若已在清单里 → 直接放弃，不用重验；
2. **再查检查项**：凯利校验、执行链路检查等，作为设计的前置约束；
3. **最后挑机制**：按"结论 / 依据 / How to apply / 边界"四段读完再决定是否迁移；
4. **迁移后回写**：在对应资产的"迁移记录"里登记哪个策略用了它、效果如何。
