## 〇、一句话结论

**"右侧追强"在 A 股不是 alpha 来源，是负 alpha。** 5 年 −50.4% 的亏损不是参数没调好，是选股层（动量）本身就反了：候选池内 IC = −0.17、6 年全负，追最高的 Q5 未来 20 日收益 −2.32%，反转后（Q1）也只是零（+0.47%）。**策略主体丢弃，但其中 4 项机制/知识可迁移到其他策略。**

## 一、策略为何失败（证据链，一句话版）

```
选股层：动量 IC −0.17（6年全负）→ 追强是负 alpha，反转是零 alpha
  ↓
出场层：日频 ATR 与月频入场尺度错配 → 砍赢家（>30天持仓仅14/92笔）
  ↓
仓位层：凯利 f* = −0.05，却用 2×50% 满仓 → MDD 75.9%
  ↓
执行层：追涨确认 + 2日滞后 + 人工延迟 → 买入价系统性抬高 2pp
  ↓
结果：−50.4%，跑输基准 000300（−9.03%）
```

**唯一正收益来源是时序层（熊市空仓 +20.7pp），它不足以让 −50% 转正。**

## 二、可复用资产（4 项 + 1 份失败清单）

### 资产 1：熊市空仓（时序择时）—— 已实证的正收益机制

| 项 | 内容 |
|:--|:--|
| **结论** | 熊市（年线下）空仓，规避系统性下跌，实测 **+20.7pp**、Sharpe 转正 |
| **数据依据** | 归因：熊市 46 笔亏 −177k（占总亏损 89%），胜率与牛市相同（30.4%）但期望 −2.4% vs +0.2% |
| **复用方式** | 作为**通用 regime 门**，迁移到任何股票多头策略（ETF 底部、低吸轮动等）：熊市空仓，牛市满仓 |
| **How to apply** | ① regime 指标须与标的匹配（小盘策略用中证1000，勿用中证500/300）；② 熊市行为直接空仓，不要"降仓 25%"这种半吊子 |
| **边界** | 永久牛市下失效（但 A 股牛短熊长，该失效条件短期不成立） |

### 资产 2：负 IC 反向知识 —— 「追高陷阱」预警指标

| 项 | 内容 |
|:--|:--|
| **结论** | 在「创新高+放量+趋势」的候选池内，动量与未来 20 日收益 IC = **−0.17，6 年全负** |
| **数据依据** | 248 个截面，Q1→Q5 收益单调下降（+0.47% → −2.32%），Q1−Q5 = +2.79%，5/6 年一致 |
| **复用方式** | 做成通用的「追高/拥挤度」预警：任何标的落入该池子的高动量分位，就是负期望信号，**不应追入** |
| **How to apply** | 对任何"追涨/突破/强势股"方向的策略立项前，先跑一次候选池分位 IC；若 IC<0，方向直接否决 |
| **边界** | 反转（选最低动量）也只是零 alpha，不能反向做多；该知识用于**规避**，不用于**选股** |

### 资产 3：执行链路隐性成本检查框架

| 项 | 内容 |
|:--|:--|
| **结论** | 信号→成交的滞后链条（选股→确认→成交 = 2 交易日 + 人工 0~2 天）叠加「追涨确认」，把买入价系统性抬高 **2pp**，直接吃掉收益 |
| **数据依据** | 成交溢价中位 +1.97%（追涨确认）→ +0.74%（站稳 N=2） |
| **复用方式** | 任何策略上线前，做两道检查：① 确认机制方向（追涨 vs 回落）；② 执行滞后量化（成交价 vs 信号价溢价中位数） |
| **How to apply** | ① 确认机制必须问"是涨了才买，还是站稳才买"；② 半自动/人工执行必须设**最长有效期**（如 2 交易日），否则滞后变成结构性成本 |
| **边界** | T+1 市场滞后不可消除，只能通过"回落确认"和"信号有效期"降低其伤害 |

### 资产 4：凯利仓位校验 + 归因方法论

| 项 | 内容 |
|:--|:--|
| **结论** | `f* = (p·b − q)/b`；f*<0 时任何仓位都不该下。本策略 30.4%×1.96 → f*=−0.05，却用满仓 → MDD 75.9% |
| **复用方式** | 凯利校验进**准入门**（G0 之前）：胜率×盈亏比不支撑仓位，直接否决；归因框架（分年/分regime/分持有/分入场特征）复用为通用复盘模板 |
| **How to apply** | ① 上线前算 f*，负值不立项；② 复盘必做四维归因，且"追根到经济学基础"（赚什么钱、为什么存在、何时失效） |
| **边界** | 凯利用精确 p、b，实际用滚动估计 + 半凯利（f*/2）留余量 |
