# 基于LightGBM的ETF抄底策略逻辑文档

## 1. 策略核心思想
本策略并非预测绝对底部，而是利用LightGBM梯度提升树模型，从历史数据中学习“高胜率底部区域”的统计特征。通过将抄底转化为一个**有监督分类问题**，输出当前市场状态属于“有效底部”的概率，辅助进行有安全边际的左侧交易。

---

## 2. 问题定义：机器学习建模
将“抄底”抽象为模型可学习的任务，首选**二元分类**。

- **输入**：t日及之前的市场特征（技术面、资金面、估值面等）。
- **输出**：t日收盘后，预测未来持有期内的“抄底成功概率” \( P(\text{success}) \)。
- **成功定义（标签=1）**：在`t+1`至`t+N`的持有期内，出现**涨幅≥X%** 且 **最大回撤≤Y%** 的反弹；否则标记为0（失败）。
- **标签构造示例**：N=10个交易日，X=3%，Y=5%。若未来10天内最高价较t日收盘价涨幅超过3%，且期间任何一天收盘价从未低于t日收盘价的5%，则`target=1`。

备选方案：也可使用回归预测未来N日收益率，或排序学习预测反弹强度分位。分类方法更直接匹配决策逻辑。

---

## 3. 数据与特征工程
特征质量决定策略上限。需围绕“超跌、恐慌、估值洼地、聪明钱动向”构造因子。

### 3.1 原始数据（日频）
- **行情数据**：开、高、低、收、成交量、成交额
- **ETF特有数据**：IOPV、折溢价率、份额变化（申购赎回）
- **资金与情绪**：大单净流入、融资余额、波动率指数（VIX）、期权PCR、涨跌家数
- **估值数据**：标的指数PE/PB及其历史分位数、股息率风险溢价
- **宏观参考**：利率、汇率、商品（可选）

### 3.2 特征构造清单（示例）
| 类别 | 特征示例 | 逻辑 |
|------|----------|------|
| 超跌类 | 相对N日最高价回撤、RSI<30持续天数、跌幅标准差 | 捕捉极端下跌后的均值回归 |
| 波动类 | 历史波动率、ATR、布林带宽度、高低价差比 | 高波动常对应底部恐慌 |
| 量价关系 | 缩量下跌天数、放量滞涨后缩量、OBV背离 | 底部多缩量，供应衰竭 |
| 市场宽度 | 上涨家数占比、新高新低比 | 市场内部结构是否极度悲观 |
| 估值分位 | PE近5年分位数（越低越安全） | 提供基本面安全边际 |
| 资金情绪 | ETF份额变化率、折溢价率 | 专业资金是否在下跌中买入 |
| 交叉特征 | 跌幅 × 成交量变化、RSI与价格偏离 | 描述非线性底部模式 |

建议初始构建50-200个因子，后续通过LightGBM的特征重要性筛选。

---

## 4. 标签构造与防泄露
严格遵循时序隔离，**只使用历史信息标记未来**。

- **步骤**：
    1. 对每个交易日`t`，计算`t+1`至`t+N`窗口内的最大收益和最大回撤。
    2. 判断是否达到成功条件，生成`target`。
    3. 剔除因除权除息、分红等导致的价格跳变样本。
- **重要约束**：所有t日特征值仅来自t日及之前的数据，严禁使用`t`日以后的信息计算指标（如未来函数）。

---

## 5. LightGBM模型设计与训练
### 5.1 数据划分
- 必须使用**时间序列切分**（如`TimeSeriesSplit`），不可随机打乱。
- 示例：2018-2022年数据训练，2023年验证，2024年测试。

### 5.2 样本不平衡处理
底部成功样本远少于失败样本（如1:5），采用以下方法之一：
- 设置`scale_pos_weight = (负样本数/正样本数)`
- 使用`is_unbalance=True`
- 评估指标使用AUC而非准确率。

### 5.3 核心参数配置
```python
model = lgb.LGBMClassifier(
    objective='binary',
    metric='auc',
    boosting_type='gbdt',      # 或 'dart' 防止过拟合
    num_leaves=63,
    max_depth=7,
    learning_rate=0.02,
    n_estimators=2000,
    subsample=0.8,
    colsample_bytree=0.7,
    reg_alpha=0.1,
    reg_lambda=0.5,
    scale_pos_weight=5,        # 根据实际比例调整
    random_state=42
)
5.4 训练与早停
python
model.fit(
    X_train, y_train,
    eval_set=[(X_valid, y_valid)],
    eval_metric='auc',
    callbacks=[lgb.early_stopping(50), lgb.log_evaluation(100)]
)
5.5 特征分析
使用plot_importance输出增益排名，剔除无贡献或高共线性因子。

通过SHAP值解释单个信号：哪些因素推动了高/低概率。

6. 信号生成与交易决策
模型输出的概率p需经过过滤和映射才形成可执行信号。

6.1 概率阈值过滤
在验证集上优化阈值T（例如T=0.7），只在p >= T时触发买入信号。

阈值选择需平衡胜率与信号频率。

6.2 市场状态过滤（可选）
仅在大盘指数位于长期均线下方（如熊市或大幅回调）时启用抄底信号，避免牛市追高。

排除异常波动日（如事件驱动暴跌无底部特征）。

6.3 仓位映射
根据概率强度动态分配仓位，不鼓励全仓单个信号：

text
仓位比例 = max(0, (p - T) / (1 - T)) × 最大允许仓位
例如最大允许仓位20%，若p=0.9, T=0.7，则实际仓位= (0.2/0.3) × 20% ≈ 13.3%。

6.4 止损与退出
硬止损：买入后亏损超过5%，无条件离场。

时间止损：持有N个交易日未触发止盈（如达到X%收益），则主动平仓。

止盈：达到预设涨幅目标后分批或一次性止盈。

7. 回测与策略评估
7.1 回测设置
考虑双边手续费（ETF万0.5至万1）、滑点（0.01%-0.05%）、冲击成本。

使用逐日或逐笔模拟，避免使用最高/最低价可直接成交的假想收益。

7.2 评估指标体系
指标	说明
胜率	盈利交易次数占比
盈亏比	平均盈利 / 平均亏损
夏普比率	风险调整后收益
最大回撤	策略净值最大跌幅
收益风险比	年化收益 / 最大回撤
信号频率	每年平均触发次数（需可接受）
7.3 稳健性检验
分年度回测，观察各年度表现一致性。

参数敏感性测试（变动阈值、持有期、止损比例）。

排除过拟合：若训练集AUC远高于测试集，需简化模型或增加正则。

8. 风险控制与资金管理
单次最大亏损：单笔交易亏损不超过总资金的1%-2%。

连续回撤控制：当周/月连续亏损达到限额，暂停交易，重新审查模型。

模型失效监控：定期计算特征稳定性PSI（群体稳定度指标），若主要特征分布发生偏移，需触发重新训练。

分散化：可同时对多只相关性较低的ETF运行策略，降低单一标的尾部风险。

9. 总结与注意事项
LightGBM解决的是概率问题，而非确定性预测。它通过挖掘数据中可重复的底部模式，提供统计优势。

策略强烈依赖特征构造，纯粹价格衍生因子容易过拟合；应优先加入估值、资金流等驱动因素。

市场风格切换（如流动性危机、政策突变）会导致历史规律短暂失效，必须严格执行止损。

本文档提供的是策略逻辑框架，不构成任何投资建议。实际应用前需用自己数据充分验证。
