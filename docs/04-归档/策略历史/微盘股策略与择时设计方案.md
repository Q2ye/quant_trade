## 一、策略定位

| 项目 | 内容 |
|:--|:--|
| 类型 | 小市值微盘股 + 大盘择时 |
| 市场 | A 股全市场（微盘池） |
| 数据要求 | 日线 + 流通市值（circ_mv） |
| 与主策略关系 | 独立进攻策略，专注微盘阿尔法 |
| 资金分配 | 单独资金账户，择时决定满仓/空仓 |
| 核心逻辑 | 微盘股低定价效率 + 壳价值提供阿尔法；择时规避微盘系统性崩塌（2024-01 微盘危机） |

**核心假设**：
1. 微盘股定价效率低 → 存在真实超额（机构覆盖少）
2. 壳价值提供底部支撑（借壳预期）
3. **微盘股有独立于大盘的崩塌风险**（2024-01）→ 必须用微盘自身指数择时

## 三、策略设计

### 3.1 微盘股池定义（定期重选）

```
【选池规则】每月初重选（市值每月变化）
  微盘池 = 全市场流通市值 circ_mv < 50 亿
          AND 非 ST / 非退市
          AND 近20日日均成交额 > 3000 万（流动性下限）
          AND 最近一期营收 > 1 亿（排除烂壳）
          AND 市净率 > 0（不资不抵债）
→ 按流通市值升序，取市值最小 N 只（如 50 只）

【加分项】
  + 壳价值（未重组过 / 无退市风险）
  + 近1年无重大违规
```

**改进点**：纯按市值最小选会选中"快退市烂股"，必须配合**退市风险过滤 + 流动性下限**——这是微盘策略的生存底线。

### 3.2 择时机制（双指数确认——设计核心）

**微盘股有独立于大盘的崩塌风险（2024-01 大盘没崩，微盘崩了）**，单用大盘 regime 择时测不出微盘危机。采用**双指数择时**：

```
【门控 1：大盘 regime】复用 market_state_daily
  BULL → 允许买入
  BEAR → 空仓（防系统性熊市，与主策略哲学一致）

【门控 2：微盘自身指数】用中证2000 ETF（563300）近20日均线
  中证2000 收盘 > 20日均线 → 微盘趋势健康，允许买入
  中证2000 收盘 < 20日均线 → 微盘趋势破坏，空仓避让（防 2024-01 式微盘独立崩塌）

→ 双门同时通过才买入；任一门关闭 → 空仓
```

**关键设计**：门控 2（微盘指数）是**本策略特有**的——它专门防"大盘没跌、微盘崩了"的独立危机（2024-01 正是这种）。这是微盘策略择时的核心差异点。

### 3.3 买入逻辑

```
【触发】双门通过（大盘 BULL + 中证2000 > 20日均线）
【选股】从微盘池按动量/质量评分选 Top 10-20
  评分 = 20日动量（正）+ 换手率适中（有资金关注但未过热）
        - 涨停次数（防连续涨停追高）
        - 退市风险分（强制过滤）
【买入】等权配置 Top 10-20 只（分散，防单票流动性风险）
  单票 ≤ 总资金 5%
  总仓位 ≤ 80%（留 20% 现金，防流动性枯竭）
```

### 3.4 卖出 / 风控

```
【止损】单票亏损 10% → 止损（微盘波动大，需严格）
【择时退出】任一门关闭（大盘 BEAR 或 中证2000 < 20日均线）→ 整体空仓
【流动性枯竭】连续跌停无法卖出 → 接受风险（微盘固有），靠分散 + 现金缓冲
【动态调整】单票浮盈 > 30% → 减半（防微盘高位回落）
```

### 3.5 与"恐慌抄底"的联动（重要协同）

微盘危机 → 恐慌指数飙升 → **恐慌抄底策略**触发：
```
微盘择时（门控2）关闭 → 微盘策略空仓避让
恐慌抄底（事件策略一）在恐慌消退后抄底微盘股
→ 两个策略在微盘危机中形成"先避让 + 后抄底"的时间互补
```

## 四、关键参数

```python
DEFAULT_PARAMS = {
    # 微盘池
    "max_circ_mv": 50e8,          # 流通市值上限 50 亿
    "pool_size": 50,              # 微盘池大小（市值最小 50 只）
    "min_volume": 3000e4,         # 日均成交额下限 3000 万
    "min_revenue": 1e8,           # 最近一期营收下限 1 亿
    "rebuild_pool_freq": 20,      # 每 20 交易日重选池
    # 择时
    "use_market_gate": True,      # 门控1：大盘 regime
    "use_micro_gate": True,       # 门控2：中证2000 20日均线
    "micro_index": "563300.SH",   # 微盘代理指数（中证2000 ETF）
    "micro_ma_window": 20,        # 微盘择时均线
    # 买入
    "holdings": 15,               # 持仓数量（分散）
    "max_single_weight": 0.05,    # 单票上限 5%
    "max_total_weight": 0.80,     # 总仓位上限 80%
    "momentum_window": 20,        # 选股动量窗口
    # 风控
    "stop_loss": -0.10,           # 单票止损 10%
    "profit_reduce": 0.30,        # 浮盈 30% 减半
}
```

## 五、回测验证方案

用现有数据（2019-2026）跑：

```
对照组：
  ① 微盘策略 无择时（满仓微盘）→ 验证微盘阿尔法是否存在
  ② 微盘策略 + 大盘门（仅门控1）
  ③ 微盘策略 + 双门（门控1 + 门控2）← 完整设计
  ④ 微盘策略 + 双门 + 恐慌抄底联动

验证重点：
  1. 微盘阿尔法是否存在（① 是否跑赢沪深300）
  2. 择时是否降低回撤（②③ vs ① 的 MDD 对比）
  3. **门控2（微盘指数）是否防住 2024-01 微盘危机**（关键）
  4. 与恐慌抄底联动的组合收益
```

**关键验证点**：2024-01 微盘流动性危机——检验门控 2（中证2000 < 20日均线）能否在危机前触发空仓。

## 六、风险与局限

| 风险 | 说明 | 缓解 |
|:--|:--|:--|
| 流动性枯竭 | 微盘危机连跌停无法卖出 | 分散 + 20% 现金 + 择时提前避让 |
| 择时滞后 | 20日均线确认慢，可能跌了 10% 才关 | 加"3日跌幅 > 5%"快速关闭 |
| 壳价值消失 | 退市新规趋严，壳价值下降 | 严格退市风险过滤 |
| 中证2000 代理偏差 | ETF 有溢价，非微盘精确 | 用指数而非 ETF 净值，或自建市值分位指数 |
| 样本回测偏差 | 微盘 2024 前 vs 后生态不同 | 分段验证（2024 前壳价值期 / 2024 后退市新规期） |
