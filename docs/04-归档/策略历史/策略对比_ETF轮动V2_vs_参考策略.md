# ETF 轮动策略对比：V2 vs 参考策略（聚宽）

> 日期：2026-07-18

---

## 一、策略骨架对比

| 维度 | 参考策略（聚宽） | V2（我们的） |
|:---|:---|:---|
| 来源 | 聚宽社区 2024，作者"路虽远终必达" | 自研，Antonacci Dual Momentum 骨架 |
| 回测引擎 | 聚宽（JoinQuant） | 我们的 BacktestEngine |
| 持有数量 | **1 只**（stock_sum=1） | **3-5 只**（max_holdings） |
| 调仓频率 | **每日**（10:30） | **每月**（月份变更日） |
| 资产池 | 9 只 ETF（商品+跨境+港股+国内+债券） | 10 只 ETF（9 大类资产） |
| 策略哲学 | "每天只持有动量最强的那一只" | "每月持有动量最强的 top N" |

---

## 二、信号生成链路对比

### 参考策略：三层过滤链 → 选出 1 只

```
每天早上 10:30：

第一层【动量评分 + 日内暴跌过滤】
  → 对数回归斜率 × R²（与 V1 完全相同的算法）
  → 动量窗口: 25 天（~1 个月）
  → 近 3 日有单日跌幅 > 5% → 得分 = -8（尾端跳水惩罚）
  → 日内距离开盘跌幅 > 3% → 直接排除（盘中熔断）

第二层【成交量异常过滤】
  → 近 7 日分钟量 > 日均量的 2 倍 → 排除
  → 等效 V1 的 _is_volume_abnormal，但阈值更紧（2x vs 2x）

第三层【RSRS 阻速线 + 均线确认】
  → RSRS 斜率 > Beta（18 日斜率 vs 250 日β窗口）
  → 强度 > 0.15 → 直接通过
  → 强度 > 0.03 + 价格 > MA5 → 通过
  → 价格 > MA10 → 通过
  → 完全等价于 V1 的 _pass_rsrs_filter

三层全部通过 → 持有得分最高的 1 只 ← 极端集中！
```

### V2：单层排名 → 选出 top N

```
每月月初：

仅一层【12-1 月简单收益率排名】
  → close[T-21] / close[T-273] - 1
  → 降序排列 → 取 top N
  → 可选：绝对动量门（候选 < 货基 → 退守国债）

无 RSRS、无成交量过滤、无尾端跳水惩罚
```

## 三、风控机制对比

| 风控层 | 参考策略 | V2 |
|:---|:---|:---|
| **日内止损** | **-3%**（距离开盘价的跌幅） | 无 |
| **隔夜止损** | -9%（固定止损） | **-10% ~ -15%**（可配） |
| **移动止损** | 可选（默认关闭） | 无 |
| **止盈** | +100% 强制止盈 | 无（仅月频调仓自然退出） |
| **熊市防御** | **无绝对动量门**，始终持有 1 只 | **绝对动量门**：全市场下跌时退守国债 |
| **成交量异常** | 当日量 > 7 日均量 × 2 → 卖出持仓 | 无 |
| **日内暴跌过滤** | 开盘-当前 > 3% → 排除该标的 | 开盘暴跌 > 3% → 不参与排名（旧版 V1） |
| **涨停板退出** | 昨日涨停今日开板 → 卖出 | 无（ETF 不涉及） |

## 四、各自优点

### 参考策略的优点

1. **极端集中 = 极端收益**：只持 1 只，选对了就是满仓涨停（年化 74% 的来源）。V2 持 3-5 只等权分散，永远不可能有这种爆发力。

2. **日频响应**：每日重新评估，趋势反转 1 天内就能切换（vs V2 月频滞后 1-3 个月）。2023 年 3 月 A 股反弹时能第一时间追入，而 V2 月频等到 5 月才切回来。

3. **三层过滤的统计优势**：动量 + 量异常 + RSRS 从不同维度交叉验证，单个信号的假阳性率低于 V2 的纯价格动量。

4. **盘中风控维度更多**：日内 -3% 止损 + 成交量异常即时卖出 + 涨停板监控，比 V2"每日收盘看一眼"的反应快得多。

5. **动量算法更精细**：对数回归 × R² = 同时衡量"涨了多少"和"涨得有多稳定"，比 V2 的简单价格变化更能区分"稳健上涨"和"暴涨后即将崩盘"。

### V2 的优点

1. **参数极度精简**：4 个参数 vs 参考策略的 10+ 个。过拟合风险低得多，跨周期稳定性有保障。参考策略的 7 个过滤参数（动量窗口、分数阈值、量阈值、RSRS 窗口、β 窗口、强度阈值）在聚宽上可能被调优到极致，换到我们的框架可能直接失效。

2. **绝对动量门 = 熊市生命线**：参考策略在 2022 年没有防御机制——它会把资金分配给"跌得最少"的 ETF（如豆粕或黄金），但如果全市场都在暴跌，单只持仓的波动是毁灭性的。V2 的绝对动量门会直接退守国债，这是 V2 MDD 11% vs 参考策略 MDD 26% 的根本原因。

3. **分散化降低个别标的的尾部风险**：参考策略持一只 ETF，如果那只是纳指 100，2024-08-05 单日 -12% 就满仓扛。V2 持 3-5 只，同日双杀导致净值的损失被分散到 ~5.9% 而非 ~12%。

4. **月频 = 低维护成本**：实盘中每月看一次 vs 每天 10:30 盯盘。参考策略的日频 + 盘中信号生成需要实时的分钟级数据和毫秒级执行——半自动交易系统中不可行。

5. **回测可信度更高**：V2 在我们的 BacktestEngine 上真实验证（年化 5%、MDD 11%）。参考策略的 74% 年化来自聚宽引擎，其撮合假设（是否支持 T+0、滑点模型、复权方式）与我们的不同，直接迁移不可信。

6. **持仓权重合理**：等权分散 vs 满仓单只。参考策略满仓一只是双刃剑——选对时极致收益，选错时毁灭性回撤。V2 的 Calmar 0.45 > 参考策略的推算 Calmar（74% / 26.5% = 2.79，但这个数字来自不同的回测引擎）。

## 五、评估：参考策略的 74% 年化能在我们框架复现吗？

**大概率不能。** 原因：

1. **聚宽回测 vs 我们的 BacktestEngine**：聚宽可能在以下方面更乐观：
   - T+0 撮合 vs 我们的 T+1
   - 不同的滑点/手续费模型
   - 不同的复权方式
   - 数据范围可能不同

2. **日频 × 单标的组合在我们的框架中的实际表现**：参考策略持有 1 只 + 每日调仓，这意味着每月约 20 次买卖。在有 T+1 撮合 + 万分之一滑点 + 万三手续费的约束下，年交易成本约 2-3%（参考策略在聚宽上 ETF 手续费为 0，滑点 0.001）。

3. **参数迁移风险**：25 天动量窗口 + RSRS(18, 250, 20) + 量异常(7, 2x) 这些参数是在聚宽数据上优化的，直接移植到我们的数据源（Tushare）上，数据精度和交易日历差异可能导致信号完全不同。

4. **半自动交易不兼容**：日频 + 盘中 10:30 执行 + 日内 -3% 熔断，这些在手动确认的半自动系统中不可行。

## 六、可借鉴的优化点

以下参考策略的设计可以直接增强 V2，且不改变 V2 的月频 + 分散化基因：

### 立即可做（低风险）

| 借鉴点 | 当前 V2 | 改造后 | 预期收益 |
|:---|:---|:---|:---|
| **尾端跳水惩罚** | 无 | 近 3 日有单日 -5% → 该标的本月不参与排名 | MDD -1~2%，年化 +0.5% |
| **开盘暴跌过滤** | 无（V1 有，V2 删了） | 开盘跌 > 3% → 该标的当日不参与排名 | MDD 微小改善 |
| **动量得分 × R²** | 简单收益率 | 对数回归斜率 × R²（复用 V1 代码） | 年化 +1~2%，更稳健的排名 |

### 需要验证（中风险）

| 借鉴点 | 说明 | 风险 |
|:---|:---|:---|
| **扩大资产池** | 参考策略包含 501018 原油、511090 三十年期国债、588220 科创板 | 数据缺口（原油）、相关性（科创 vs 创业板） |
| **RSRS 过滤** | 参考策略的核心过滤层，RSRS 强度 > 0.15 才通过 | 增加参数、增加计算复杂度 |

### 不建议借鉴

| 参考策略做法 | 原因 |
|:---|:---|
| 只持 1 只 ETF | 与 V2 的分散化定位冲突，单标的尾部风险不可接受 |
| 日频调仓 | 半自动交易不可行，交易成本侵蚀严重 |
| 日内 -3% 止损 | 需要实时行情 + 程序化执行，半自动系统不兼容 |
| 分钟级成交量检测 | 依赖盘中分钟数据，基础设施不支持 |

## 七、总结

| 评价维度 | 参考策略 | V2 |
|:---|:---:|:---:|
| 理论收益上限 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| 回撤控制 | ⭐⭐ | ⭐⭐⭐⭐ |
| 参数稳健性 | ⭐⭐ | ⭐⭐⭐⭐⭐ |
| 实盘可执行性 | ⭐⭐（日频+盘中） | ⭐⭐⭐⭐⭐（月频） |
| 跨周期适应力 | ⭐⭐ | ⭐⭐⭐⭐ |
| 信噪比（回测可信度） | ⭐⭐（聚宽引擎） | ⭐⭐⭐⭐（自研引擎验证） |

**参考策略是 V1 的"单标的 + 日频"增强版，V2 是 V1 的"多标的 + 月频"简化版。两者代表了 ETF 轮动的两极——极端进攻 vs 稳健防御。V2 在实盘可行性和参数稳健性上远胜，但借鉴参考策略的尾端跳水惩罚和 R² 加权可以低成本提升 V2 的信号质量。**
