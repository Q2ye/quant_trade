## 2. R1 结构层 — 研究记录 IR-01

- **所属段**：R1 结构层
- **假设**：31 个申万 L1 行业中，存在至少一种可提取的结构性收益（A 时序择时 / B 横截面动量 / C 时序反转 / D 横截面反转）。
- **🔒 判据冻结时间：2026-10-20 19:11** —— 以下定义与判据在跑数之前写定，跑后不改。

### 2.1 数据与口径（冻结）

| 项 | 取值 |
|:---|:---|
| 池 | `index_sw_daily` 的 31 个申万 L1 行业指数（`*.SI`） |
| 价格 | `open` / `close`（原始指数点位；申万指数为价格指数） |
| 主段 | 2016-01-01 ~ 2021-12-10；2021-12-13 ~ 2026-10-19 |
| 描述性段 | 2014-02-21 ~ 2015-12-31（不进主判据） |
| 执行 | 信号在 `t` 收盘计算，`t+1` 开盘成交；持有 20 个交易日后在开盘卖出 |
| 成本 | 指数级 **0.05%/边**（往返 0.10%）；按换手计 |
| 基准 | **31 行业等权**，同调仓日、同成本口径 |
| 样本外 | 两段互为样本外（无参数拟合）；另报告段内 60/40 描述性切分 |

### 2.2 四种结构（冻结）

| 结构 | 定义 |
|:---|:---|
| **A 时序择时** | 行业收盘价 > MA60 时持有，否则现金；每日信号、次日开盘执行；按换手计成本 |
| **B 横截面动量** | 按 **120 日**形成期收益（`close_t / close_{t-120} - 1`）排序，取 **Top-5**，等权；每 **20 个交易日**调仓；信号 `t` 收盘、`t+1` 开盘成交 |
| **C 时序反转** | 单行业 5 日收益 ≤ 过去 250 日 **5% 分位**；次日开盘买入，持有 20 日，开盘卖出；对照 = 同行业同段无条件 20 日收益 |
| **D 横截面反转** | 按 **20 日**收益排序，取 **Bottom-5**，等权；每 20 个交易日调仓；执行同 B |

> B 的 60 日 / 250 日形成期、Top-3 / Top-10 只做**描述性稳健性**，不参与“选哪个”。若 120 日不通过，不得改用其他窗口“再试一次”。

### 2.3 判据（冻结，全部满足才算该结构通过）

| # | 判据 | 阈值 |
|:--|:---|:---|
| 1 | 净超额（扣成本） | > **2× 成本**（B/D：>0.20%/20 日；C：>0.10%/事件；A：净 CAGR > 买入持有） |
| 2 | 分年度正超额占比 | ≥ **70%** |
| 3 | 两段同向 | 2016-2021 与 2022-2026 的净超额 **同号** |
| 4 | 5 分层单调 | B：动量层↑→收益↑，Spearman **ρ > +0.7**；D：动量层↑→收益↓，**ρ < −0.7** |
| 5 | 安慰剂 | 随机 5 行业、同调仓/持有规则，**1,000 次抽样**；真实臂 > p95 |
| 6 | β 分解 | 报告对 000300 / 000905 / 000852 的回归；超额不得仅由小盘/高波动解释 |

**A 的专属判据**：净 CAGR > 同行业买入持有，且 CAGR/MDD 改善；否则仅作对照。

### 2.4 主池可行性门槛（次级，不改变 R1 通过/不通过）

### A.3 观察（描述性）

- **1-3M 形成 × 1-3M 持有**：IC ≈ 0 或负（3M/3M 为 **−0.020**），短周期是**反转/噪声** → 解释 IR-01 的 20 日失败。
- **6-12M 形成 × 6-12M 持有**：IC **0.084~0.112**，是动量主战区。
- **24M 形成**：IC 衰减到 0.020~0.037；**36M 形成**：0.005~0.021，基本失效。
- 最强格子：**6M 形成 / 12M 持有 IC 0.112**；**12M 形成 / 6M 持有 IC 0.104、年化超额 +5.1pp**；**6M/6M IC 0.084、+4.3pp**。
- 多空价差更大（12M/12M +5.12%/12M），但 A 股行业无低成本做空工具，**只能看 long-only**。
- 含 2014-2015 泡沫时，1M/1M 的 Top5 年化被抬到 10.6%，但 IC 只有 0.015 → **短周期高收益是样本偏差，不是信号**。

> ⚠️ 24 个格子是同一份数据上的多次观察；**平滑山脊比单格峰值可信**，但仍须在 IR-02 中做样本外（2016-2021 观察 / 2022-2026 验证）与安慰剂，不能直接按最高格子上线。
