# 验证设计：结构 → 行为 → 统计

> **本文件重整 `策略验证开发流程.md` 的 R3/R4。** 原 R3/R4 把三者混在一起做，
> 导致「先假定信号成立、再调参数」的颠倒顺序，且从未验证结构层与行为层。
> 日期：2026-09-19

## 〇 前一轮的错误（必须记录，避免重犯）

| # | 错误 | 后果 |
|:--|:---|:---|
| 1 | **结构层只被"叙述"，未被"验证"** | R2 写了三层分析，之后直接跳到测参数 |
| 2 | **测的信号 ≠ 结构层声明的钱源**。结构层说赚 A（时序β）+ B（横截面α），而我全程测的是 **C（单标的短期反转）** | **错位**：用 C 的结果讨论"策略行不行" |
| 3 | **行为层完全未测** | 筛选结果反常（最均值回归的反而最差）时无法解释 |
| 4 | **统计层脱离因果** | VR / 条件期望 / 止损网格 / 分形 / 筛选都成了"参数搜索"，不是验证 |
| 5 | **顺序颠倒** | 应先证"池里存在可提取的结构性收益"，再问"用什么信号提取"；实际相反 |

**教训**：统计层的每一个测量，都必须能回答"它检验的是结构层/行为层的哪一条假设"。答不出，就不是验证。

## 第一步：结构层 —— 池子里到底有哪几种钱？

在同一 ETF 池、同一时间轴、**同一套评价标准**下，并列测四种候选收益结构。

| 候选 | 定义 | 测什么 | 判据 |
|:---|:---|:---|:---|
| **A 时序择时** | 按市场状态（市场宽度 regime）决定池内是否持有 | 择时组合 vs 一直持有；分年度 | 择时须提升风险调整后收益 |
| **B 横截面动量** | 池内按过去 N 日收益排序，买 Top-K 持有 M 日 | 分层收益单调性 / 排序 IC | 分层单调 + IC 显著 |
| **C 时序反转** | 单标的超卖后反弹（前一轮全程在测的） | 跌幅 → 未来收益（含非线性） | 条件期望超额 > 成本 |
| **D 横截面反转** | 池内按过去 N 日收益排序，买 Bottom-K 持有 M 日 | 反向分层 | 分层单调 + IC 显著 |

**产出**：四种结构各自的 ① 超额大小 ② **分年度稳定性** ③ 样本外一致性（前 60%/后 40%）
**判据（进入第二步的门槛）**：
- 超额 > 成本，**且**
- 分年度方向一致（不能只靠 2007/2015 这类单一年份），**且**
- 样本外同向
- **四种全部不达标 → 方向作废，不进第二步**

> ⚠️ **纪律**：本步**不涉及任何入场/出场信号设计**。只问"池子里有没有钱"，不问"怎么捡"。

## 第二步：行为层 —— 机制是否有可观测含义、且仍存在？

对第一步胜出的结构，验证其**机制假设**。不同结构对应不同的行为机制，测法不同：

| 胜出的结构 | 机制假设 | 可观测含义（测这个） |
|:---|:---|:---|
| **B / D（横截面）** | 资金在板块间迁移有摩擦与滞后 | 用**成交额 / 份额变化**作资金流代理，测链条：涨幅 → 后续资金流 → 后续涨幅。滞后须可测 |
| **C / A（时序）** | 过度反应后的修正 | 测**跌幅与反弹幅度的非线性**：过度反应应表现为"跌得越多反弹越大，**直到某点转为趋势**"（这个转折点就是 A 与 C 的分界） |

**并须回答持续性**：该机制在样本外 / 近年是否**衰减**（拥挤度上升会杀死公开的异象）。

**判据**：机制可观测 + 未显著衰减 → 进入第三步
**不通过**：机制讲不通或已衰减 → **回到第一步换结构**，而不是硬调参数

---

## 第三步：统计层 —— 信号、参数、止盈止损、标的池

**只有走到这一步，才允许做前一轮做的那些**（通道定义、入场规则、出场网格、止损、标的筛选）。

且**每一条参数的选择都必须锚在第一步选定的结构上**：
- 若结构是 B/D（横截面）→ 参数是**排序窗口、持仓数、调仓频率**，标的池筛选标准应是**横截面离散度 / 资金流敏感度**
- 若结构是 C（时序反转）→ 参数才是**通道定义、超卖阈值、持有期**，标的池筛选标准应是**反转弹性**

> ⚠️ 前一轮在**未确定结构**的情况下，用"VR / 往返完成率"筛池——那些是**为 C 设计的判据**，而又没先证明 C 是有效的结构。**筛不出来是必然的。**

## 每一步的产出物

| 步 | 产出物 | 不通过的处置 |
|:---|:---|:---|
| 一 | 结构层对照表（四种结构的超额/稳定性/样本外） | 全部不达标 → **方向作废** |
| 二 | 机制验证报告（可观测链条 + 持续性） | 机制不成立 → **回第一步换结构** |
| 三 | 参数与信号规格 + 标的池定义 | 不达标 → 回第二步复核机制 |
