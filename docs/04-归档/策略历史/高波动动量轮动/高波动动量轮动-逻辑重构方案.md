## 〇、一句话结论

策略的"第一性原理"（右侧追强）在 A 股不成立：**突破后 7 天内 93% 是亏损**（43 笔中胜率 7%）。
重构不是"让突破更准"，而是**先重建经济学基础**（收益来源从"横截面动量"改为"时序风险规避 + 趋势肥尾"），再据此把逻辑改成——**突破当候选、确认当信号、风险预算当仓位、组合回撤当熔断**。
凯利公式给出定量依据：实测 30.4% 胜率 × 1.96 盈亏比下 `f* = −0.05`，本不该下注，策略却用 2×50% 满仓。

## 一、经济学基础闭环（先回答"赚什么钱"，再谈怎么赚）

> 审阅结论之一：原方案跳过了"收益来源"这一层，直接给了处方。没有经济学基础，任何判据都可能是对噪声的拟合。

### 1.1 收益来源重新定位（原隐含假设已被数据证伪）

| | 原方案隐含假设 | 数据结论 | 重构后定位 |
|:--|:--|:--|:--|
| 主收益 | 强者恒强（横截面动量 alpha） | 横截面 IC≈0，逐年翻号 | ❌ 放弃 |
| **主收益** | — | 熊市空仓 +20.7pp（方案 C） | ✅ **时序风险规避** |
| 次收益 | — | >30 天持仓 +18.6%、盈亏比 1.96 | ✅ **趋势肥尾** |
| 待证收益 | — | 突破当天 93% 失败（散户追高） | ⏳ **行为错误纠正** |

**结论：这个策略赚的不是"选股"，是"择时 + 赔率"。** 方案 C 的 +20.7pp 是唯一已实证的收益来源，它的本质是规避系统性下跌，与选股无关。

### 1.2 三条钱的市场无效性来源

| 钱 | 来源（为什么长期存在） | 可监测指标 |
|:--|:--|:--|
| **① 时序风险规避** | A 股牛短熊长，散户满仓扛跌，规避下跌 = 超额 | 熊市区间亏损（BASE −2.42% → 目标 ≈0） |
| **② 趋势肥尾** | 真趋势一旦形成有惯性，右尾不封顶 | 盈亏比（目标 1.96 → 2.5+） |
| **③ 行为错误纠正** | 散户追涨停/追新高 → 假突破多 → 反向"确认后再买" | 突破确认组 vs 追涨组收益差 |

### 1.3 机制与经济学的对应（闭环的关键）

```
经济学        →  机制                     →  判据
① 时序风险规避 →  熊市空仓（维度四）      →  熊市区间亏损≈0
② 趋势肥尾     →  出场绑定入场（维度二）  →  盈亏比 ≥1.96 且向 2.5 收敛
③ 行为错误纠正 →  突破确认/回落站稳（维度一）→  成交溢价中位数下降
④ 生存（凯利） →  风险预算仓位（维度三）  →  MDD 收敛
```

**每个机制都对应一个经济学来源，每个经济学来源都对应一个可监测的失效信号。** 这是闭环。

### 1.4 失效条件（这个钱什么时候消失）

| 失效 | 表现 | 触发动作 |
|:--|:--|:--|
| 系统性下跌消失（永久牛市） | 熊市空仓不再贡献超额 | 维度四判据失败 → 关闭熊市空仓 |
| 趋势消失（长期横盘） | 盈亏比跌向 1.0 | 维度二判据失败 → 回归止损出场 |
| 散户变理性（假突破消失） | 突破确认组与追涨组无差别 | 维度一第 1 步判据失败 → 弃用确认 |

## 二、总原则（四条，贯穿所有维度）

1. **单变量推进**：每个实验臂只改一个变量；维度内部多步也逐步拆臂验证。
2. **出场绑定入场**：出场条件是"入场逻辑的否定"，不是独立的日频止损。
3. **仓位服从期望**：先证信号正期望，再谈仓位；"正期望"有可验证标准（§六）。
4. **判据前置**：每个实验臂的通过判据在跑之前冻结，跑完不改。

## 四、维度一：信号生成 —— 从「追突破」到「确认趋势」

### 4.1 现状逻辑

```
候选 = 创新高(20日) + 放量(5日均量≥20日均量×1.2) + 趋势(价>MA200 且 MA50>MA200)
信号 = 60日动量 + 0.5×20日加速 + 0.5×相对强度  → 排序取 Top2
```

**问题**：信号在"突破当天"成立，≤7 天失败笔胜率 7%；且确认机制是"追涨确认"（§八）。

### 4.2 重构后的实现逻辑（三步，各自独立验证）

**第 1 步：突破 → 突破确认（时序问题，替换「追涨确认」）**

```
现状①：突破日当天即成为候选信号
现状②：确认机制是「追涨确认」—— T 收盘 > 信号价 才通过（涨了才买）
改为：突破日后，需连续 confirm_days 个交易日满足「收盘 ≥ 突破价 × (1 − confirm_buffer)」
      才升级为可交易信号；期间跌破则取消候选
      —— 确认方向从「涨了才买」反转为「站稳（未跌破）才买」
```

| 参数 | 默认 | 含义 |
|:--|--:|:--|
| `confirm_days` | 3 | 突破后需确认的交易日数 |
| `confirm_buffer` | 0.03 | 确认期允许的回撤幅度 |

**逻辑依据（经济学③）**：≤7 天失败 7% 胜率说明"突破当天"是负期望入场点；现有 `_confirm_pending_buys` 的 `T 收盘 > 信号价`（`:716`）是追涨确认，把买入价系统性抬高。改为"站稳才买"，在时间轴上避开假突破的第一次回落。

**⚠️ 这是"替换"不是"叠加"**：若只加回落确认、不删追涨确认，两者方向相反且滞后翻倍。

**第 2 步：绝对动量 → 横截面分位（截面问题）**

```
现状：score = mom60 + 0.5×mom20 + 0.5×rs     （绝对 log 收益）
改为：score = pct(mom60) + 0.5×pct(mom20) + 0.5×pct(rs)   （池内排名分位）
```

**逻辑依据**：绝对动量 IC≈0 且逐年翻号；分位化只保留相对强弱，去掉绝对涨幅（追高）噪声。

**第 3 步：资金流确认（截面问题，**待重新验证**）**

```
条件 = mf_ratio > 0 且 mf_ratio 在当日池内分位 ≥ 0.5
      mf_ratio = net_mf_amount(t) / circ_mv(t)
```

**⚠️ 状态：未证实，需重做。** 全市场 IC +0.0248 是"全市场排序"，与"候选池内分位"统计对象不同；A 臂实测**失败笔数 +18.6%（未过预注册判据）**，说明该迁移未走通。第 3 步须先在**候选池内**单独测资金流分位 IC，通过才纳入。

### 4.3 判据（冻结，**分步骤，不再共用一条**）

| 步骤 | 判据 | 类型 |
|:--|:--|:--|
| 第 1 步（突破确认） | **成交价 vs 信号价溢价中位数下降**；且确认组入场后 20 日收益 ≥ 突破当天入场组 | 时序判据 |
| 第 2 步（横截面分位） | 入场后 20 日收益的横截面 IC > 0，6 年方向一致 | 截面判据 |
| 第 3 步（资金流） | 候选池内资金流分位 IC > 0（先在池内验证，非全市场） | 截面判据 |

> 审阅结论修复：原"横截面 IC"统一判据不适用于第 1 步（时序问题），已拆开。

## 五、维度二：入场/出场 —— 统一尺度，出场绑定入场逻辑

### 5.1 现状逻辑

```
入场：突破 + 动量打分（月频尺度）
出场：2×ATR 移动止损（日频尺度）  ← 尺度错配，任何日频回撤都砍掉趋势
```

### 5.2 重构后的实现逻辑

**出场主逻辑 = 入场逻辑的否定**，分三层：

| 层 | 出场条件 | 否定对象 |
|:--|:--|:--|
| ① 确认否定 | 收盘跌破「突破平台价」（突破确认价 − buffer） | 维度一第 1 步 |
| ② 动量否定 | 分位动量 pct(mom20) 跌破 0.5 或翻负 | 维度一第 2 步 |
| ③ 资金否定 | 资金流连续 3 日净流出（mf_ratio 累计 < 0） | 维度一第 3 步 |

**ATR 只保留为最后的硬止损兜底**：

```
硬止损 = 入场价 × (1 − 2×ATR)，仅作「极端跳空/隔夜风险」的最后防线，不作为常规出场
```

### 5.3 判据（冻结，**补盈亏比、修方向矛盾**）

| # | 判据 | 说明 |
|:--|:--|:--|
| 1 | **盈亏比 ≥ 1.96 且向 2.5 收敛** | 核心假设（经济学②趋势肥尾）显式跟踪 |
| 2 | >30 天持仓占比从 15%（14/92）上升 | 让赢家奔跑 |
| 3 | MDD 不劣于 BASE +1pp | 兜底（防持有过久恶化回撤） |
| 4 | 出场平均滞后天数上升（趋势被否定前不退出） | 尺度统一的效果 |

> 审阅结论修复：删除原"≤7 天失败笔亏损收敛"——它与"持有更长"方向冲突，且无法在"出场绑定入场"的语境下解释。维度二的目标是**让赢家奔跑**，输家侧用 MDD 判据兜底即可。

## 六、维度三：仓位管理 —— 从「固定 2×50%」到「风险预算 + 半凯利」

### 6.1 现状逻辑

```
仓位 = 固定 50% × 权益（每只），2 只 = 100% 满仓
```

**问题**：凯利 `f* = −0.051`，满仓在负期望下放大亏损 → MDD 75.9%。

### 6.2 重构后的实现逻辑

**两层约束，各自自洽**：

```
第一层：风险预算制（控单笔亏损）
  止损距离 dist = 2 × ATR
  单笔风险预算 risk = 权益 × risk_budget_pct      # 默认 1.5%
  目标股数 = risk / dist

第二层：半凯利封顶（控整体暴露，随期望自适应）
  滚动 p = 近 20 笔胜率；b = 近 20 笔盈亏比
  f* = (p·b − q) / b                              # 凯利
  仓位上限 = f* / 2                                # 半凯利（留估计误差余量）
  实际仓位 = min(风险预算仓位, 权益 × f*/2)
```

**半凯利依据**：凯利公式假设 p、b 精确已知，实测 p、b 有估计误差，半凯利在误差下更稳健（业界标准做法）。**不再拍固定 25%**——封顶随期望自适应：期望为负时 f*<0 → 上限为 0（空仓），期望转正后自动给上限。

### 6.3 "信号期望转正"的可验证标准（**新增，维度三的触发条件**）

| 标准 | 阈值 |
|:--|:--|
| 12 起始日收益中位数 > 0 | 转正的必要条件 |
| 滚动 20 笔胜率 × 盈亏比 > 1（即 f*>0） | 转正的充分条件 |

**维度三在两条同时满足后才生效**；在此之前，仓位恒为 0（不参与）。

### 6.4 判据（冻结）

| # | 判据 |
|:--|:--|
| 1 | 单笔最大亏损占权益 ≤ 2 × risk_budget_pct |
| 2 | MDD 相对 BASE（75.9%）**显著收敛**，逐步向 <30% 逼近（最终目标是四维叠加后的合力） |
| 3 | 期望转正后，收益不显著低于满仓（半凯利不应牺牲太多收益） |

> 审阅结论修复：① `kelly_cap=25%` 无依据 → 改为半凯利自适应；② "转正"从模糊表述改为可验证的两条标准。

## 八、执行链路与追高机制（横切关注点）

### 8.1 完整时序（买入）

| 时点 | 动作 | 价格基准 | 代码位置 |
|:--|:--|:--|:--|
| T-1 收盘 | `on_bar_batch_end` 选股，候选入池 | `signal_price = T-1 收盘` | `:376-405` |
| T 收盘 | `_confirm_pending_buys` 确认：`T 收盘 > 信号价` | `price = T 收盘` | `:716` |
| T+1 开盘 | `order_mode="open"` 成交 | 开盘竞价 | `:1152`、`:1182` |

从选股到成交：**2 个交易日**。

### 8.2 滞后来源

| 环节 | 滞后 | 是否已处理 | 追高贡献 |
|:--|:--|:--|:--|
| 选股→确认 | 1 交易日 | 有意设计 | 确认要求涨 → 抬高买入价 |
| 确认→成交 | 1 交易日 | ✅ v9.0 已改 open | 强势股常高开 |
| 计算/调度 | 收盘后 | ✅ 无当日延迟 | 无 |
| 半自动人工 | 0~2 天 | ❌ 未控制 | 最长放大 |
| 滑点/跳空 | 开盘竞价 vs 信号价 | ⚠️ 无跳空保护 | 追高时最伤 |

### 8.3 核心缺陷：确认机制是「追涨确认」

```
信号层：选"创新高" → 已是高位
确认层：T 收盘 > 信号价才买 → 追涨确认，再抬一档
执行层：T+1 开盘成交 → 强势股常高开
人工层：semi_auto 延迟 0~2 天 → 再抬一档
滑点层：开盘竞价 vs 信号价 → 追高时滑点最大
→ 结果：≤7 天失败笔胜率 7%
```

### 8.4 重构落地（**补判据**）

| # | 动作 | 判据 |
|:--|:--|:--|
| 1 | 「追涨确认」→「回落站稳」（进维度一第 1 步） | 成交溢价中位数下降 |
| 2 | 信号加最长有效期（2 个交易日） | 超期未成交的信号自动作废，作废率可量化 |
| 3 | 开盘跳空 >2% 不追 | 跳空触发次数可量化 |
| 4 | 回测量化「成交价 vs 信号价」溢价中位数 | 作为追高程度基准 |

> 审阅结论修复：原第 2、3 条无判据，已补。

| 风险 | 表现 | 缓解 |
