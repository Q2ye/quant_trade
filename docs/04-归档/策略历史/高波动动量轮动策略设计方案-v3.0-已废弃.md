# 高波动动量轮动策略 v3.0 · 详细设计

> 2026-08-09 | 定位：小资金膨胀期 · 高收益优先 · 赔率优先 · **等回调避开顶部**
> 实现文件：`quant_server/modules/strategy/strategies/rotation/high_vol_momentum_strategy.py`

---

## 1. 版本演进依据

| 版本 | 核心问题 | 结论 |
|:---|:---|:---|
| v1.0 | 5 日高频 + trailing 5%/3% 对高波动池太紧 | 盈亏比 1.31，大赢家仅 1%，目标不可达 |
| v2.0 | 月频固定日买动量 Top，**买在顶部** | 胜率 20%（盈亏平衡需 33%），盈亏比 1.98 但期望仍为负 |
| **v3.0** | **入场逻辑重构：顺势 + 回调确认** | 不再追高，胜率提升路径；扩池增加独立板块 |

**v2.0 真实引擎证据（49 笔配对）**：
- 盈亏比 1.98 ✅（离场健康）
- 胜率 20% ❌（入场失败）
- 60% 持仓 21 天内亏损；MA50 机械退出造成 18% 交易 0-3 天全亏（churn）

**根因**：60 日动量最强 = 刚涨完的资产，在均值回归市场里即将回落 → 系统性买在顶部。

## 4. 选择逻辑（三层过滤 + 回调确认）

### 入场信号（核心重构：不追高）

```
① 候选池扫描：ETF 12 + 个股 12（个股过筛选）
② 趋势过滤（硬门槛）：价格 > MA200 且 MA50 > MA200（多头排列）
   排除下跌趋势中的反弹，只做多头趋势里的强势标的
③ 动量排序：60 日动量（skip 10）→ 选 Top 1-2
④ 回调确认（避开顶部）：
   计算偏离度 dev = (price - MA50) / MA50
   - dev ≤ entry_band_high(5%) 且 ≥ entry_band_low(-3%) → 立即入场（回调到位）
   - dev > overheat(8%) → 过热，不追高，加入「回调观察列表」
   - 观察列表每日检查：dev 回落到入场带 → 入场
   - 回调中跌破 MA200 或 MA50<MA200 → 放弃该标的
```

### 观察列表状态机（新增，v3.0 核心）

| 状态 | 条件 | 动作 |
|:---|:---|:---|
| 过热等待 | dev > overheat(8%) 且趋势成立 | 加入观察，剩余 N=20 天 |
| 回调到位 | dev ≤ 5% 且 ≥ -3% | 入场，移出观察 |
| 趋势破坏 | 价格 < MA200 或 MA50 < MA200 | 放弃，移出观察 |
| 观察超时 | 20 交易日未回调到位 | 放弃，移出观察 |

### 板块去重（保留）

ETF ↔ 个股同板块不重叠持仓（半导体ETF ↔ 北方华创等），双向去重。

## 5. 止盈止损（非对称，自适应）

| 类型 | 规则 |
|:---|:---|
| 硬止损 | 价格 < 成本 × (1 - 15%) → 次日开盘离场（宽，容忍高波动） |
| 移动止盈 | 浮盈 ≥ 20% 启动；从最高价回撤 ≥ 自适应阈值 → 离场 |
| **自适应回撤** | `max(固定 10%, 2 × ATR20 / price)` —— 高波动标的自动放宽，消除 churn |
| **趋势破坏** | MA50 < MA200（死叉）→ 离场（替代 v2.0 机械 MA50 退出线） |

> v2.0 用「价格 < MA50」单线退出，波动大时频繁触发（18% churn）。
> v3.0 改用「MA50 与 MA200 死叉」判定趋势破坏，更稳定。

## 6. 仓位与调仓

| 项 | 值 |
|:---|:---|
| 持仓 | ETF Top 2 只 × 50%（满仓 100%） |
| 个股增强 | 0-1 只，与 ETF 竞争动量，同权重 50% |
| 调仓频率 | 月频检查（21 交易日）+ 日频回调入场 + 日频风控 |
| 冷却期 | 卖出后 5 交易日不重买同标的 |
| 绝对动量门 | 最强标的动量 ≤ 0 → 空仓（货基落脚） |
| 入场/止损 | 调仓日收盘确认入场（order_mode=close）；止损/退出次日开盘（order_mode=open） |

## 7. 完整周期

```
每日 on_bar_batch_end
  │
  ├─ ① 日频风控（对持仓）：硬止损 / 移动止盈 / 趋势破坏(MA50<MA200) 退出
  ├─ ② 回调观察检查：观察列表中标的回调到位 → 建仓
  ├─ ③ 月频（每 21 交易日）：动量排名 → 目标 Top2
  │     ├─ 目标回调到位 → 立即入场
  │     ├─ 目标过热 → 加入观察列表（等回调）
  │     └─ 卖出不在目标中的旧持仓
  └─ ④ 状态更新：position / entry_price / peak_high / watchlist / cooldown
```

## 10. 验收标准

- [ ] 3 个月冒烟回测（有交易、无 NaN、收益率 ∈ [-95%, +500%]）
- [ ] 5 年回测：入场胜率提升至 > 30%（相对 v2.0 的 20%）
- [ ] 盈亏比 ≥ 2:1
- [ ] 无 look-ahead / survivorship bias / 数据泄露（audit-strategy 门）
- [ ] 等回调确实避免顶部：入场后短期（≤5 日）回撤比例下降

## 11. 风险与优化预留

- **等回调可能踏空**：强势主升浪不回调 → 观察列表 20 天超时放弃。缓解：观察期可配，超时后重新评估而非永久放弃。
- **个股黑天鹅**：硬筛选（ST/市值/流动性）+ 单笔 50% 上限。
- **板块集中**：扩池后 12 板块覆盖更独立，降低同涨同跌。
- **扩池数据校验**：新增标的（纳指/恒生科技/新能源车）历史较短，回测早期自动预热跳过。
