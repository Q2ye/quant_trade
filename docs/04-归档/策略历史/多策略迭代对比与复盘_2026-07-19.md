## 二、LightGBM ETF 底部策略迭代

### v1 — 可行性验证 (2026-07-18)

```
数据: 27 ETF × 23因子 (oversold子集)
训练: N=10, X=3%, Y=-5%  → AUC=0.614, T=0.72
回测: 2024.01-2024.12, 5 ETF, 固定止盈3%/止损-5%, 20%仓位
结果: 总收益+0.28%, 胜率62.86%, Sharpe=0.23

结论: 模型有效(AUC>0.6)，但止盈太小导致每笔期望≈0
```

### v2 — 因子补齐 + 提高标签目标 (2026-07-19)

```
数据: 27 ETF × 41因子 (oversold + valuation + market_regime)
      valuation子集仅覆盖7只宽基ETF(PE/PB有数据的)
训练: N=20, X=8%, Y=-5%  → AUC=0.655, T=0.36
新增因子: pe_percentile_5y, volatility_pct, momentum_score 等

回测(旧策略参数): 2024.01-2024.12, 7 ETF
结果: 总收益-1.67%, 胜率42.86%, Sharpe=-2.12
       ← 旧参数(止盈3%)与新高目标(8%)不匹配

结论: 模型精度提升，需配合策略层改造
```

### v2 策略层改造（已编码，待回测）

| 参数 | v1 策略 | v2 策略 | 逻辑 |
|:---|:---|:---|:---|

| 止损 | -5% | -8% | 给波动空间 |
| 阈值 | 0.70 | 0.30 | 宁错勿漏 |
| 仓位 | 20% | 35% | 集中火力 |
| 冷却 | 5天 | 2天 | 提高频率 |
| 持有期 | 10天 | 不限(trailing stop管理) | 让趋势走完 |

## 三、低吸轮动 StockLowHighStrategy 迭代

> 详细迭代历史见: `策略优化迭代记录.md`（16轮完整记录）

### 基准锚点（原版 v1.0）

```
回测区间: 2021-07-19 → 2026-07-18 (5年)
总收益: +66.78%    年化: +11.26%
Sharpe: 0.63       最大回撤: 26.09%
胜率: 39.91%       盈亏比: 1.45      交易: 694笔

核心参数: stop_loss=-4%, rebalance=100%, positions=3, 年线门=开, 6选股条件
```

### v1: 激进放宽全面失败

```
改动: 止损-8%, 年线门关, 持仓5只, ROC5→3, 量比1.2→1.0, 回撤保护关
结果: 18个月总收益 -11.46%, 最大回撤 -32.46%
原因: 放宽选股 = 选到噪音，更多持仓 = 更多垃圾
```

### v2: 半激进全面失败

```
改动: 止损-6%, 再平衡100%→50%, 其他保持原版
结果: 5.5年总收益 +33.58% (vs原版+67%), 最大回撤 +33.51% (vs原版26%)
     2024牛市年仅+1.7% (原版预期+30~60%)
原因: 再平衡50%砍了大赢家——牛市自残。止损-6%放大了震荡市亏损
```

### v3 方向讨论

**已验证不应动的东西**: 止损-4%, 再平衡100%, 年线门, 6条选股条件

**可以动的**:
1. **选股分层** → 最安全：核心层(3只)用原版全套条件 + 增厚层(1-2只)用放宽条件但严格止盈
2. **波动率加仓** → 中等风险：在确定赢家上加大仓位
3. **止盈分级** → 最互补：高波动股晚减仓，低波动股早减仓

## 四、关键教训

### 1. 选股质量的α远超参数调优

低吸轮动 v1/v2 动参数均失败。这个策略的66%收益来自「6条条件选出的股+让它们跑到100%才减仓」。改变这个机制的任何一个环节都会降低收益。

### 2. 牛市砍赢家 = 自废武功

v2的再平衡从100%改到50%直接导致2024牛市年颗粒无收。在上涨趋势中提前兑现是成本最高的操作失误。

### 3. 震荡市放宽止损 = 放血

-6%止损比-4%在震荡市中多亏50%。止损应该看标的波动率而非固定百分比——高波动股自然需要更宽的止损。

### 4. 每次只改一个变量

v1同时改6个参数，失败后分不清是谁的锅。v2只改2个参数，但两个改动互相放大负面效果（更宽的止损让烂股多亏+更早的减仓让好股少赚）。

### 5. ML策略的问题不在模型精度

LightGBM AUC从0.614提升到0.655，但策略收益没变——因为瓶颈在止盈止损比(3:5)，不在模型。改止盈止损是免费的午餐，提升AUC只是甜点。
