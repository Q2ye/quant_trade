## §0 赚什么钱（三层分析）—— 一切规则的前提

> 这一节是 G0 立项门准入条件①的正文。**规则可以改，这一节必须先立住。**

### 0.1 结构层：钱从哪来、谁在付

趋势臂可能赚三种钱，**必须选一个作为主来源**——它们的闸门完全不同：

| 来源 | 是什么 | 是 α 吗 | 需要的闸门 |
|:---|:---|:---|:---|
| **A 时序 β 再分配** | 上涨期持有、下跌期退出，赚风险溢价的时序暴露 | **不是**，是 β 择时 | 宽度的**绝对水平** |
| **B 横截面 α** | 板块间资金迁移的摩擦与滞后 | **是** | 横截面的**离散度** |
| **C 流动性提供** | 在边界反向承接，赚价差与冲击成本 | 是 | 波动率水平 |

- **C 是震荡臂的生意，不是趋势臂的**——趋势跟随在突破点是**消耗**流动性而非提供。原方向文档把 A/B/C 三种生意装进一个框架，是最上层的结构混同。
- 趋势臂实际赚 **A + B**，两者性质不同：A 的天花板 ≈ 市场长期收益 × 择时胜率；**B 才是"小资金快速膨胀"的可能来源**。

> ⚠️ `cross_market_momentum_strategy.py:369-371` 已自认此边界：*「A股普涨时随便一只 ETF 都「动量强」，但那是 **β 不是 α**」*。

### 0.2 行为层：谁在持续付钱

| 机制 | 内容 | 对趋势臂的支撑 |
|:---|:---|:---|
| **处置效应** | 过早止盈、过晚止损 → 解套盘被吸收后延续 | **最强** |
| **锚定 + 分批决策** | 机构按季/月调仓，看到涨幅才追 → **资金流滞后于价格** | 强 |
| **排名博弈 / 抱团** | 相对排名考核 → 追明星板块 → 板块动量自我强化 | 强，**只作用于板块层面** |
| **羊群 / 涨跌停 / T+1** | 涨停磁吸；T+1 推迟当日买盘卖压 | **对 ETF 弱**——ETF 有申赎套利，溢价被抑制 |

**推论**：支撑最强的是**板块间的资金迁移**。→ **趋势臂的池子应偏行业/风格 ETF，不是宽基 ETF**。宽基 ETF 的突破基本只剩 A（β 择时），那是薄生意。

### 0.3 统计层：什么规律在支撑

| 规律 | 内容 | 说明 |
|:---|:---|:---|
| **波动率聚集** | 高波动状态有持续性（GARCH） | **最稳健的经验规律**。ATR 止损、波动率确认的统计基础 |
| **时序动量 TSMOM** | 过去收益预测未来方向 | 全球验证，**A 股是弱版本** |
| **横截面动量 > 时序动量** | 文献稳健性更高 | 再次指向板块轮动而非市场择时 |
| **收益肥尾** | 趋势跟随在正态分布下**不赚钱** | 截断左尾、保留右尾的结构性依据 |
| **动量崩溃** | 反转期剧烈回撤 | 必须接受的代价，也是止损存在的理由 |
| **尺度分离** | **日频反转、月频动量**，方向相反 | `cross_market` :166-168 实测：信号日涨 2~5% → 胜率 **31%**、平均 **−0.55%**；跌 0~−2% → 胜率 **58%**、平均 **+1.38%** |

**最后一行最有价值**：方向用月尺度、执行用日尺度，且**入场必须回避"当日已大涨"**。原方向文档的"突破日收盘买入"恰好踩在这条上——**突破日本身就是大涨日**。

**与项目哲学的匹配**：趋势跟随天然是「赔率优先」的生意（右偏、截断左尾），与`小资金膨胀期、赔率优先于胜率`一致 ✅。但**机会频率低**——而 `high_vol` 的路径是"每月 1-2 笔 × 盈亏比 3:1"。**频率是关键变量**（见 R3⑤）。

### 0.4 与既有策略的增量 —— 必须先答

**既有两个动量策略，都是「横截面轮动 + regime 门 + ATR 移动止损」**：

| 策略 | 池 | 选券 | 止损 | regime 门 |
|:---|:---|:---|:---|:---|
| `high_vol_momentum` v7.1 | 全市场**个股** | 多因子打分选 Top2 | 2~3.5×ATR 追踪 | CSI500 年线门 |
| `cross_market_momentum` v1.0 | **ETF 池**（29 只） | 25 日动量选 1 只 | 轮动换仓 | 走弱期 4 指数投票 |

趋势臂唯一的结构差异是：**绝对阈值、可以不满仓**（轮动策略永远被迫持有"最不差"的那只）。而 `cross_market` 已有防御 ETF（国债）兜底——**增量比看起来更薄**。

> ⚠️ **一票否决警示**：若本方向的"增量"本质是"给动量策略加市场择时开关"，**已证否**——`high_vol` v7.2 试过（年线门 + CSI500 MA20>MA60 + 近20日动量>0），结论**负优化**（+177%/MDD 31.8%，2025 大牛损失 213pp，代码回退 v7.1，见其文件头 `:28-32`）。

### 0.5 三层分析推出的三个硬结论

1. **趋势臂赚 A+B，A 和 B 需要不同的闸门** —— 原方向文档用一个状态机同时管两件事，逻辑不成立。
2. **震荡臂赚 C，是一门与趋势臂完全不同的生意** —— 不该被同一个框架"切换"。
3. **标的池的选择 = 选择赚哪种钱** —— 不是配置细节（见 §4）。

## §1 状态机

### 1.1 是否使用 · 支持逻辑 · 脆弱处

在只有趋势臂的系统里，**状态机的唯一职能是「风险预算闸门」**。

**支持逻辑（成立）—— 它不是预测涨跌，而是关闭负期望赌局：**

横截面动量的**前提是"存在强板块"**。宽度崩塌、所有 ETF 同跌、相关性趋同后，「选最强」退化为「在下跌的里面选跌得最少的」——**这是负期望**。状态机的作用是关掉这个赌局。

这正是 `cross_market` 开篇的逻辑原话（:8-9）：
> 「A股走弱时，多数行业 ETF 同跌、**相关性趋同，此时「避」比「选」更重要**」

**且它不可被止损替代**（这是它真正的存在理由）：

| | 止损 | 市场闸门 |
|:---|:---|:---|
| 作用域 | 标的级、逐只触发 | 全局 |
| 时点 | **事后**（跌了才退） | **事前** |
| 相关性趋同的下跌中 | 所有标的同时被扫，且**都成交在更低的价格** | 提前撤出 |

**支持逻辑（不成立/脆弱）—— 判据与收益源不匹配：**

- **宽度水平**衡量的是 **β 的方向**（市场整体涨跌）
- 趋势臂（若做板块选择）赚的是 **B：横截面 α**
- 横截面动量赚钱的前提是**离散度**（有强有弱），**不是方向**
- 关键：**普涨（>60）和普跌（<30）时，离散度都低**——普涨是"都是 β"，普跌是"都在跌"。真正赚钱的是**分化市**。**而宽度的绝对水平恰恰不衡量分化**

→ 用宽度水平当趋势臂闸门，在两个极端都可能误判。

### 1.2 拆成两个方向相反的判断（最重要的结构性修正）

**"市场是不是震荡"和"这只标的是不是在做区间"是两个判断，且错误代价方向相反：**

| | **市场级**：现在能不能进攻 | **标的级**：这只适合做回归吗 |
|:---|:---|:---|
| 归属 | 风控（仓位上限） | 选券（用哪套逻辑） |
| 判断对象 | 全市场相关性是否趋同 | 该标的是否在区间内往复 |
| **漏报代价** | 系统性下跌没躲掉 → 大回撤 | 少做几笔 → 机会成本 |
| **误报代价** | 少赚 → 机会成本 | **在趋势标的上做回归 → 接飞刀，无界亏损** |
| → 偏向 | **高召回、低精确** | **高精确、低召回** |
| 合适判据 | 宽度水平、相关性 | 该标的的 VR / 自相关 / 区间稳定性 |

**两者不能用同一套阈值、甚至不能用同一种判据。** 原方向文档用同一个状态机同时决定"启用震荡臂"和"这只标的在不在震荡"，必然在其中一端是错的。

**根本原因**：**均值回归是标的属性，不是市场属性。** 债券 ETF、黄金 ETF 结构性震荡；成长风格 ETF 结构性趋势。市场级标签会把两者混在一起——而市场级标签在收盘后才告诉你"今天是震荡"，对"这只标的有没有区间可做"几乎没有信息量。

### 1.3 市场级闸门（收敛后）

**复用，不新建**：`shared/market_regime.py::breadth_to_regime`。该模块已自我声明为「单一可信源」，被策略择时 / 资金分配 / 回测 CapitalAllocator 三处调用。新建第二套会分叉口径——而库里**已存在两套不一致的 regime**：

| 来源 | 判据 | 状态 |
|:---|:---|:---|
| `market_state_daily.regime` | CSI300 的 MA20/MA60 + 斜率（`market_state_classifier.py:317-322`） | 旧口径 |
| `market_regime.py::compute_regime/breadth_to_regime` | 市场宽度 `above_ma250_pct` | 为**替代前者**而建 |

**不使用 `market_state_daily.regime`（CSI300 版）——它是被替代对象，不是竞品。**

```python
from shared.market_regime import breadth_to_regime
regime = breadth_to_regime(above_ma250_pct)   # 0=BEAR / 1=RANGE / 2=BULL
```

| 状态 | 宽度 | 仓位上限 | 趋势臂行为 |
|:---|:---|:---|:---|
| `BEAR` (0) | `b < 30` | **0%** | 不开新仓；已持仓交由止损自然退出 |
| `RANGE` (1) | `30 ≤ b ≤ 60` | **50%** | 可开仓，总仓位封顶 50% |
| `BULL` (2) | `b > 60` | **100%** | 可开仓，总仓位封顶 100% |

阈值 30/60 为 `breadth_to_regime` 默认值，与 `docs/00-核心策略体系/00-总览架构/执行框架设计.md:124` 一致。**本轮不改这两个阈值**——改它等于重新拟合状态机。

> ⚠️ **`above_ma250_pct` 不在 `create_table.sql`** —— DDL 只有 `above_ma20_pct`/`above_ma60_pct`；该列由 `scripts/data/backfill_breadth_ma250.py:24` 的 `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` 补入，**只存在于活库**。按 DDL 重建库会静默丢失 → `breadth_to_regime(None)` 返回 `RANGE`（`market_regime.py:75-76`）→ **永久半仓且不报错**。R1 必须先确认并补进 DDL。

> ⚠️ **代理口径**：`above_ma250_pct` 是**全市场股票**宽度，而交易标的是 **ETF 池**。这是"已接受的代理"，但**必须在 R3④ 用 ETF 池收益本身验证**，否则重犯本项目已犯过的代理错配（`market_regime.py:60-62` 记载：用 CSI500 中盘指数保护小盘策略，**曾致 54% 回撤**）。

### 1.4 去抖：滞回带，不是 N 日确认

原方向文档用"3 日确认期"。**改为滞回（hysteresis）**：

```python
if not bull and b > 60: bull = True
if bull and b < 55:     bull = False      # 进入需越外沿，退出只需回内沿
```

**理由**——本项目已实测过 N 日确认的代价（`cross_market_momentum_strategy.py:137-139`，5269 个交易日）：

| 确认天数 N | 年均翻转 | 走弱期天数占比 |
|:---|---:|---:|
| 1（当前） | 15.8 | 43.6% |
| 3 | 7.6 | 41.4% |
| 5 | 5.0 | — |

即**去抖几乎不改变长期仓位分布，全部代价落在进/出滞后上**。N 日确认是**无差别**地拖慢每一次切换；滞回只在阈值附近起作用，远离阈值的果断切换**立即生效**。

> ⚠️ 滞回带宽（60→55，5 个百分点）是本轮**唯一新增参数**，标为待校准，由 R3 敏感性扫描单独确定，**不与其他参数联合拟合**。

### 1.5 特例：极端波动（保留）

原方向文档"单日波动 > 3×ATR → 立即降仓，不等确认"——**保留**。这是全文档最好的一条直觉（风控优先于状态确认），且与滞回不冲突。

## §2 趋势臂

### 2.1 进场：单一规则

```python
breakout_level(t) = max(high[t-N+1 .. t-1])      # N=20，不含当日 → 无未来函数
触发:  close[t] > breakout_level(t)
验证:  volume[t] / mean(volume[t-20 .. t-1]) > 1.8
```

| 原方向文档规则 | 处置 | 理由 |
|:---|:---|:---|
| 触发「收盘价 > 最近分形高点」 | **改为 N 日新高（N=20）** | 5 根分形在日线上信号过密，且枢轴需 `i+2` 才确认 → 突破位天然滞后 2 日。N 日高点用 `t-1` 及之前数据，无确认滞后 |
| 验证「量能比 > 1.5」 | **保留，取 1.8** | 本项目已实证量能确认是正确过滤（cross_market `volume_threshold: 1.8`，有 A/B 支撑） |
| 验证「ATR 压缩后放大」 | **降级为待验证增强** | ⚠️ **自我修正**：波动率聚集是最稳健的经验规律，"低波动→高波动"有实证支撑（VCP/布林收口突破），**不应直接砍**；但引入 2 个参数，须由 R3 单独 A/B |
| 验证「肯特纳上轨之上**或附近**」 | **砍掉** | 「附近」不可编码，违反原文档 §3 自述的"无主观成分"；且与突破规则冗余 |
| 验证「未逆大周期（日线在 TREND_UP）」 | **改由市场级闸门承担** | 见 §1.2——标的层不再看市场标签 |
| 确认层「D1 试探 30% → D2/D3 加至 70% → D4+ 满仓」 | **默认一次性建仓；分步建仓列为待验证** | 与原文档 §7.1.1 的 2% 风险预算**数学互斥**（见 §2.3）；且应先证明假突破亏损占比高到值得 |

**假突破率是 R3 要量的数**：按上述规则统计"突破后 N 日内跌破 `breakout_level`"的比例。若低（如 <20%），分步建仓直接不需要。

### 2.2 仓位：风险金额法（废止固定阶梯）

原文档 §7.1.3 的 30/70/100 阶梯与 §7.1.1 的"单笔风险 ≤2%"**不可能同时成立**。止损距离 `d`、仓位 `P` → 止损时亏损 = `P × d`，要求 `P × d ≤ 2%`：

| 仓位档 | 文档给定 P | 满足 2% 所需 d | 等价要求的 ATR% |
|:---|---:|---:|---:|
| 试探 | 30% | ≤ 6.7% | ≤ 2.2% |
| 确认 | 70% | ≤ 2.9% | ≤ 0.95% |
| 满仓 | 100% | ≤ 2.0% | ≤ 0.67% |

止损为 3×ATR 时，**「确认档」与「满仓档」在正常波动率下永远违反 2% 预算（满仓档违反 3 倍）**。

**修正**：

```python
stop_distance = 3 * ATR(14)[t]
P_risk = RISK_BUDGET / stop_distance            # RISK_BUDGET = 2%
P      = min(P_risk, 状态机仓位上限 - 当前持仓)
if P <= 0 or stop_distance >= entry_price:      # ATR 过大或资金不足
    不开仓
```

符合本项目 `.claude/rules/audit-strategy.md §3.3` 强制要求的风险金额法。

### 2.3 止损：唯一规则

**唯一规则 = 3×ATR 追踪**，只上移不下移：

```python
stop(t) = max(stop(t-1), highest_close_since_entry(t) - 3 * ATR(14)[t])
```

- **砍掉「分形低点」**：枢轴滞后 2 日；且快速拉升中"最近分形低点"可能**高于**入场价 → 止损立即触发
- **砍掉「肯特纳中轨」**：中轨是均值回归的锚，对趋势仓会被正常回撤扫出，与"让利润奔跑"矛盾
- **无主动止盈**：沿用 `cross_market_momentum_strategy.py:1591-1593` 的声明式豁免

### 2.4 出场与执行

| 触发 | 动作 |
|:---|:---|
| `close[t] < stop(t)` | 全部退出 |
| 状态机转 `BEAR` | 不强制平仓，由止损自然退出（避免与止损规则冲突） |
| 其他 | 本臂不做轮动换仓（会引入与 cross_market 重叠的机制） |

**执行模型（T+1）**：信号在 `t` 日**收盘**产生 → `t+1` **开盘**执行。校验口径：收益率 ∈ **[−95%, +500%]**、≥1 笔交易、无 NaN。

**成本（必须进回测，不能留到模拟盘）**：ETF **免印花税**（本项目曾因 ETF 回测错收印花税系统性低估，2026-09-12 修复）；佣金 + 滑点按既有参数（万1 + 万1）。

## §3 震荡臂

### 3.1 "震荡判断是否准确"—— 指标本身要换

**震荡与突破，在 `t` 时刻用同一份历史数据不可分辨。** 看到"价格在下沿附近"，无法区分①要反弹（该买）②要跌破（该跑）——两个世界的历史完全一样。

原方向文档 §6.1 写"若收盘突破下沿 → 转为突破信号处理"，**不是 bug，是结构性的自认**。

**正确的问题不是"分类器准不准"，而是：**

> **在标为震荡、价格触及下沿时买入，条件期望收益是否为负？**

这把**准确率问题**转成了**赔率问题**——与`赔率优先于胜率`一致。45% 胜率 × 盈亏比 2:1 是好生意；60% 胜率 × 每次赔 3 倍是坏生意。

> ⚠️ **测量纪律**：必须用**分类器在 `t` 时刻真实会打出的标签**，不能用事后回看划分的"干净区间"——后者系统性剔除了转头那几天，而那几天恰是全部亏损来源。

### 3.2 周期必须先测，且原文档窗口存在量级矛盾

**震荡判断的滞后必须远小于震荡周期本身。** 而原文档 §3.3/§4.2 用 **60 日回归窗口**。

若震荡周期只有 30–40 日，则 60 日窗口内已含 1.5–2 个完整周期 → **回归斜率被平均到趋近 0**：

- 实际只能识别"水平震荡"（斜率≈0）
- **识别不了它想识别的"倾斜震荡"**——倾斜信号被窗口自身的长度抹掉了
- 而 §4.2 恰恰把"倾斜震荡"当核心状态之一

这不是参数没调好，是**窗口与信号在量级上不匹配**。所有窗口（回归、MA、确认期、持有期）都必须由**实测周期反推**。

**且**：若周期均值 30 多天、而标签需 60 天窗口 + 确认期才输出，则标签出现时区间可能已走完大半 → **震荡臂会系统性在周期尾部入场**。

### 3.3 标的级判据："有规律"落成四个可测量

| # | 条件 | 度量 | 期望方向 |
|:--|:---|:---|:---|
| 1 | **均值回归性** | `VR(k) = Var(k日收益)/(k·Var(1日收益))` | **VR < 1**（最直接的单一指标） |
| 2 | **边界有效性** | 触及下沿后 N 日内回到中轨的概率 | 越高越好 |
| 3 | **长期漂移小** | `drift / σ` | 越小越好。有大漂移的标的会持续单边破沿，区间假设不成立 |
| 4 | **波动率适中且稳定** | ATR% 水平 + 其自身波动 | 太高→边界宽、跌破凶；太低→覆盖不了成本 |

第 3 条最易忽略：**长期单边漂移的品种**（如某些赛道 ETF）在震荡态下看着也有区间，但它的"下沿"会一次次被向下突破——**震荡臂的钱亏在这种标的上**。

### 3.4 止损与仓位

- 单笔止损 `1.5 × ATR`（比趋势臂紧——震荡臂必须快进快出）
- 仓位上限 30%（防守性质），且受市场级闸门约束
- **转势保护**：标的级判据一旦失效 → 立即平仓，不做犹豫

## §4 标的池

### 4.1 趋势臂与震荡臂的池子要求相反

| | 趋势臂（突破） | **震荡臂（均值回归）** |
|:---|:---|:---|
| 行为层的钱来自 | 追涨的羊群、处置效应、涨跌停磁吸 | **过度反应后的修正** |
| 个股 or ETF 更强？ | **个股更强**（羊群、磁吸） | **ETF 更强** |
| 主要风险 | 假突破（有界，止损可处理） | **区间被基本面破坏** |

### 4.2 个股 vs ETF —— 震荡臂的关键分野

**个股有一个无法通过分散或止损消除的左尾**：退市、暴雷、停牌。均值回归的本质是"跌了会回来"，而个股可以永远不回来（退市 = −100%）。

**ETF 不会退市**，其"跌破区间"是市场/板块级的态变，**左尾有界且更可预测**；且 ETF 有**申赎套利机制**——价格锚定净值，这本身就是"有规律"的制度来源。

→ **震荡臂的池子应该是 ETF，不是个股。** 这与趋势臂的结论**正好相反**。

> 公平地说：个股的**短周期反转（1–5 日）**是 A 股最强异象之一，并非不能做均值回归；但那个尺度上**成本吃掉大部分收益**；而中周期（20–60 日）区间回归上，个股左尾风险显著高于 ETF。**先明确捕捉哪个尺度的反转。**

### 4.3 两层筛选

**第一层 · 结构性排除（硬条件，无自由度）**
- 类型（理由见 §4.2）
- 历史 ≥ 500 交易日（指标预热）
- 日均成交额 ≥ 阈值（容量）
- 无长期停牌记录

**第二层 · 行为筛选（软条件，用数据选）**
用 §3.3 的四个量在**标的级判据划出的震荡期**内打分排序。

### 4.4 选池本身就是一次拟合

> ⚠️ **最容易被忽略的过拟合**：用全历史挑出"最均值回归的 N 只"，再在这 N 只上回测全历史 → **选择偏差 + 幸存者偏差叠加**，结果显著虚高。
>
> **必须**：前 60% 数据选池 → 后 40% 复核；并**同时报告"全候选池等权"**作为无选择偏差对照。
