# 量化策略逻辑规格书 v1.0

日期：2026-09-16
定位：中低频（日线 / 周线）量化交易系统 —— 市场状态机 + 双策略（趋势 / 震荡）+ 风控模块
状态：待实现代码验证

## 一、总体架构

```
市场状态机（总开关）
识别当前状态：趋势牛 / 趋势熊 / 震荡 / 倾斜震荡
        ↓
┌──────────────┐        ┌──────────────┐
│趋势策略      │        │震荡策略      │
│（趋势模式）  │        │（均值回归模式）│
└──────────────┘        └──────────────┘
        ↓
┌────────────────────┐
│仓位与风控模块      │
│止损/回撤/仓位分配  │
└────────────────────┘
```

核心原则：状态机决定 “哪个策略上场”，策略模块决定 “何时进出”，风控模块决定 “下多大注”。三层职责分离。

## 二、输入数据

### 必需数据（日线级别，中低频）

1. OHLCV（开盘、最高、最低、收盘、成交量）— 至少 250 交易日（约 1 年）
2. 推荐 500+ 交易日做指标预热

### 可选增强数据

1. 全市场涨跌家数（宽度指标）— 用于趋势确认
2. 行业指数 — 用于交叉验证

### 数据清洗要求

复权处理、剔除停牌、处理除权除息

## 三、指标定义（全部可编码，无主观成分）

### 3.1 ATR（平均真实波幅）—— 波动率基础

```
TR = max(high-low, |high-prev_close|, |low-prev_close|)
ATR(N) = 过去 N 日 TR 的简单平均，N=14（默认）
ATR 趋势线 = 过去 40 日 ATR 的均值（用于判断压缩/放大）
```

### 3.2 肯特纳通道（Keltner Channel）—— 动态边界

```
中轨 = EMA(close, 20)
上轨 = 中轨 + 2 × ATR(14)
下轨 = 中轨 - 2 × ATR(14)
```

特点：波动率收缩时通道变窄，放大时通道变宽（自适应）

### 3.3 回归通道（线性回归 + 残差）—— 识别倾斜震荡

```
对过去 N(N=60) 日收盘价做线性回归：
回归线 slope（斜率）→ 判断震荡倾斜方向
回归线上沿 = 回归线值 + 2 × StdDev(残差)
回归线下沿 = 回归线值 - 2 × StdDev(残差)
```

输出：

- slope → 用于状态判断
- 回归通道上下沿 → 用于震荡策略的进场参考

### 3.4 分形高低点（Fractals）—— 结构拐点

```
分形高点：出现于 i-2, i-1, i, i+1, i+2 共5根K线中，
第 i 根最高价严格大于其他4根 → 记为局部高点

分形低点：第 i 根最低价严格小于其他4根 → 记为局部低点

维护两个队列：
fractals_high[]（最近分形高点序列）
fractals_low[]（最近分形低点序列）
```

### 3.5 均线系统 —— 趋势骨架

MA20 / MA60 / MA120 / MA250
用于趋势方向的粗判定和过滤

### 3.6 ADX（趋势强度）—— 状态机辅助

```
ADX > 25 → 存在强趋势
ADX < 20 → 震荡状态
20-25 → 过渡区
```

### 3.7 成交量确认

```
量能比 = 当日成交量 / 过去 20 日均量
放量阈值：量能比 > 1.5
```

## 四、市场状态机（核心总开关）

### 4.1 状态输出

- `TREND_UP` （趋势牛）
- `TREND_DOWN`（趋势熊）
- `RANGE_H`（水平震荡）
- `RANGE_TILT_UP`（倾斜震荡上行）
- `RANGE_TILT_DN`（倾斜震荡下行）

### 4.2 判定规则（按优先级顺序）

第一层：趋势强度判定（ADX + 均线排列）

```
IF ADX > 25 AND MA20 > MA60 > MA120:
    状态 = TREND_UP
IF ADX > 25 AND MA20 < MA60 < MA120:
    状态 = TREND_DOWN
```

第二层：趋势方向分叉（ADX>25 但均线纠缠）→ 转观察（降仓）
第三层：震荡判定（ADX <= 25）

```
计算回归通道 slope（过去60日）：斜率 = 回归系数（价格变化/日）

IF |斜率| < 阈值（slope_threshold）:
    状态 = RANGE_H（水平震荡）
IF 斜率 > 阈值:
    状态 = RANGE_TILT_UP（倾斜震荡上行）
IF 斜率 < -阈值:
    状态 = RANGE_TILT_DN（倾斜震荡下行）
```

斜率阈值设定（示例，需回溯校准）：

- 对价格归一化后，斜率 > 0.05%/ 日，斜率 > 0.05%/ 日 ≈ 倾斜震荡
- 或直接用 60 日回归的 R² 辅助判断：
    - R² > 0.6 且斜率大 → 已经是趋势（升级处理）
    - R² < 0.4 → 震荡（区间处理）

### 4.3 状态切换的滞后管理

1. 状态切换不立即生效，设置确认期（默认 3 日）：新状态连续确认 3 个交易日 → 才切换生效
2. 期间仓位减半（不确定期的防守）
3. 特例（风控优先）：出现暴跌 / 急涨（单日波动 > 3×ATR）→ 立即降低仓位，不等确认

## 五、趋势策略模块（TREND_UP / TREND_DOWN 时启用）

### 5.1 进场信号 —— 突破判定引擎（多层叠加）

做多信号（TREND_UP 状态下）

- **触发层**：收盘价 > 最近分形高点 (fractals_high 最新值) → 结构破位
- **验证层（全部满足才算 “真突破”）**
    - ✓ 量能比 > 1.5（放量）
    - ✓ ATR 处于压缩后放大（当前 ATR > 前 20 日 ATR 均值 × 1.2）
    - ✓ 未逆大周期（日线在 TREND_UP，周线不处于下降结构）
    - ✓ 突破日的收盘在肯特纳上轨之上或附近
- **确认层（分步建仓）**
    - D1 触发 + 验证通过 → 试探仓 30%
    - D2/D3 连续收盘站稳突破位 → 加至 70%
    - D4+ 继续站稳 → 满仓
    - 任何一日收盘回到突破位下方 → 假突破，全部退出

做空信号（TREND_DOWN 状态下）：完全镜像
收盘价 < 最近分形低点 + 量能 + ATR 确认 + 分步建仓

### 5.2 持仓管理

跟踪止损（移动止损，三选一或叠加）

- 方案 A（ATR 追踪）：止损线 = 最高收盘价 - 3 × ATR (14)（做多）；每个交易日更新，只上移不下移
- 方案 B（分形跟踪）：止损线 = 最近分形低点（跌破则退出）
- 方案 C（通道跟踪）：止损线 = 肯特纳中轨（跌破中轨退出趋势仓）

止盈（不设固定止盈，让利润奔跑）：只在跌破止损线时退出，不主动止盈

### 5.3 趋势辅助过滤（宽度确认，可选）

增强：如果数据可得，叠加市场宽度

- 指数创新高 且 创新高家数不再增加 → 宽度背离 → 减仓 30%
- 宽度背离 + ATR 急剧放大 → 顶部预警 → 减仓 50%

## 六、震荡策略模块（RANGE_H / RANGE_TILT_UP / RANGE_TILT_DN 时启用）

### 6.1 进场规则（均值回归）

水平震荡（RANGE_H）—— 在肯特纳 / 回归通道边界反向操作
做多信号：

- 价格触及 / 接近回归通道下沿（±0.5 倍 ATR 内）
- 且 ADX < 20（确认震荡）
- 且未跌破下沿（若收盘突破下沿 → 转为突破信号处理）
- 进场：下沿附近买入，仓位上限 = 总仓的 30%（防守性质）

做空信号：

- 价格触及 / 接近回归通道上沿
- 且 ADX < 20
- 进场：上沿附近卖出 / 减仓，仓位上限 30%

倾斜震荡（RANGE_TILT_UP）—— 顺着倾斜方向做：

- 主方向做多（顺着斜率）
- 价格回调到回归线下沿附近 → 做多
- 止损 = 跌破最近分形低点
- 不做反向（不逆着斜率在上沿做空）；仅回补 / 减仓，不开新空仓

倾斜震荡（RANGE_TILT_DN）—— 镜像：反弹到上沿 → 做空 / 减仓；不在下沿抄底

### 6.2 震荡策略的核心风控（防假突破打脸）

1. 单笔止损：进场后亏损达 1.5 × ATR → 止损退出（比趋势止损更紧，因为震荡策略必须快进快出）
2. 转势保护（最重要的一条）：状态机一旦切换到 TREND_UP / TREND_DOWN → 震荡策略立即全部平仓，交给趋势模块；震荡策略不做任何犹豫（震荡策略的钱都亏在 “转势迟走” 上）
3. 仓位限制：震荡策略总仓位永远 ≤ 总资金的 30%（防守性质）
4. 盈利目标 = 覆盖日常磨损，不指望它赚大钱

## 七、风控模块（全局）

### 7.1 仓位分配总规则

1. 总风险预算 = 账户资金的 2% / 单笔（即单笔亏损不超过 2%）
2. 按状态的仓位上限：
    - TREND_UP / TREND_DOWN（强趋势）→ 最高 100% 投入
    - RANGE_TILT（倾斜震荡）→ 最高 50%
    - RANGE_H（水平震荡）→ 最高 30%
    - 状态切换确认期 → 最高 30%（不确定防守）
3. 按信号的仓位拆分：
    - 趋势策略：试探 30% → 确认 70% → 满仓
    - 震荡策略：单笔不超过总仓 30%，最多同时持有 2 笔

### 7.2 止损与回撤熔断

1. 单笔止损：
    - 趋势仓：3 × ATR 追踪
    - 震荡仓：1.5 × ATR 固定
2. 账户级回撤熔断（最重要，写在最前面）：
    - 账户回撤达到 10% → 仓位减半 + 停止开新仓 5 个交易日
    - 账户回撤达到 20% → 全部平仓 + 停止交易 20 个交易日（暂停期间复盘，确认是策略问题还是执行问题）
3. 恢复规则：
    - 复盘后有明确改进 → 按 1/2 仓位重新入场试探
    - 复盘后认为是市场环境问题 → 等待状态机重新给信号

### 7.3 最大持仓与相关性控制

1. 同时持有策略（趋势 + 震荡并行）：最多 1 个趋势仓 + 1-2 个震荡仓
2. 若两个震荡仓在同一品种上 → 合并计算仓位
3. 同一品种只允许一个方向（多头 / 空头不并存）

## 八、完整信号流（一天的处理流程）

每个交易日收盘后执行：

1. STEP 1：更新指标
   计算当日 ATR、肯特纳通道、回归通道、分形点、ADX、量能比
2. STEP 2：跑状态机
   输入：ADX、均线排列、回归斜率
   输出：当前状态（含 3 日确认逻辑）
3. STEP 3：选策略
    - 状态 = TREND_UP/TREND_DOWN → 执行趋势模块逻辑
    - 状态 = RANGE_* → 执行震荡模块逻辑
    - 状态 = 确认期 → 只减仓不开新仓
4. STEP 4：检查风控
    - 账户回撤 > 10% / 20% → 触发熔断（平仓 / 停开仓）
    - 单笔止损线是否被触发 → 是则退出
5. STEP 5：生成当日指令
   输出格式：

```
{
    "date": "",
    "status": "", // 市场状态
    "signals": [
        {
            "action": "BUY/SELL/CLOSE/HOLD",
            "size": "百分比",
            "stop": "止损价",
            "target": "止盈价(震荡) / 追踪(趋势)"
        }
    ],
    "reason": "突破分形高点+放量+ATR压缩后放大",
    "status_confirmation": "3日内确认进度"
}
```

6. STEP 6：记录日志
   每日净值、持仓、状态、信号、触发原因（为归因分析和调优提供数据）

## 九、回测验证的步骤（实现后按此顺序做）

1. 第 1 步：数据准备
   清洗数据（复权处理、剔除停牌、处理除权除息）；至少 5 年历史数据（覆盖牛 / 熊 / 震荡各阶段）
2. 第 2 步：指标与状态机单元测试
   逐个验证 ATR、肯特纳通道、回归通道、分形、ADX，确保指标计算和人工画图一致；单独跑状态机，输出历史状态序列，人工抽检状态标记是否合理
3. 第 3 步：模块独立回测
    - 趋势模块单独回测：仅在历史标记为 TREND_UP / TREND_DOWN 的时段运行，评估趋势策略在趋势行情下的收益、最大回撤、胜率、盈亏比
    - 震荡模块单独回测：仅在历史标记为 RANGE_* 的时段运行，评估震荡策略在震荡行情的表现；重点观察假突破带来的亏损
4. 第 4 步：全系统联合回测
   状态机自动切换，趋势 / 震荡模块自动启停，叠加完整风控、仓位规则、熔断机制；输出全周期净值曲线、风险指标（Calmar、夏普、最大回撤、盈亏比、交易次数）
5. 第 5 步：样本外滚动验证
   预留一段样本外数据不参与参数调优；使用滚动窗口（例如每半年重新训练 / 校准阈值），避免过拟合
6. 第 6 步：压力测试与鲁棒性测试
    - 极端行情：暴涨暴跌、流动性枯竭、连续假突破区间
    - 参数敏感性扫描：轻微改动斜率阈值、ADX 阈值、ATR 倍数，观察绩效是否剧烈漂移；参数鲁棒性差说明过拟合
7. 第 7 步：实盘前置模拟
   模拟盘跑至少 3 个月，对比回测与模拟绩效差异，评估滑点、延迟、成交冲击对策略的影响；确认没有明显回测 - 实盘衰减后再小资金实盘

## 补充设计思路摘要（来自前面对话）

>
> 震荡是小范围的快牛快熊，在边界内做反转（到高抛、到低买），突破边界则进入牛熊市。
>
>
> 市场本质：两个机制在交替
>
>
> - 震荡期（均值回归主导）：力量均衡，价格在区间内往复；最优策略：在边界反向操作（到上边卖、到下边买）
> - 趋势期（动量主导）：力量失衡，价格持续单边；最优策略：突破后顺势（突破上边界做多、突破下边界做空）
>
>
> 框架需要补全的三个关键点：
>
>
> 1. 边界不是固定的价格线，是动态的通道（推荐肯特纳通道 ATR 自适应）
> 2. 震荡期在边界反转前，必须先确认 “还在震荡”；加状态确认开关，一旦疑似转趋势，立即停止反转，等突破确认
> 3. 突破有真假；用分步建仓处理假突破，而不是全仓赌突破。
>
>
> 市场三态：趋势牛 / 震荡 / 趋势熊；状态机作为总开关，决定启用哪一套策略。bu
