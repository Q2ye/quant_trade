# 两大事件驱动量化策略
> 信息仅供参考，不构成投资建议。

## 策略一：极端事件归零博弈（恐慌抄底）
### 一、策略定位
|项目|内容|
| ---- | ---- |
|类型|事件驱动 + 恐慌抄底|
|市场|A 股全市场|
|数据要求|日线|
|与主策略的关系|并行运行。正常市场时主策略运行，恐慌信号触发时本策略接管部分 / 全部仓位|
|资金分配|总资金的 20%‑40%（平时现金，信号触发后全仓出击）|
|核心逻辑|市场在极端恐慌时出现系统性折价，买入后等待情绪修复卖出获利|

### 二、策略逻辑
市场恐慌：全市场无差别抛售，好股票也被带崩
买入被错杀的标的
恐慌消退，价格修复
卖出获利

**核心假设**
1. 恐慌是暂时的（A 股历史上每次极端恐慌后都修复）
2. 恐慌时好股票和坏股票一起跌（钟摆式的）
3. 修复的第一波速度最快（情绪驱动的反弹）
4. 大资金（国家队 / 机构）会在极端恐慌后入场托底

### 三、触发条件（三重确认）
**条件 A：全市场恐慌指数突破阈值**
> 恐慌指数 = 全市场跌幅中位数 × 全市场下跌比例
> 全市场跌幅中位数：当日所有 A 股涨跌幅的中位数 (%)
> 全市场下跌比例：当日下跌家数 ÷ 全市场总家数

阈值划分：
- 恐慌指数＞2.0 → 轻度恐慌（关注）
- 恐慌指数＞3.5 → 中度恐慌（准备）
- 恐慌指数＞5.0 → 极度恐慌（出手）

历史参考值大致范围：
- 正常日：恐慌指数 0.1‑0.5
- 调整日：0.5‑1.5
- 恐慌日：1.5‑4.0
- 极端恐慌日：4.0‑8.0（2024 年 1 月、2020 年 2 月）

**条件 B：主要指数处于关键位置**
沪深 300 满足任一：
1. 跌幅较 250 日均线（年线）超过 5%
2. 距离前期低点（近 1 年最低点）＜3%
3. 连续 5 日跌幅累计＞8%

**条件 C：流动性信号**
- 恐慌首日：成交放大（放量下跌，有人在卖，有人在接）
- 恐慌次日：成交萎缩（缩量下跌，抛压衰竭）
- 信号：恐慌次日成交额 ＜ 恐慌日的 80% → 抛压衰竭确认

**完整入场信号**
> 入场信号 = 条件 A (恐慌指数＞阈值) + 条件 B (指数处于低位) + 条件 C (抛压衰竭确认)
> ✅ 三个条件同时满足，触发入场信号

### 四、选股与买入
#### 候选池一：超跌股票
筛选条件：
1. 过去 5 日跌幅＞15%
2. 日均成交额＞500 万（保证流动性）
3. 非 ST
4. 最近一期营收＞5000 万（排除壳、烂公司）
5. 市净率＞0（没有资不抵债）

加分项：
6. 恐慌前 ROE＞5%（曾经是好公司）
7. 有北上资金持仓（机构背书）
8. 属于 “恐慌前热门板块”（说明之前有资金关注）

#### 候选池二：指数 ETF（最稳妥）
直接买入：沪深 300ETF、中证 500ETF、创业板 ETF
> 当你不确定哪个股票会被错杀时，买 ETF 是最稳妥的恐慌抄底方式

#### 候选池三：可转债（替代方案）
条件：价格＜90 元 + 正股无退市风险
> 极端恐慌时可转债会被打到很低价格，保险最高，适合作为替代方案

**买入方式**
- T 日：恐慌指数触发，确认条件 B、C
- T+1 日开盘：买入候选池中的 5‑10 只股票或 ETF

**仓位分配（以总资金 20 万举例）**
- 方案 A（分散）：10 只 ×10% 仓位
- 方案 B（集中）：3‑5 只 ×20‑30% 仓位

买入价格：开盘价买入（或盘中回落时买入）；开盘直接涨停 / 大涨则放弃，抢跑盘太多。

### 五、卖出规则
**止盈（满足任一即卖出）**
1. 持仓盈利达到 15‑20% → 卖一半
2. 持仓盈利达到 30%+ → 清仓
3. 恐慌指数回落至正常水平（＜1.0）→ 清仓
4. 持仓超过 20 个交易日 → 清仓

分批卖出节奏：
- 反弹初期（前 3 日）：持有不动，吃最大的涨幅
- 反弹中段（3‑10 日）：分批止盈
- 反弹末期（10‑20 日）：清仓，不管后面还涨不涨

**止损（满足任一即止损）**
1. 单只股票亏损达到 15% → 止损
2. 买入后 5 日仍亏损 → 审视，考虑止损
3. 指数继续暴跌，恐慌指数再创新高 → 止损或减半仓

> 特殊风险：流动性枯竭，连续跌停无法执行止损。
> 处理方式：持有，等流动性恢复后卖出。这是本策略最大风险，需要心理准备。

### 六、收益预估
历史可回测事件：
- 2020‑02‑03 疫情恐慌：沪深 300 单日‑7.9%，恐慌指数≈7.0，后续 10 日反弹 + 10%~+15%
- 2022‑03 俄乌 + 中概暴跌：恐慌指数 3.0‑4.0，后续反弹 + 8%~+12%
- 2022‑04 上海疫情：沪深 300 到低点，恐慌指数≈4.0，反弹至 7 月 + 15%~+20%
- 2024‑01 微盘流动性危机：恐慌指数≈8.0，2 月反弹微盘 + 30%~+60%

|场景|触发频率|单次收益|成功率|
| ---- | ---- | ---- | ---- |
|小恐慌（指数跌 2‑3%）|每年 2‑3 次|+5%~+10%|65‑70%|
|中恐慌（指数跌 4‑6%）|每年 1‑2 次|+10%~+20%|70‑80%|
|大恐慌（指数跌 7%+）|每 2‑3 年一次|+30%~+60%|80‑90%|

年化贡献预估：
- 平静年份：0‑1 次，年化 0‑10%
- 正常年份：2‑3 次，年化 + 10%~+30%
- 多事年份：4‑5 次，年化 + 30%~+80%
- 极端年份：1‑2 次大机会，年化 + 50%~+100%

### 七、注意事项（风险坑）
|风险点|说明|应对|
| ---- | ---- | ---- |
|假恐慌（持续阴跌）|以为到底，实际只是半山腰|只用恐慌指数 + 抛压衰竭双重确认|
|流动性枯竭|连续跌停卖不出去|分散，不选成交额太小标的|
|抄底遇到退市股|暴跌不修复，直接退市|严格过滤 ST、营收过低、资不抵债标的|
|反弹太弱|涨 3% 又跌回去|设置时间止损 20 日，不恋战|
|和其他策略冲突|主策略在牛市满仓，恐慌来了没钱抄底|留 20‑30% 现金不动|

## 策略二：股指期权集中押注（波动率博弈）
> 期权的非对称性：损失有限（权利金），收益无限；买入期权最多亏掉权利金；方向对了，几倍、几十倍收益。
> 策略本质：用 90% 的耐心等待一次 10 倍以上机会；平时小亏，一次大赚。

### 二、触发条件
**条件 A：波动率处于极低位**
标的：沪深 300 的隐含波动率 IV
获取：东方财富 / Choice / 万得，次月平值期权隐含波动率

判断标准：
- 当前 IV 处于近 3 年 20% 分位以下 → 期权便宜
- 当前 IV＜15% → 非常便宜，可以入手

历史极低 IV 区域：
- 2017：持续 10‑12%（慢牛波动小）
- 2023 年中：跌到 13‑15%（长期横盘）
- 2024‑09 前：IV 跌到 12‑14%（大行情前夜）

> 行情爆发后 IV 飙升到 30‑50%，期权变贵，不适合买入。

**条件 B：技术形态处于变盘前夜（沪深 300 日线）**
1. 布林带：带宽收窄到近 1 年 10% 分位以下，上下轨几乎平行（极度压缩）
2. 均线粘合：5/20/60 日均线距离＜2%，均线几乎粘在一起
3. 成交量：持续萎缩到近 1 年均量以下，缩量‑> 变盘

> 历史信号举例：2024 年 8‑9 月，布林带收窄 + 均线粘合 + 缩量，9 月底爆发。

**条件 C：方向判断（最难部分）**
期权押注需要定方向（看涨 / 看跌）
结合主系统三档状态识别
- 判断即将进入牛市：买入看涨期权
- 判断即将进入熊市：买入看跌期权
- 判断震荡：不操作（方向不明不赌）

动量简单确认
- 沪深 300 向上突破 20 日均线 → 看涨
- 沪深 300 向下跌破 20 日均线 → 看跌
- 在均线附近来回震荡 → 不动

**完整触发条件**
- 选项 1：买入看涨期权
> 条件 A (IV＜15%) + 条件 B (布林带收窄)+ 条件 C 看涨信号

- 选项 2：买入看跌期权
> 条件 A (IV＜15%) + 条件 B (布林带收窄)+ 条件 C 看跌信号

- 选项 3：双买（同时买看涨 + 看跌）
> 条件 A (IV＜12% 极端低位)+ 条件 B 极致压缩 + 条件 C 方向不明
> 逻辑：不知道方向，但确定有大行情；亏一边赚一边，总体期望为正

### 三、仓位与执行
假设资金门槛 50 万，信号触发之后

合约选择：买入次月平值期权（权利金 100‑300 点），或轻度虚值期权（权利金更低、赔率更高）

仓位分配：
- 首次：总资金 20‑30%
- 确认方向盈利 50% 以上：加仓到 50%
- 极端信号：总资金 50‑70%

右尾加仓（押对后放大）：
> 第一笔盈利 100%（期权翻倍），加同等仓位第二笔；继续上涨，浮动盈利覆盖成本；最终做到小亏、一次大赚。

买入时机：收盘前 30 分钟，期权价格稳定，避开盘中剧烈波动。
合约周期：选次月合约，距离到期 30‑45 天；
- 当周合约：时间价值衰减太快，不选
- 季度合约：权利金太贵，杠杆不足

**卖出规则（满足任一）**
1. 盈利达到 200‑500%，卖出一半，剩余持有
2. 盈利达到 1000%，全部清仓
3. 到期前 7 天，无论盈亏清仓（时间价值加速衰减）
4. 方向错判，权利金亏损 70%，止损

### 四、收益预估
|场景|概率|单次收益|备注|
| ---- | ---- | ---- | ---- |
|大行情 + 方向对|10‑20%|+1000%~+6000%|决定全年收益机会|
|小行情 + 方向对|20‑30%|+100%~+400%|常规操作|
|方向不对|30‑40%|-70%~‑100%|投入部分资金亏损|
|横盘至到期|20‑30%|-100%|时间价值归零|

典型场景：
- 场景 A 正常变盘：IV 低位向上突破 10%，买入平值看涨，投入 10 万，收益 + 200%~+400%
- 场景 B 大级别行情：一个月涨 25%+，轻度虚值期权，投入 10 万，收益 + 2000%~+6000%
- 场景 C 方向错：权利金归零，该笔投入亏 100%，但总资金仅亏 20‑30%
- 场景 D 方向对但力度小：指数只波动 3‑5%，期权几乎不涨，小幅亏损‑20~‑40%

> 本部分针对两策略初稿评审发现的缺陷，结合系统实际可复用模块与数据可得性进行完善。
> 核心原则：**可落地性优先** —— 用现有数据/模块能算的指标，不重复造轮子；数据缺失的部分明确标注并给出降级方案。

## 策略一 设计完善：极端事件归零博弈（恐慌抄底）

### 一、复用系统已有能力（避免重复造轮子）

| 需要 | 已有能力 | 复用方式 |
|:--|:--|:--|
| 全市场涨跌分布 | `stock_daily`（5512+ 只/日） | 直接算跌幅中位数、下跌比例 |
| 全市场宽度/情绪 | `market_state_daily`（breadth_ratio、limit_up_count、avg_turnover） | 恐慌指数直接从这些字段派生，**不重复计算** |
| 沪深300 位置 | `index_daily`（已有 repo） | 年线偏离、前低距离、5日跌幅 |
| 成交额（抛压衰竭） | `stock_daily.amount` | 恐慌次日 vs 恐慌日成交额对比 |
| 基本面过滤（ROE/营收） | `stock_daily_basic`（pe/pb/turnover 等） | 过滤烂公司/壳 |

**核心改进**：恐慌指数不新增独立表，基于 `market_state_daily.extra` 扩展字段写入，复用日终流水线。

### 二、恐慌指数公式（明确、可复现）

```
恐慌指数 panic_idx = |全市场跌幅中位数(%)| × (下跌家数 / 总家数)
```

- **跌幅中位数**：当日全市场涨跌幅的中位数（负数时取绝对值）
- **下跌比例**：下跌家数 ÷ 全市场有效家数
- 与 `market_state_daily.breadth_ratio` 的关系：`下跌比例 = 1 - breadth_ratio`（直接复用，不重算）

**阈值分级**（与初稿一致，但明确用可复现口径）：
| 档位 | panic_idx | 动作 |
|:--|:--|:--|
| 正常 | < 0.5 | 不动作 |
| 轻度恐慌 | 1.5-3.0 | 关注（预置候选池） |
| 中度恐慌 | 3.0-5.0 | 准备（确认条件 B） |
| 极度恐慌 | > 5.0 | 出手（三条件全确认） |

### 三、三重确认的独立性修正 + 真恐慌确认（评审修订）

初稿的三个条件实为"同一天系统性下跌"的三次观测，非独立信号。修正为**时间错开的递进确认**：

```
【门控前置】年线门（与主策略哲学一致）
  CSI500 收盘 < MA250 → 熊市 → 【放弃本策略，不抄底】
  解释：熊市中的恐慌多为趋势中继（2018/2022），非错杀；
       本策略只在牛市/震荡市的急跌错杀中出手（2020-02/2024-01 均为牛市暴跌）。

T 日（恐慌日）：条件 A（恐慌指数 > 阈值）✅ 触发
                + 条件 B（沪深300 在年线下 5% 或距前低 3% 或 5日跌 8%）
T+1 日（衰竭日）：条件 C（抛压衰竭：T+1 成交额 < T 日 80%，且恐慌指数未再创新高）
T+2~T+6 日（真恐慌确认）：恐慌指数回落 < 1.5（情绪修复开始），或沪深300 收阳
→ 确认后 T+7 日开盘执行买入
```

**关键改进（评审 3 点）**：
1. **年线门门控**：恐慌抄底仅限牛市/震荡市的急跌错杀，熊市恐慌直接放弃——与主策略"熊市停买"哲学一致，避免重蹈"趋势抄底"覆辙（项目教训：关闭年线门 5 年期 = -53%）
2. **真恐慌确认**：T+1 抛压衰竭只证明"卖压暂歇"，不能证明"这是错杀而非趋势中继"。增加 T+2~T+6 的"恐慌指数回落 <1.5 或指数收阳"确认——**牺牲第一波反弹（约 5-8 个交易日）换确定性**，过滤 2018/2022 式持续阴跌
3. **时间错开**：三重确认跨 7 个交易日，消除同源性问题

### 四、选股质量修正（防"接飞刀"）

初稿"超跌 5 日跌 15%"会选中流动性最差的弱票。增加**质量权重评分**：

```
候选得分 = 超跌分（5日跌幅，越深越高）
          × 质量分（恐慌前 ROE>5% 加 1.5x，营收>1亿 加 1.2x，非ST 必需）
          × 流动性分（日均成交额，>5000万 加 1.5x，>1000万 加 1.2x）
          × 机构分（北向持仓 加 1.3x，【数据存疑】见下）
→ 取 Top 5-10 只，且单票不超总资金 10%
```

**改进点**：
- 质量分权重 > 超跌分：避免"跌最多"= "最烂"的陷阱
- 强制流动性下限：防连续跌停无法止损（初稿已提，这里量化）
- **机构分（北向持仓）数据存疑**：项目暂无北向持仓表。实现时若数据不可得，**机构分降级为"前 20 日成交额放大"或直接去除**（该因子是加分项，非必需）。ROE 来自 `stock_fina_indicators`，营收来自 `financial_income`（表已存在，需确认数据同步）

### 五、卖出规则优化（评审发现：15% 卖半仓过早）

初稿"盈利 15-20% 卖半仓"会错过恐慌修复主升段。修正为**阶梯式让利润奔跑**：

```
止盈（分批）：
  阶段1（反弹 0-3 日）：持有不动，吃第一波最强反弹
  阶段2（盈利 15%）：卖 1/3，锁定部分利润
  阶段3（盈利 30%）：卖 1/3，让剩余奔跑
  阶段4（盈利 50% 或恐慌指数回正常 <1.0）：清仓
  时间兜底：持仓 20 交易日仍未达目标 → 清仓

止损（严格，快速）：
  单票亏损 15%：立即止损（不等 5 日审视）
  指数再创新低（恐慌加深）：减半仓
  流动性枯竭连续跌停：持有等恢复（接受此风险）
```

**改进点**：止盈从"15% 就卖半仓"改为"15%/30%/50% 三档"，保留右尾；止损比初稿更果断（不等 5 日）。

### 六、与主策略的资金切换机制（组合层）

```
组合资金分配（恐慌期）：
  正常市：主策略 100%（进攻满仓）
  恐慌信号触发（中度恐慌确认）：
    → 主策略释放 30-40% 资金（主策略此时大概率已因崩盘止损空仓）
    → 策略一接管 30-40% 资金抄底
  恐慌消退（恐慌指数回 <1.0）：
    → 策略一清仓，资金回归主策略
```

**核心逻辑**：恐慌时主策略（追强）天然空仓止损，策略一正好接棒——**两者是时间互补，不是冲突**。组合 allocator 只需识别恐慌 regime（在 `market_state_daily.regime` 增加 PANIC 档或复用 extra 字段）。

**补充约束（评审修订）**：
- **资金切换仅在"年线门以上 + 真恐慌确认"后发生**——熊市恐慌（趋势中继）不切换，主策略空仓等待（资金闲置可接受，优于抄底被套）
- **策略一与主策略不并发持仓**：策略一接管期间，主策略暂停新买入（防双策略同时押注反向）

### 七、回测验证方案（必做，防"历史事件幸存者偏差"）

用现有日线数据跑 2019-2025 全区间：

**第一步：反例统计（前置，验证三重确认有效性）**
1. 用恐慌指数公式**逐日计算**，标出所有 `panic_idx > 3.0` 的信号日
2. 统计：其中多少后续 20 日上涨（真恐慌）vs 下跌（假恐慌）？
3. **核心指标**：假恐慌占比 = 假恐慌次数 / 总信号次数
   - 若假恐慌占比 > 30% → 三重确认不足，需加强（如延长真恐慌确认窗口）
   - 若加了年线门后假恐慌占比仍高 → 需增加"恐慌性质"判别
4. 同时统计**年线门过滤效果**：全年线以下 vs 以上恐慌信号的后续表现差异

**第二步：全流程回测**
5. 对通过三重确认 + 年线门的信号，执行"T+7 开盘买入 → 规则卖出"全流程
6. 统计：触发次数、胜率、单次收益、最大回撤、年化贡献
7. **重点验证**：2020-02 / 2022-03 / 2022-04 / 2024-01 四次历史事件的实际收益 vs 初稿预估
8. 若某次事件策略亏损（如 2022 中继下跌），记录并修正"恐慌修复"假设
9. **对照实验**：跑"无年线门"版本，对比收益/回撤——验证年线门门控的必要性

## 策略二 设计完善：股指期权集中押注（波动率博弈）

### 一、数据可得性评估（关键前置）

| 需要 | 现状 | 判定 |
|:--|:--|:--|
| 沪深300 隐含波动率 IV | **无数据表、无数据源接入** | ❌ 当前不可落地 |
| 期权合约价格/权利金 | **无** | ❌ |
| 沪深300 日线（条件 B/C） | ✅ index_daily 已有 | ✅ |

**结论**：策略二**当前无法在系统内实现**。需要先解决期权 IV 数据源（如 Choice/Wind 导出、或 Tushare 期权数据）。

### 二、降级方案：波动率 proxy（评审修订：仅作研究，不验证期权策略）

在正式期权数据接入前，用**可计算的历史波动率**验证策略逻辑的可行性：

```
proxy_vol = 沪深300 近20日收益率年化波动率（从 index_daily 计算）
```

- 低波动判定：proxy_vol 处于近 3 年 20% 分位以下
- 变盘前夜判定：布林带收窄 + 均线粘合 + 缩量（用 index_daily 均可算）
- 方向判定：复用 `market_state_classifier` 的 regime（BULL→看涨 / BEAR→看跌）

> ⚠️ **评审结论（2026-08-19）**：proxy 方案的验证价值有限，**不构成期权策略的前置验证**。
> 第一性原理分析：期权收益 = 方向 × IV 变化 × 时间价值衰减。历史波动率（HV）反映过去，隐含波动率（IV）反映市场未来预期（含升贴水、情绪、供需），**HV 无法代理 IV**——即使"变盘时点"判断准确，也无法证明期权策略能赚钱。
> **降级定位**：proxy 仅用于研究"低波动 → 变盘"的市场规律（可选），**不作为期权策略可行性依据**。策略二整体降为远期规划，等真实 IV 数据接入后再评估。

### 三、触发条件的量化完善

| 条件 | 初稿 | 完善（可复现） |
|:--|:--|:--|
| A. IV 极低位 | "20% 分位以下" | proxy_vol < 近3年20分位，或 < 15% |
| B. 变盘前夜 | "布林带收窄+均线粘合+缩量" | 布林带宽 < 近1年10分位；MA5/20/60 极差 < 2%；量 < 近1年均量 |
| C. 方向 | "突破20日线" | 复用 regime：BULL 看涨 / BEAR 看跌 / NEUTRAL 不动（或双买） |

**关键改进**：方向判断不再用"20 日均线穿越"这种易反复的信号，**改用系统已成熟的 regime 判断**（market_state_classifier 的 BULL/BEAR），一致性更高。

### 四、仓位与风控量化（防单次亏光）

```
首次触发：总资金 20%（权利金上限）
方向确认（浮盈 50%）：加仓至 30%
极端信号（A+B 极致 + 双买）：至多 50%

单策略风控：
  单次最大损失：总资金 5%（权利金亏 70% 即止损）
  年最大损失：总资金 15%（连续 3 次止损即暂停，等下一轮低波动）
  到期前 7 天无条件清仓（时间价值加速衰减）
```

**改进点**：明确"单次最大损失 ≤ 总资金 5%"——即使权利金归零，也不伤本金。年亏损 15% 即暂停，防长期低波动磨损。

### 五、收益预估修正（初稿过于乐观）

初稿"+1000%~+6000%"依赖极端行情，概率被高估。修正为**保守分层**：

| 场景 | 概率（修正） | 单次收益 |
|:--|:--|:--|
| 大行情 + 方向对 | 5-10% | +200%~+1000% |
| 小行情 + 方向对 | 15-25% | +50%~+200% |
| 方向不对 | 35-45% | -50%~-100%（权利金） |
| 横盘至到期 | 25-35% | -100%（时间价值归零） |

> 年化贡献预估：保守 5-15%（多数年份），仅在极端行情年份可能 +30%+。**不将其作为主要收益来源**，定位为"尾部对冲 + 低波动期的期权费彩票"。

### 六、落地路径（明确阶段）

```
阶段 1（先行）：策略一（恐慌抄底）——数据齐备，先回测验证
阶段 2（proxy）：策略二用历史波动率 proxy 验证"变盘时点"判断
阶段 3（实盘）：期权 IV 数据接入后，实现真实期权交易
```

## 两策略与系统集成的最终定位

| 维度 | 策略一（恐慌抄底） | 策略二（期权押注） |
|:--|:--|:--|
| 数据 | ✅ 齐备（stock_daily + market_state_daily） | ❌ 缺 IV（需 proxy/接入） |
| 可回测 | ✅ 用现有日线 | ⚠️ 仅能验证时点，不能验证期权收益 |
| 定位 | **熊市尾部对冲**（主策略空仓时接棒） | **低波动彩票**（尾部肥尾，非主收益） |
| 优先级 | **高（先开发）** | 低（等数据） |
| 与主策略 | 时间互补（恐慌↔空仓） | 独立（50万门槛另设资金） |

> **核心结论**：先落地策略一（恐慌抄底），它数据齐备、可回测、与主策略时间互补，是"组合收益最大化"的真实补充。策略二作为远期规划，等期权数据接入后评估。
