## 一、策略研究：从数据到策略

### 1.1 完整链路

```
原始数据               因子              特征              模型              策略
stock_daily      →  factor_data   →  feature_sets  →  LGBMClassifier  →  bottom_strategy.py
etf_daily            74 因子 × ETFs    44 特征集          27 trees           on_bar()
financial_income                                                         _predict()
```

### 1.2 数据→因子：`factor_data` 表

```
数据源: Tushare → etf_daily / stock_daily / financial_income

回填脚本: scripts/backfill_top100_factors.py
           scripts/backfill_decline_factors.py (新增 drawdown_accel/vol_contraction)

核心表: factor_data (超表)
  (ts_code, factor_code, trade_date, factor_value)
  唯一约束: (ts_code, factor_code, trade_date)

因子元数据: factor_definitions
  定义每个因子的名称、类别、计算方式

特征集: feature_sets
  feature_columns: JSONB 数组, 4 个内置集共 74 个因子
```

**实现位置**：
- 回填：`quant_server/scripts/backfill_top100_factors.py`
- 因子计算函数：脚本内嵌（`f_drawdown_20d()`, `f_rsi_14()` 等）
- 因子注册：`docs/sql/seed_factor_definitions.sql` → `factor_definitions` 表
- 特征集注册：`feature_sets` 表，`seed_builtin_templates` 时读入

### 1.3 特征→模型：`training_service.py`

```
文件: modules/strategy/services/training_service.py

TrainingService.run():
  ① load_features()         → 从 factor_data 读 74 因子, 转宽表
  ② load_labels()           → 从 etf_daily 构造标签
       标签逻辑: 未来 10 日最高涨幅≥3% 且 最大跌幅≥-5% → target=1
  ③ 合并 → 缺失值填充 → 标准化 → 训练/验证/测试划分
       训练: ~2024-12-31
       验证: 2025-01~2025-06
       测试: 2025-07~2026-07
  ④ LGBMClassifier.fit()    → 早停 50 轮
  ⑤ 阈值优化                → 网格搜索最佳截止点
  ⑥ joblib.dump(artifact)   → storage/models/etf_bottom_v2_20260726.joblib
       artifact = {model, feature_names, scaler_params, threshold, metadata}
```

**API 入口**：`POST /api/strategy/train/lgb`

## 二、策略执行：从信号到成交

### 2.1 完整链路

```
行情 bar → strategy.on_bar() → TradingSignal → StrategyManager → EventEngine → Broker → 券商
```

### 2.2 信号产生：`strategy_manager.py`

```
文件: modules/strategy/engines/strategy_manager.py

StrategyManager.handle_bar_batch(trade_date, bars):
  for strategy_id in running_states:
      strategy = _strategy_objects[strategy_id]

      for bar in bars:
          sigs = strategy.on_bar(bar)              ← ① 逐 bar 产生信号

      sigs = strategy.on_bar_batch_end(trade_date) ← ② 批次结束信号（低吸轮动用）

      strategy_signals.extend(sigs)

  for sig in strategy_signals:
      if strategy.validate_signal(sig):            ← ③ 基础验证
          valid_signals.append(sig)

  _publish_signals(valid_signals)                 ← ④ 发布到 EventEngine

_publish_signals(signals):
  for sig in signals:
      event = StrategySignalEvent(...)
      event_engine.put(event)                     ← ⑤ 事件总线
```

### 2.3 风控检查：`risk_rules/`

```
文件: modules/risk/rules/ (19 条规则)

流程:
  信号 → _publish_signals() → EventEngine
  → RiskEngine 订阅 StrategySignalEvent
  → check_signal(signal_data) → 遍历 19 条规则
      ├── AccountBalanceRule     : 资金是否充足 (v2.5: Broker 三层防护后关闭)
      ├── PositionLimitRule      : 单仓位上限
      ├── LossLimitRule          : 亏损限制
      ├── ConcentrationRule      : 行业集中度
      └── ... (15 条其他规则)
  → 通过 → 发布 TradeOrderEvent
  → 拦截 → 记录到 risk_events 表 + 日志
```

**实现位置**：`modules/risk/rules/account_rules.py`、`modules/risk/engines/risk_engine.py`

### 2.4 订单执行：`backtest_broker.py`（回测）/ 实盘券商接口

```
文件: modules/backtest/engines/backtest_broker.py

BacktestBroker.submit_order():
  ① _validate_order()           ← L1: 资金校验 (宽松门, 1% 容忍)
  ② 手数取整 (100 股/手)
  ③ 资金检查 + 自动缩减        ← L2: 数量下调
  ④ 冻结资金 (买入) / 提前释放 (卖出)
  ⑤ 创建 BrokerOrder → pending_orders 队列

BacktestBroker.match_orders():
  ① 逐笔撮合昨日挂单
  ② 涨跌停检查
  ③ 确定成交价 (开盘价 + 滑点)
  ④ 资金结算 (缩减或取消)      ← L3: 最终资金校验
  ⑤ _update_position() → 持仓更新
  ⑥ 记录到 trade_history

BacktestBroker.mark_to_market():
  ① 按收盘价重估所有持仓
  ② 计算总资产 + 累计收益率
  ③ 创建 AccountSnapshot → snapshots 列表
```

**实盘路径**：
```
策略 on_bar → TradingSignal
  → StrategyManager._publish_signals()
  → EventEngine → 实盘 Broker 订阅
  → 券商 API 下单
  → 成交回报 → trades 表 + positions 表
```

### 2.5 Sizer：信号→股数

```
文件: modules/backtest/engines/sizer.py

select_sizer(signal):
  signal.weight > 0     → WeightSizer     : shares = weight × cash × 0.995 / price
  signal.direction=CLOSE → CloseAllSizer  : shares = 全部持仓
  signal.half_exit       → HalfCloseSizer : shares = 一半持仓
  signal.quantity > 0    → QuantitySizer  : shares = quantity
```

## 三、数据资产化：从交易到知识

### 3.1 信号→盈亏闭环

```
signals 表 (信号产生时写入)
  ↓
trades 表 (成交时写入)
  ↓ 每日盘后脚本
UPDATE signals SET
  is_executed = true,
  pnl_outcome = (卖出金额 - 买入成本) / 买入成本
WHERE id = matched_signal_id
  ↓
积累 N 条带标签的信号 → 模型重训练的直接原料
```

**涉及表**：
- `signals`：信号产生（`strategy_id, ts_code, direction, confidence, reason`）
- `trades`：成交记录（`ts_code, direction, price, volume, value`）
- `strategy_daily_performance`：每日净值（`daily_return, total_return, max_drawdown`）

**数据流**：
```
on_bar → signal → signals 表
                   ↓
              submit_order → orders 表
                   ↓
              match_orders → trades 表
                   ↓
              _update_position → positions 表
                   ↓
              mark_to_market → strategy_daily_performance 表
```

### 3.2 策略版本溯源

```
strategy_versions 表:
  strategy_id → version_id → code 快照 + parameters 快照 + created_at

回测时:
  backtest_tasks.strategy_version_id → 关联到具体版本

实盘时:
  signals.strategy_version_id → 每个信号都知道是哪个版本的策略产生的

溯源查询:
  任意一笔交易 → 找到产生它的信号 → 找到策略版本 → 找到当时的代码和参数
  → 拿这个版本重新回测 → 对比实盘和回测差异
```

**涉及表**：
- `strategy_versions`：每次保存时创建快照（`strategy_id, code, parameters, created_at`）
- `strategy_parameters`：参数演变（`strategy_id, param_name, param_value`）
- `strategies`：策略实例（`code, class_name, status`）

### 3.3 因子有效性追踪

```
因子在 factor_definitions 注册
  ↓
计算 → factor_data (历史序列)
  ↓
IC 分析 → 每个因子的 IC 均值/标准差/IR
  ↓
分层回测 → 因子分组收益曲线
  ↓
市场状态细分 → 牛/熊/震 市下因子 IC 差异
  ↓
因子淘汰决策：连续 N 期 IC 不显著 → 移出特征集
```

**涉及表**：
- `factor_definitions`：因子元数据
- `factor_data`：因子值时间序列
- `factor_research`：因子研究记录（IC、分层回测结果）

### 3.4 市场状态标签积累

```
market_state_daily 表:
  trade_date | regime | trend_strength | momentum_score | breadth_ratio | volume_ratio

数据来源：market_state_daily (factor_data 中也有)
消费方：ETF 底部策略的 _get_regime() / 低吸轮动的 _calc_csi500_regime()
资产价值：
  每条记录 = 一个交易日的市场状态标签
  积累 2-3 年后 → 训练你自己的 regime 分类器
  精度远超公开的任何市场状态指标
```
