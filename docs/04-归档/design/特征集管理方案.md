# 特征集管理方案

> 版本 v1.0 | 2026-06-27

---

## 一、背景

### 1.1 现状

系统已具备完整的量化因子基础设施：

- **因子数据**：data 模块产出 15+ 种因子，存储在 `stock_factor_daily` 表
- **AI 策略**：`MLStrategy`（XGBoost/随机森林/SVM）和 `DLStrategy`（LSTM/CNN/Transformer）已实现，通过 `feature_columns` 参数接收特征列
- **因子研究**：`FactorDashboard.vue` 支持因子选取、IC 分析、分层回测

但创建 AI 策略时，**特征列必须手动输入**（如 `feature_columns: ["open","high","low","close","macd","rsi"]`），缺少预设模板和界面化选择。

### 1.2 目标

- 支持**特征集的创建、编辑、删除和查看**
- 创建 ML/DL 策略时可**一键引用**特征集，自动填充 `feature_columns`
- 特征集与因子数据**自动校验**（引用的因子必须已存在）
- **前端友好**：选择器预览特征集包含的因子列表

## 二、数据模型

### 2.1 新增表：`feature_sets`

```sql
CREATE TABLE feature_sets (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name            VARCHAR(128) NOT NULL,          -- 特征集名称（唯一）
    description     TEXT,                           -- 描述
    category        VARCHAR(32) DEFAULT 'custom',   -- 分类：momentum/value/volatility/quality/custom
    feature_columns JSONB NOT NULL DEFAULT '[]',    -- 特征列列表 ["macd","rsi","pe","pb"]
    strategy_types  JSONB DEFAULT '["ml","dl"]',    -- 适用的策略类型
    is_public       BOOLEAN DEFAULT TRUE,           -- 是否公开
    created_by      INTEGER REFERENCES sys_users(id),
    created_at      TIMESTAMP DEFAULT NOW(),
    updated_at      TIMESTAMP DEFAULT NOW()
);

CREATE UNIQUE INDEX idx_feature_sets_name ON feature_sets(name);
```

### 2.2 字段说明

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| `name` | VARCHAR(128) | 唯一名称，如 "momentum_basic" |
| `description` | TEXT | 中文描述，如 "基础动量特征集：MACD + RSI + CCI + 3日动量" |
| `category` | VARCHAR(32) | `momentum`(动量) / `value`(价值) / `volatility`(波动) / `quality`(质量) / `volume`(量价) / `custom`(自定义) |
| `feature_columns` | JSONB | 特征列名的 JSON 数组，`["macd","rsi","kdj_k"]` |
| `strategy_types` | JSONB | 适用策略类型，默认 `["ml","dl"]` |
| `is_public` | BOOLEAN | 公开的特征集可供所有用户使用 |

### 3.2 API 端点

| 方法 | 路径 | 功能 |
|:---|:---|:---|
| `GET` | `/quantTrade/strategy/feature-sets` | 获取特征集列表（支持按 category 筛选） |

### 3.4 FeatureSetRepository（关键方法）

```python
class FeatureSetRepository(BaseRepository):
    async def get_by_name(self, name: str) -> Optional[FeatureSet]
    async def get_by_category(self, category: str) -> List[FeatureSet]
    async def get_presets(self) -> List[FeatureSet]           # is_system=True
    async def search(self, keyword: str, category: str) -> List[FeatureSet]
    async def validate_features(self, columns: List[str]) -> Dict[str, Any]
        # 校验 feature_columns 中的列名在可用因子列表中是否存在
```

### 3.5 集成点：创建策略时引用特征集

在 `StrategyService.create_strategy()` 或 `TemplateService.create_from_template()` 中：

```python
# 如果传了 feature_set_id，自动填充 feature_columns
if params.get("feature_set_id"):
    fs = await self.feature_set_repo.get(params["feature_set_id"])
    if fs:
        params["feature_columns"] = fs.feature_columns
```

## 五、数据结构

### 5.1 TypeScript 接口

```typescript
// types/entities-strategy.ts

export interface FeatureSet {
  id: string;
  name: string;
  description: string;
  category: 'momentum' | 'value' | 'volatility' | 'quality' | 'volume' | 'custom';
  feature_columns: string[];
  strategy_types: string[];
  is_public: boolean;
  created_at: string;
  updated_at: string;
}

export interface AvailableFactor {
  name: string;        // "macd"
  label: string;       // "MACD"
  category: string;    // "momentum"
  description: string; // "指数平滑异同移动平均线"
}
```

### 5.2 Vuex Store 扩展

```typescript
// store/modules/strategy.ts 追加

state: {
  featureSets: FeatureSet[],
  availableFactors: AvailableFactor[],
  featureSetsLoading: false,
}

actions: {
  async fetchFeatureSets({ commit }) {
    const data = await strategyAPI.getFeatureSets();
    commit('SET_FEATURE_SETS', data);
  },
  async fetchAvailableFactors({ commit }) {
    const data = await strategyAPI.getAvailableFactors();
    commit('SET_AVAILABLE_FACTORS', data);
  },
  async createFeatureSet({ dispatch }, params) {
    await strategyAPI.createFeatureSet(params);
    await dispatch('fetchFeatureSets');
  },
  async updateFeatureSet({ dispatch }, { id, params }) {
    await strategyAPI.updateFeatureSet(id, params);
    await dispatch('fetchFeatureSets');
  },
  async deleteFeatureSet({ dispatch }, id) {
    await strategyAPI.deleteFeatureSet(id);
    await dispatch('fetchFeatureSets');
  },
}
```

## 八、验证方案

| 验证项 | 方法 |
|:---|:---|
| 特征集 CRUD | API: POST 创建 → GET 列表确认 → PUT 修改 → DELETE 删除 → 列表确认已移除 |
| 因子校验 | POST 创建含不存在因子 → 返回 422 + 错误因子名 |
| 前端选择器 | 创建 ML 策略 → 选择"动量基础"特征集 → feature_columns 自动填充 → 确认因子列表正确 |
| 预设数据 | 系统启动后，GET presets 返回 4 个默认特征集 |
