# 策略列表页面重构设计方案

> 2026-08-10 | 前端页面改造 | 涉及 `quant_web/src/views/StrategyCenter/Build/StrategyList.vue`
> 关联：方案 B（策略淘汰机制）· 策略生命周期管理

---

## 1. 背景与目标

### 1.1 现状问题

| 问题 | 说明 |
|:---|:---|
| **全部 Tab 混杂** | 当前 5 个 Tab（全部/草稿/已验证/运行中/已停止），"全部"混合展示草稿+运行中+已停止，策略多时难区分 |
| **模板库位置不佳** | 模板库只在"全部"Tab 显示，与草稿策略混杂，语义不符（模板=起点，应独立引导） |
| **版本管理缺失** | 同一策略多版本（如 HighVolMomentumStrategy-5.0/7.0/7.1）平铺展示，无法快速识别最新版与历史版 |
| **淘汰策略无归处** | 方案 B 引入 retired 状态后，需要明确"已归档"展示区 |

### 1.2 目标

1. 精简 Tab 结构（5 → 4），取消"全部"，明确"已归档"归类
2. 模板库移到"草稿"Tab（语义匹配：模板 = 新策略起点）
3. 同策略多版本按类名分组，突出最新版本
4. 默认选中"草稿"Tab（新建策略的落点）

## 4. Tab 结构设计

### 4.1 Tab 栏（4 个）

```
┌───────────────────────────────────────────────────────┐
│  策略构建                                          ⟳ │
│  📝草稿(3)   ✅已验证(2)   🟢运行中(1)   📦已归档(5)   │
└───────────────────────────────────────────────────────┘
```

| Tab | 过滤条件 | 模板库 | 说明 |
|:---|:---|:---|:---|
| **📝 草稿**（默认） | `status=draft` | ✅ 顶部独立区 | 新策略起点 + 模板引导 |
| **✅ 已验证** | `status=backtested` | ❌ | 回测通过，可启动实盘 |
| **🟢 运行中** | `status=running` + `paused` | ❌ | 实盘/仿真运行中 |
| **📦 已归档** | `status=stopped` + `retired` | ❌ | 停止/淘汰，只读 |

### 4.2 Tab 统计数字

每个 Tab 显示数量（沿用现有 `statusCounts`，扩展 archived 聚合）：
```ts
statusCounts = {
  draft, backtested, running, paused, stopped, error,
  archived: stopped + retired   // 新增聚合
}
```

## 6. 版本分组设计

### 6.1 分组依据

按 **`class_name`（策略类名）** 分组：
- 同一 `class_name` 的策略实例视为"同一策略的不同版本"
- 例：`HighVolMomentumStrategy` 下的 v5.0/v7.0/v7.1

### 6.2 组结构

```
高波动动量轮动  (3)                    ← 组标题（策略中文名）+ 版本数
  ┌─────────────────────────────────────┐
  │ v7.1  🆕最新  📝草稿  行业轮动  [编辑]  │
  │ v7.0         📝草稿  行业轮动  [编辑]  │
  │ v5.0         ✅已验证 行业轮动  [回测]  │
  └─────────────────────────────────────┘
```

### 6.3 分组逻辑（前端 computed）

```ts
// 按 class_name 分组
groupByClass(strategies) {
  const groups = {};
  for (const s of strategies) {
    const key = s.className || s.class_name || '未分类';
    (groups[key] = groups[key] || []).push(s);
  }
  // 组内按版本号排序（最新在前）
  for (const key in groups) {
    groups[key].sort((a, b) => (versionNum(b) - versionNum(a)));
  }
  return groups;
}

// 从名称提取版本号：HighVolMomentumStrategy-7.1 → 7.1
versionNum(s) {
  const m = (s.name || '').match(/[-_]v?(\d+(?:\.\d+)*)/i);
  return m ? parseFloat(m[1]) : 0;
}
```

### 6.4 最新版识别

优先级：**`created_at` 最大**（最可靠），版本号作为排序补充。

```ts
isLatest(group) {
  // 组内 created_at 最大的为最新版
  return group.reduce((a, b) =>
    new Date(b.created_at) > new Date(a.created_at) ? b : a
  );
}
```

### 6.5 渲染结构（完整）

```
┌───────────────────────────────────────────────────────┐
│ ▸ 高波动动量轮动  (3)   [组标题+数量+折叠]              │
│ ┌─────────────────────────────────────────────────┐  │
│ │  ┌────────────────┐                            │  │
│ │  │ v7.1  🆕最新     │   ← 最新版带徽标，默认高亮     │  │
│ │  │ 📝草稿 行业轮动   │                            │  │
│ │  │ [编辑][回测]     │                            │  │
│ │  └────────────────┘                            │  │
│ │  ┌────────────────┐                            │  │
│ │  │ v7.0  📝草稿     │   ← 历史版                    │  │
│ │  │ [编辑]          │                            │  │
│ │  └────────────────┘                            │  │
│ │  ┌────────────────┐                            │  │
│ │  │ v5.0  ✅已验证    │   ← 历史版（不同状态）          │  │
│ │  │ [回测][启动实盘]  │                            │  │
│ │  └────────────────┘                            │  │
│ └─────────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────────┘
```

### 6.6 版本徽标规则

| 徽标 | 显示条件 |
|:---|:---|
| `🆕最新` | 组内 `created_at` 最大的实例 |
| 版本号（v7.1） | 从名称提取，显示在卡片名旁 |
| 状态标签 | 沿用现有（草稿/已验证/运行中） |

### 6.7 交互

- 组标题可点击折叠（默认展开）
- 组内卡片保留原有操作按钮（编辑/回测/启动实盘等）
- 点击卡片进入工作区（`/strategies/workspace/{id}`），不变

### 6.8 边界情况

| 场景 | 处理 |
|:---|:---|
| 无 `class_name` | 归入"未分类"组 |
| 无版本号 | 按 `created_at` 排序 |
| 同版本号不同实例 | 按 `created_at` 区分最新 |
| 单版本策略 | 不分组，直接平铺卡片（无组标题） |

## 7. 已归档 Tab 设计

### 7.1 显示内容

- `status=stopped` + 未来 `retired` 的策略
- **只读**：不提供"启动实盘"，保留"编辑/回测/查看日志"
- 版本分组同样适用

### 7.2 与方案 B 的衔接

方案 B 引入 `retired`（淘汰）状态后：
- `retired` 并入"已归档"Tab
- 已归档 Tab 区分"已停止"（可恢复）与"已淘汰"（终态只读）徽标
- 数据全保留（不删行），仅状态标记

## 10. 实施计划（四层）

### 第 1 层：常量与状态映射（strategyMeta.ts）

- 新增 `groupByClass()`：按 `class_name` 分组 + 最新版判断
