## 二、《主动投资组合管理》核心框架

### 2.1 七条量化真知

1. **主动管理即预测** — 一致预期导致基准组合，差异来自你的预测
2. **信息率（IR）是决定附加值的关键因素** — IR 是信息质量的综合度量
3. **主动管理基本定律** — `IR ≈ IC × √BR`
4. **阿尔法公式** — `Alpha = Volatility × IC × Score`
5. **避免数据挖掘** — 容易陷入，需要结构化流程避免
6. **组合实施应尽量减少附加值的损失** — 交易成本可以吃掉大部分 alpha
7. **区分能力和运气很难** — 需要足够的样本量

### 2.2 CAPM 与一致预期收益率

**核心思想**：
- 任何股票收益率 = 系统性（市场）部分 + 残差部分
- CAPM 要求残差收益率的期望值为零
- 一致预期收益率是主动管理的比较基准——主动管理决策由"你的预测与一致预期的差异"驱动
- CAPM 将举证责任归于主动投资经理：你必须证明自己不是"更傻的傻瓜"

**主动管理推论**：
- 残差收益率的一致预期为零 → 方便的研究起点
- 无需预测市场方向（μ_M），集中精力于残差收益率预测
- 贝塔中性策略避免承担不需要的市场风险

### 2.3 风险：定义与模型

**风险定义**：收益率的标准差（波动率）

关键性质：
- 风险不具有可加性——组合风险 < 各资产风险的加权平均（分散化）
- 主动风险 ≈ ψ_P = Std{r_P - r_B}
- 风险成本与方差成正比：`Cost = λ × ψ²`

**三类风险赌注**：
- **固有风险**：基准本身的风险，无法避免
- **意向风险**：主动经理有意承担的、有信息优势的赌注
- **意外风险**：构建过程中的副产品——最常见的 alpha 杀手

**结构化风险模型**：`r = X·b + u`
- 三大因子类别：对外部变化的响应、横截面比较、统计因子
- 因子三维评判标准：有区分力、直观、有意义
- 典型风险指数：波动率、动能、规模、流动性、成长性、价值、盈利波动率、财务杠杆

### 2.4 信息率（IR）— 核心 KPI

**定义**：`IR = α / ω`
- α = 年化主动收益率
- ω = 年化残差风险

IR 决定了主动管理的机会集：
- IR > 1.0 → 前 10% 的基金经理
- IR > 0.5 → 良好
- IR < 0 → 负附加值

**附加值与 IR 的关系**：`VA = IR² / (4λ)`（λ 为风险厌恶系数）

### 2.5 主动管理基本定律 🔴 最重要

```
IR ≈ IC × √BR
VA ∝ IC² × BR
```

| 符号 | 名称 | 含义 | 典型值 |
|:---|:---|:---|:---|
| IR | 信息率 | 风险调整后的超额收益质量 | 0.5~1.0 |
| IC | 信息系数 | 预测值与实现值的相关系数 | 0.02~0.10 |
| BR | 广度 | 每年独立预测的次数 | 100~1000 |

**核心推论**：

1. **广度与能力的权衡**：
   ```
   提高 IC 50%（同时保持 BR）→ IR 提高 50%
   提高 BR 50%（同时保持 IC）→ IR 提高 22%
   所以：提高 IC 的 ROE 更高，但难度也更大
   ```

2. **只需微弱的优势**：
   - IC = 0.0577 → 方向正确率仅需 52.885%
   - IC = 0.02 + BR = 800（200股×季度） → IR = 0.56（已超过多数基金经理）

3. **可加性**：`IR²_total = IR²_1 + IR²_2 + ...`
   - 多信息源 → 信息率平方相加
   - 多经理 → 最优配置下信息率平方相加

4. **强假设**：
   - 各预测之间独立（相关性会降低附加值）
   - 每个预测的 IC 相同
   - 经理能精确衡量能力并最优利用信息

### 2.6 阿尔法预测基本定律

```
Alpha = Volatility × IC × Score
```

其中 Score 是标准化分值的 z-score（均值=0，标准差=1）。

**信息处理流程**：
1. 原始信号 → 标准化为分值（z-score）
2. 分值 × IC → 原始预测
3. 原始预测 × 波动率 → 阿尔法（精炼预测）

**关键性质**：
- "垃圾进，垃圾出"——如果 IC=0，无论信号多强，输出 Alpha=0
- 无需精确预测——IC=0.02 的策略已经有效
- 只需方向正确，不需要幅度精确

### 2.7 组合构建原则

- 阿尔法 → 风险调整 → 最优头寸
- 实现值 = 预期 α - λ×ω²（风险惩罚）
- 交易成本直接影响净收益
- 市场冲击是机构投资者的主要交易成本

## 三、《量化投资策略：如何实现超额收益Alpha》实证体系

### 3.1 研究方法论

| 特性 | 描述 |
|:---|:---|
| 数据库 | 标普 Compustat Point in Time（1987-2006，20年） |
| 样本 | 约 2200 只美股，市值 > 5亿美元 |
| 测试方式 | 五等分法（按因子值排序，分5组） |
| 持有期 | 12个月 |
| 可靠性增强 | 年度+季度两种频率交叉验证 |
| 偏差控制 | Point-in-Time 数据库避免预测偏差、生存偏差、重述偏差 |

**有效策略的五个评判标准**：
1. 最高分位显著跑赢基准（超额 > 2% 单因子 / > 4% 双因子）
2. 最低分位显著跑输基准（同样量级）
3. 分位与超额收益呈线性关系
4. 1年战胜率 > 60%，3年滚动战胜率 > 70%
5. 低波动、低最大回撤

### 3.2 七大因子体系总览

```
投资马赛克 = 7 个维度 × N 个组件策略

┌────────────┬──────────────────────────────────────┬──────────┐
│  因子大类   │  核心度量                             │  有效性  │
├────────────┼──────────────────────────────────────┼──────────┤
│ 盈利性      │ ROIC, 经济利润, EBITDA-Capex/IC      │ ⭐⭐⭐⭐  │
│ 估值        │ FCF/Price, EV/EBITDA, P/E(当年预测)   │ ⭐⭐⭐⭐⭐ │
│ 现金流      │ FCF/营收, 现金ROIC, FCF增长           │ ⭐⭐⭐⭐  │
│ 成长性      │ FCF增长+稳定性, GARP组合              │ ⭐⭐⭐    │
│ 资产配置    │ 股份减少, 债务清偿, 外部融资(-)        │ ⭐⭐⭐⭐  │
│ 价格动量    │ 7月相对强弱, 52周价格区间              │ ⭐⭐⭐⭐  │
│ 危险信号    │ 债务回报率, 资本密集度, 折旧政策       │ ⭐⭐⭐    │
└────────────┴──────────────────────────────────────┴──────────┘
```

### 3.3 各因子详细发现

#### （1）盈利性 — 商业价值的根本

**最强单因子**：投入资本回报率（ROIC）

| 策略 | 最高分位超额 | 1年胜率 | 3年胜率 | 关键特性 |
|:---|:---|:---|:---|:---|
| ROIC 单因子 | +2.3% | 69% | 78% | 跨行业有效，熊市更有效 |
| ROIC + 市销率 | +5.9% | 70% | 83% | 盈利性+估值，强强联合 |
| ROIC + 现金ROIC | +8.4% | 78% | 89% | 双报表交叉验证 |
| 经济利润（现金版+PS估值） | +9.3% | 78% | 95% | 理论最优，实际最强 |

**核心结论**：
- ROE 有效，ROA **无效**（总资产不是投资者贡献资源的恰当度量）
- EBITDA - Capex 比投入资本：比 ROIC 更简单且更有效
- 盈利性 × 估值 = 最强的组合策略类型

#### （2）估值 — 最强的单因子大类

| 策略 | 最高分位超额 | 特征 |
|:---|:---|:---|
| **FCF/Price** | ⭐最强 | 结合现金流+估值，跨行业稳定 |
| **EV/EBITDA** | ⭐最强 | 考虑债务，比P/E更全面 |
| P/E（当年预测） | 中等 | 比历史P/E有效，因为包含前瞻信息 |
| 市销率（P/S） | 中等 | 对无盈利公司有用 |
| 市净率（P/B） | 中等 | 效果弱于前两者 |
| 股息率 | **无效** | 高股息公司常伴随股息削减风险 |
| PEG（P/E ÷ 增长率） | **无效** | 增长率预测不可靠 |

**核心结论**：
- FCF/Price 和 EV/EBITDA 绑定几乎所有好策略
- 估值 × 动量 = 特别强大的组合（便宜 + 有人开始买）
- 估值 × 成长性 = GARP（Growth At Reasonable Price）框架

#### （3）现金流 — 盈利质量的验证

**关键发现**：
- FCF 策略在 1989-2002 极强，2002 年后预测力下降（市场逐渐吸收此信息）
- 通过结合估值因子，FCF 策略衰退被有效弥补
- FCF/营业收入：衡量损益表盈利质量——比值越低，盈利越可疑
- 负 FCF + 高资本支出：显著跑输，应做空
- 负 FCF + 大量股份发行：极大的负超额收益

**FCF增长的预测性**：
- 与 EPS 增长不同，FCF 增长**对未来的超额收益有预测性**
- 原因：市场对 FCF 吸收不如 EPS 有效（信息传播慢）

#### （4）成长性 — 增长的质量比速度重要

| 发现 | 细节 |
|:---|:---|
| EPS 增长 **不具预测性** | 市场快速吸收；高增长难以为继 |
| FCF 增长 **具有预测性** | 市场吸收较慢 |
| 增长稳定性 ≥ 增长速率 | 稳健的15%增长 > 波动的40%增长 |
| 资本支出高增长 | 应**避免**——常在错误时点扩张 |
| GARP 策略 | 成长性 × 估值 → 最强成长类组合 |

**成长得分（Growth Score）**方法：结合 FCF 增长水平 + 增长的线性度（稳定性）→ 效果远超纯增长速率。

#### （5）资产配置 — 管理层是否考虑股东

| 策略 | 方向 | 效果 |
|:---|:---|:---|
| 股份减少（回购） | 做多 | 跨行业有效，+估值组合极强 |
| 股份增加（发行） | 做空/避开 | 显著跑输 |
| 债务减少 | 做多 | 有效，跨行业 |
| 债务增加 | 避开 | 财务风险增加 |
| 外部融资（=股份+债务发行） | 做空 | 高估值+大量融资 = 大幅下跌 |
| 大型现金收购 | 避开 | 普遍表现不佳（并购溢价） |

**核心发现**：资产配置策略 = 质量保证。公司如何处理盈余现金（回购 vs 发行，偿债 vs 借债），是预测未来收益的可靠信号。

#### （6）价格动量 — 投资者情绪的量化

| 周期 | 方向 | 最优参数 |
|:---|:---|:---|
| 短期动量 | 延续 | **7个月**相对强弱最优；12个月也有效 |
| 长期反转 | 反转 | 36个月最强组跑输；88个月最弱组跑赢 |
| 52周价格区间 | 延续 | **比RS更强**——接近高点→继续涨，接近低点→继续跌 |

**52周价格区间策略**是单因子中效果最强的动量指标：
```
高位得分 = (当前价 - 52周最低) / (52周最高 - 52周最低)
→ 得分高（接近高点）= 继续跑赢
→ 得分低（接近低点）= 继续跑输
```

**动量因子组合**：
- 动量 × 估值 → 最强大的双因子策略类型之一
- 动量 × 盈利性 → 强趋势 + 强基本面
- 动量 × 外部融资（负）→ 极端回报（双向）

#### （7）危险信号 — 降低风险的因子

| 有效因子 | 无效因子（出乎意料） |
|:---|:---|
| 债务回报率（总债务/EBITDA） | 财务杠杆（债务/总资本）— **无效！** |
| 经营性现金流/长期债务 | 高负债公司短期内反而跑赢 |
| Capex/PP&E（资本密集度） | 低现金余额公司战胜高现金余额公司 |
| 营运资金效率（存货+应收周转变化） | |
| 折旧/投入资本（会计保守度） | |

**关键反直觉发现**：高财务杠杆公司在短期内战胜低杠杆公司。市场在短期奖励承担风险的激进财务策略，但这不代表长期有效。

### 3.4 因子组合的效率

**最强双因子组合类型**（按超额收益排序）：

1. 盈利性 × 估值 （如 ROIC × FCF/Price）
2. 动量 × 估值 （如 52周区间 × EV/EBITDA）
3. 现金流 × 估值 （如 FCF/营收 × P/E）
4. 成长性 × 估值 （GARP：FCF增长 × EV/EBITDA）
5. 资产配置 × 估值 （股份减少 × 低估值）
6. 动量 × 盈利性 （7月RS × ROIC）

**组合方法**：串行筛选而非并行打分
- 先用第一因子选出 Top 20% → 再用第二因子从这 20% 中选出新的 Top 20%
- 结果：选股范围缩小到 4%，组合更集中、超额更高
- 强调第一因子的主导地位（类似 L1/L2 优先级）

### 3.5 三大投资基本问题（Tortoriello框架）

```
问题 1: 公司做得好吗？
  → 盈利性（ROIC、经济利润）
  → 现金流（FCF、现金ROIC）
  → 成长性（FCF增长的水平和稳定性）
  → 资产配置（回购/发行、偿债/举债）

问题 2: 估值有吸引力吗？
  → FCF/Price、EV/EBITDA、P/E
  → GARP：成长与价值的平衡

问题 3: 买入时机对吗？
  → 价格动量（7月RS、52周区间）
  → 市场整体趋势（MA20/MA60等）
  → 行业/个股供需趋势
```

## 四、两书对行业轮动策略 V2 的映射与启示

### 4.1 与主动管理基本定律的对照

当前 V2 策略的参数映射：

```
BR（广度）= 31个行业 × 约25次/年调仓（5天频率）≈ 775
  ↑ 但注意：预测不是独立的！同一套8因子体系同时用于所有行业

IR 目标值 = ？
  若期望年化超额 10%，主动风险 10%，则 IR = 1.0
  基础定律: 若 BR ≈ 30（月频独立行业预测），则需要 IC ≈ 0.18
  IC = 0.18 在行业层面是极高要求（业界最佳 IC ≈ 0.05-0.10）
```

**启示**：
- 当前调仓频率（5天）看似提高了广度，但预测非独立 → 广度假高
- 应更关注**提高 IC**（改善因子质量），而非堆砌伪广度
- 月度调仓（BR≈30，但每个预测更独立）可能更接近真实有效广度

### 4.2 因子有效性与 V2 因子权重

| V2 因子 | Tortoriello 对应因子 | 实证有效性 | V2 当前权重 | 建议权重 |
|:---|:---|:---|:---|:---|
| A1（多窗口动量） | 相对强弱（7月最优） | ⭐⭐⭐⭐ | 25%（趋势大类） | 应为主要因子 |
| A2（动量加速度） | — | 无直接对应 | |
| A3（相对强弱vs基准） | — | 无直接对应 | |
| B1（量比） | —（量价结合） | 有支持 | 30% | 15-20% |
| B2（价量配合） | — | 有支持 | |
| B3（换手加速度） | — | 弱 | |
| **C1（PE分位）** | PE比率 | ⭐⭐⭐ | **45%（估值大类！）** | 15-20% |
| C2（PB分位） | 市净率 | ⭐⭐ | |
| C3（估值扩张） | — | 无实证支持 | |

**最关键的发现**（来自 Tortoriello 实证）：
> P/E 比率在行业配置层面 IC 仅 2.47%，远弱于动量因子（IC 3-5%）。估值因子中最强的是 **FCF/Price** 和 **EV/EBITDA**，而 V2 完全没有这两个因子！

**缺失的关键因子**（Tortoriello 体系中最强但 V2 没有的）：
- ❌ FCF/Price（最强的估值因子）
- ❌ EV/EBITDA（第二强）
- ❌ ROIC 或经济利润（最强的盈利性因子）
- ❌ 股份减少/外部融资（资产配置因子）
- ❌ 52周价格区间（比RS更强的动量信号）

### 4.3 阿尔法精炼流程对标

G&K 的"信息处理流程"与当前 V2 的对比：

```
G&K 流程：
原始信号 → 标准化(z-score) → ×IC → ×Volatility → Alpha

V2 流程：
原始值 → 横截面 z-score → sigmoid归一化 → 大类加权 → 综合得分
                                          ↑
                                     缺少 IC 校准步骤！
```

**缺失环节**：V2 跳过了 IC 校准——每个子因子的预测能力没有被量化。G&K 的 Alpha = Volatility × IC × Score 公式要求：如果某个子因子的 IC=0，它就不应该对最终得分有贡献。而 V2 通过固定权重强制所有因子参与打分，包括 IC 可能为负的因子。

### 4.4 风险模型对标

G&K 定义了三种风险赌注，V2 中的对应：

| 风险类型 | V2 对应 | 建议 |
|:---|:---|:---|
| 固有风险 | 行业 ETF 本身的 beta 暴露 | 无法避免，但可通过熊市防御控制 |
| 意向风险 | Top 5 行业选择（赌行业分化） | 应占总风险的 70%+ |
| 意外风险 | 同一 ETF 对应多行业（假分散）、板块集中 | **需要识别并消除** |

## 五、整合：为 V2 优化的理论指南

### 5.1 理论框架 → 实践检查清单

```
□ 每个因子是否通过了"IC 显著性"检验？（G&K 第10章）
□ 因子之间是否独立？（G&K 第6章 — 可加性要求）
□ 估值因子权重是否与其实证 IC 匹配？（Tortoriello 第5章）
□ 是否使用了最强的估值因子（FCF/Price > P/E）？
□ 是否有盈利性因子（ROIC/经济利润）作为补充维度？
□ 动量周期是否匹配市场特征？（7月RS > 1月RS）
□ 调仓频率是否产生真正的独立预测？（BR 不应虚高）
□ 组合构建是否最小化了意外风险？（G&K 第3章）
□ 交易成本是否建模并计入？（G&K 第16章）
□ 是否有业绩归因来区分 IC 和运气？（G&K 第17章）
```

### 5.2 因子优先级重构（基于两书综合）

```
第一梯队（必须有，实证 IC 最高）：
  1. 价格动量 — 7月RS / 52周区间（Tortoriello ⭐⭐⭐⭐, 行业IC 3-5%）
  2. 估值 — FCF/Price / EV/EBITDA（Tortoriello ⭐⭐⭐⭐⭐, 行业IC 2.5%）
  3. 盈利性 — ROIC / 经济利润（Tortoriello ⭐⭐⭐⭐, 行业IC 3.75%）

第二梯队（强力增强）：
  4. 现金流 — FCF增长稳定性（Tortoriello ⭐⭐⭐⭐）
  5. 资产配置 — 股份回购/外部融资（Tortoriello ⭐⭐⭐⭐）
  6. 成长性 — GARP 框架（Tortoriello ⭐⭐⭐）

第三梯队（辅助）：
  7. 量价配合 — 资金流向确认
  8. 危险信号 — 资本密集度、折旧政策
```

### 5.3 核心公式速查

```
主动管理基本定律:
  IR ≈ IC × √BR
  VA ∝ IC² × BR

阿尔法精炼:
  Alpha = Volatility × IC × Score

信息率分解:
  IR²_total = Σ IR²_i  (可加性)

最优主动风险:
  ω* = IC × √BR / (2λ)

风险成本:
  Cost = λ × ψ²

方向正确率与IC:
  IC = 2 × (正确率 - 50%)
  如：正确率=52.885% → IC=0.0577

有效广度估计:
  BR = N_stocks × frequency  （理想独立情形）
  BR_effective < BR_nominal  （考虑相关性后）
```
