## 二、策略创建与注册流程

### 2.1 组件参与

| 组件 | 作用 |
|------|------|
| `StrategyEditor.vue` | 前端 Monaco 编辑器，用户编写策略代码 |
| `StrategyList.vue` | 策略列表，展示已创建策略 + 筛选/批量操作 |
| `StrategyService` | 后端 CRUD 服务，策略持久化到 strategy 表 |
| `StrategyRegistry` | **单例**，策略类注册表，映射 StrategyType → List[BaseStrategy] |
| `StrategyManager` | 引擎，策略生命周期管理（load/start/stop/pause/resume） |

### 2.2 注册路径（两条）

#### 路径 A：自动发现（应用启动时）

```
应用启动 → StrategyManager._on_initialize()
    → StrategyRegistry.auto_discover("modules.strategy.strategies")
        → importlib.import_module("modules.strategy.strategies.technical")
        → inspect.getmembers(module, isclass)
        → 过滤 BaseStrategy 子类
        → 推断 StrategyType（类名关键字 / 类属性 / 包默认值）
        → registry.register(type, class)
    
    扫描结果:
      technical/ → MACDStrategy, MACrossStrategy  → StrategyType.TECHNICAL
      alpha/     → FactorStrategy, MeanReversionStrategy
      ai/        → MLStrategy, DLStrategy (需 PyTorch)
```

#### 路径 B：用户创建（前端操作）

```
用户: 打开 /strategies/create → 编写代码 → 点击 [保存]
    → strategyStudio.saveStrategy()
    → POST /quantTrade/strategies {name, code, parameters}
    → StrategyService.create_strategy()
    → INSERT INTO strategy (...)
    → 返回 strategy_id

用户: 点击 [启动]
    → POST /quantTrade/strategy/{id}/start
    → StrategyManager.start_strategy(id, context)
        → StrategyContextBuilder.inject_callbacks(context)
        → strategy.initialize() → strategy.start()
        → 状态: DRAFT → RUNNING
```

### 3.2 关键决策点

| 决策点 | 位置 | 逻辑 |
|--------|------|------|
| **复权选择** | DataFeedEngine | 默认前复权(qfq)，优先读 `stock_adjusted_prices`，空则回退 `stock_daily` |
| **停牌处理** | DataFeedEngine.iter_bars() | 停牌日该股票无 bar → 自动跳过，不报错 |
| **T+1 制度** | BacktestBroker.match_orders() | 当日买入，`available_quantity = 0`，次日才可卖 |
| **涨跌停** | BacktestBroker._can_trade() | 主板 ±10%，科创板(688) ±20%，ST ±5% |
| **费用计算** | BacktestBroker | 佣金 ≥ 5 元，印花税 0.1%(仅卖出)，过户费 0.002% |
| **滑点** | BacktestBroker.match_orders() | 买入向上滑动(×1.001)，卖出向下滑动(×0.999) |
| **手数取整** | BacktestBroker.submit_order() | `quantity // 100 * 100`，不足 1 手拒绝 |

## 四、信号处理流程

### 4.1 信号链路

```
Strategy.on_bar(bar)
    │
    ▼
TradingSignal (id, ts_code, direction, price, quantity, confidence, reason)
    │
    ▼
StrategyManager.handle_bar_batch(trade_date, bars)
    │
    ├─→ state.pending_signals.extend(signals)        # 内存记录
    │
    └─→ StrategyManager._publish_signals(strategy_id, signals)
            │
            ▼
        StrategySignalEvent(data={...})
            │
            ▼
        EventEngine.put(event)
            │
            ├─→ SignalEngine._persist_signal()        # 持久化
            │       │
            │       ▼
            │   SignalRepository.create() → INSERT INTO signals
            │       │
            │       ▼
            │   signals 超表 (strategy_id, ts_code, signal_type,
            │                direction, price, confidence, signal_time)
            │
            └─→ WebSocketManager.broadcast("signal", event_data)
                    │
                    ▼
                SignalMonitor.vue (实时信号面板)
```

### 4.2 信号类型

| SignalType | 含义 | 触发场景 |
|------------|------|----------|
| `ENTRY` | 入场信号 | 金叉、因子打分 > 阈值、价格突破布林下轨 |
| `EXIT` | 离场信号 | 死叉、因子打分 < 阈值、价格回归均线 |
| `STOP_LOSS` | 止损 | 亏损 ≥ 5%（默认） |
| `TAKE_PROFIT` | 止盈 | 盈利 ≥ 15%（默认） |
| `REBALANCE` | 重平衡 | FactorStrategy 每 20 根 bar 触发 |

| SignalDirection | 含义 |
|-----------------|------|
| `LONG` | 买入开多 |
| `SHORT` | 卖出开空 |
| `CLOSE_LONG` | 卖出平多 |
| `CLOSE_SHORT` | 买入平空 |

## 五、回测结果计算

### 5.1 指标来源

```
BacktestBroker.get_equity_curve() → DataFrame
    │
    ├─→ total_return    = (final_assets - initial) / initial
    ├─→ annual_return   = (1 + total_return) ^ (365/days) - 1
    ├─→ sharpe_ratio    = mean(daily_returns) / std(daily_returns) × √252
    ├─→ max_drawdown    = max(equity_df["max_drawdown"]) from mark_to_market snapshots
    └─→ volatility      = std(daily_returns)

BacktestBroker.get_trade_list() → List[{trade_id, ts_code, direction, price, quantity, ...}]
    │
    ├─→ num_trades      = len(trades)
    ├─→ win_rate        = count(profitable_trades) / total_trades
    ├─→ profit_factor   = gross_profit / |gross_loss|
    └─→ avg_trade_return = mean(trade_pnls)
```

### 5.2 每日快照计算

```
BacktestBroker.mark_to_market(bars):
    for each position:
        current_price = bar.close
        market_value  = quantity × current_price
        pnl           = (current_price - avg_cost) × quantity
        pnl_rate      = (current_price - avg_cost) / avg_cost

    total_assets = cash + frozen_cash + Σ(market_value)
    
    回撤计算:
    current_peak   = max(历史最高 total_assets)
    drawdown       = (current_peak - total_assets) / current_peak
    max_drawdown   = max(历史所有 drawdown)
```

## 六、数据流总结

### 6.1 数据表写入时机

| 表 | 写入时机 | 写入内容 |
|----|----------|----------|
| `strategy` | 用户保存策略 | name, code, parameters, status |
| `backtest_tasks` | create_backtest_task() | name, strategy_id, start_date, end_date, status=pending |
| `backtest_tasks` | _save_results() | status=completed, total_return, sharpe_ratio, max_drawdown... |
| `backtest_equity_curves` | _save_results() | 每日: task_id, trade_date, total_assets, cumulative_return |
| `backtest_trades` | _save_results() | 每笔: task_id, ts_code, direction, price, quantity, commission |
| `signals` | _persist_signal() | strategy_id, ts_code, signal_type, direction, price, confidence |
