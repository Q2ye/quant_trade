#### 计算器注册 (`factor_calculators.py`)

29 个因子通过 `@register_factor` 注册：

```
register_factor("pe", FactorSpec(
    factor_code="pe", factor_name="市盈率",
    factor_type="fundamental", category="value",
    data_source="both", calculator=_calc_pe

```

每个 `FactorSpec` 包含：`factor_code`, `factor_name`, `factor_type`, `category`, `data_source`, `calculator`

`data_source` 决定调用签名：
- `"market"` / `"technical"` → `calculator(df: DataFrame, parameters: Dict)`
- `"both"` / `"financial"` → `calculator(df: DataFrame, financial_data: DataFrame)`

### 2.2 计算层

#### 计算入口

```
API: POST /api/data/factors/research
  → handlers.py: research_factor()
    → 解析股票池（指数/ETF/篮子 → 全市场股票代码）
    → 创建 factor_research 记录（status=pending）
    → 后台 Task 执行 _execute_async_factor_research():
       → research_service._execute_factor_research()
          → calculate_factor()                    # 逐股计算
             → _calculate_single_factor(ts_code)
                → 加载 StockDaily → DataFrame
                → 解析因子名（别名 → 计算器）
                → _get_financial_data() (PIT 安全)
                → calculator(df, financial_data/params)
                → 返回 List[{ts_code, trade_date, factor_value}]
          → _compute_cross_sectional_stats()      # v3.2 新增
             → 逐日 Winsorize → z_score/percentile/rank
             → 批量更新 factor_data 表
          → 分析阶段
             → _perform_ic_analysis()      # Rank IC (v3.2)
             → _perform_quantile_analysis()
             → _perform_stability_analysis()
             → _save_research_result()
```

#### 财务数据获取 (PIT 安全)

```
_get_financial_data(ts_code, start_date, end_date):
  1. FinancialIncome 查询
     WHERE f_ann_date <= end_date     ← PIT 过滤
     提取: eps, revenue, oper_cost, n_income, n_income_attr_p
     计算: gross_margin, net_profit_margin

  2. FinancialBalance 查询
     WHERE f_ann_date <= end_date     ← PIT 过滤
     提取: total_assets, total_liab, total_cur_assets,
           total_cur_liab, total_hldr_eqy_exc_min_int, total_share
     计算: roe, roa, debt_to_asset, current_ratio, quick_ratio, bps

  3. ffill 到日频，返回 DataFrame
```

### 2.4 分析层

#### IC 分析 (Rank IC — v3.2)

```
_perform_ic_analysis(factor_data, returns_data, parameters):
  输入: factor_data (trade_date × ts_code), returns_data (trade_date × ts_code)
  方法: Spearman 秩相关 (Rank IC)
  输出:
    - ic_mean:       均值
    - ic_std:        标准差
    - ic_ir:         IC_IR = ic_mean / ic_std
    - ic_series:     时序 IC 序列
    - ic_pvalue:     单样本 t 检验 p 值
    - ic_positive_ratio: IC > 0 的占比
    - ic_decay:      滞后 1~5 期的 IC 衰减
```

#### 分位数分析

```
_perform_quantile_analysis(factor_data, returns_data, parameters):
  按因子值分 N 组（默认 5 组），计算每组平均收益
  输出:
    - quantile_returns:   每组收益
    - top_minus_bottom:   Q5 - Q1 多空收益
    - monotonicity_check: 收益是否随因子值单调
```

#### 稳定性分析

```
_perform_stability_analysis(ic_series):
  按季度分组计算:
    - ic_stability:  1 - CV(IC)
    - quarterly_ic:  每季度平均 IC
    - rank_ic_mean:  季度 Rank IC 均值
```

## 四、关键设计决策

### 4.1 Rank IC 而非 Pearson IC

v3.2 将 IC 分析方法从 Pearson 相关系数改为 Spearman 秩相关：

- **Pearson** 要求线性关系 + 正态分布 → 金融数据通常不满足
- **Spearman** 只要求单调关系 → 更适合因子收益分析
- 行业内 Barra / WorldQuant / MSCI 等主流机构均使用 Rank IC

### 4.2 Winsorized Z-Score

横截面标准化使用 5%/95% Winsorize 后再计算 z_score：

- 极端值（如 PE > 1000 或负 PE）不会被完全丢弃
- 但被缩尾到 5%/95% 分位数边界，避免扭曲均值/标准差
- 每只股票至少 10 只有效值的交易日才做标准化

### 4.3 PIT 过滤（v3.1 修复）

所有财务数据查询均按 `f_ann_date <= query_date` 过滤：

- `end_date` = 报告期截止日（如 2023-03-31）
- `f_ann_date` = 实际公告日（如 2023-04-26）
- 在 2023-04-15 查询 → 2023Q1 财报不可见 → 无未来函数

### 4.4 串行计算（非并行）

`calculate_factor()` 内的 per-stock 循环是串行的：

```
原因: asyncpg / SQLAlchemy AsyncSession 不支持并发协程访问同一 session
结果: 全市场 5000 只股票计算一个因子约需 30-120 秒
优化: v3.2 修复了 N+1 查询（get_factor_data），计算阶段暂保持串行
```

## 六、使用方式

### 提交因子研究

```bash
curl -X POST http://localhost:8080/api/data/factors/research \
  -H "Content-Type: application/json" \
  -d '{
    "factor_code": "roe_ttm",
    "universe_type": "all_a_shares",
    "start_date": "2023-01-01",
    "end_date": "2024-12-31",
    "parameters": {"forward_period": 5}
  }'
```

```bash
curl "http://localhost:8080/api/data/factors?factor_names=ROE,PB&ts_codes=600519.SH,000858.SZ&start_date=2024-01-01&end_date=2024-12-31"
```
