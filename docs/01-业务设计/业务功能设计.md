## 三、跨模块业务流转（详见《架构与业务流程流程图.md》）

1. **数据管道**：Tushare → sync_service（两层任务）→ Quality → TimescaleDB（131 表）
2. **信号链路**：StrategyManager 信号 → SignalEngine（持久化→半自动/全自动）→ RiskEngine 检查 → ExecutionEngine 下单 → PositionEngine 持仓 → SettlementEngine 结算 → signals.pnl_outcome 回填
3. **回测链路**：BacktestEngine → DataFeed → Strategy 信号 → Sizer → Broker 撮合 → 绩效 → backtest_tasks.result JSONB
4. **策略生命周期**：模板 seed → 实例创建（源码快照）→ 回测验证 → 实盘切换（paused/running）
