## 一、模块现状（10 业务模块 + storage 存储目录）

来源：`quant_server/config.yaml` 的 `modules:` 配置 + `quant_server/modules/` 目录。

| 模块 | 引擎（EngineBase 子类） | 职责 | 依赖 |
|:---|:---|:---|:---|
| **data** | DataSyncEngine / DataCleanEngine / DataQualityEngine / FactorResearchEngine | 数据同步（Tushare→DB）、清洗、质量检查、因子研究 | — |
| **market** | MarketEngine | 实时行情、交易日历、指数/行业数据 | data |
| **strategy** | StrategyManager / DataFeedEngine / PerformanceTrackerEngine | 策略管理、信号生成、绩效跟踪 | data |
| **risk** | RiskEngine | 风控检查（信号级 + 定时巡检） | trade, data |
| **trade** | SignalEngine / ExecutionEngine / PositionEngine | 信号处理、订单执行、仓位管理 | strategy, data |
| **backtest** | BacktestEngine / BacktestBroker / SimulationEngine / OptimizationEngine / ReportEngine / Sizer | 历史回测、模拟撮合、参数优化、报告 | strategy, data |
| **account** | SettlementEngine | 账户管理、日终结算、资金流水 | trade |
| **analysis** | AnalysisEngine | 绩效分析、归因 | account, strategy |
| **monitor** | AlertEngine / SystemMonitorEngine / BusinessMonitorEngine | 系统监控、告警推送（微信/钉钉/邮件） | data, strategy, trade, account, analysis |
| **system** | — | JWT 认证、系统配置 | — |
| **storage**（非业务模块） | — | **模型/文件存储目录**：`modules/storage/models/`（如 `etf_bottom_v2_20260726.joblib`），非可启用模块 | — |

> ⚠️ 注：`modules/storage/` 在 `modules/` 目录下但**不在** `config.yaml` 模块清单中，实为模型文件存放处（对应 CLAUDE.md 中 `storage/models/`）。
