## 二、核心功能：系统到底做什么

这个系统归根结底做三件事，其他都是辅助：

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│  1. 策略研究                                         │
│     因子管线 → 回测引擎 → 模型训练 → 参数优化          │
│     输出：一个经过验证的策略版本                        │
│                                                     │
│  2. 策略执行                                         │
│     实盘信号链路 → 风控 19 规则 → 券商接口             │
│     输出：信号 → 订单 → 成交 → 持仓                    │
│                                                     │
│  3. 数据资产化                                        │
│     信号→盈亏闭环 → 策略版本溯源 → 市场状态标签          │
│     输出：别人没有的独有数据                            │
│                                                     │
└─────────────────────────────────────────────────────┘
```

131 张表、10 个模块、22 个引擎（2026-08 代码实证，见《系统建设现状白皮书》），最终都服务于这个"研究→执行→学习"的闭环。

## 三、数据资产分层架构

### 3.1 五层金字塔（更新）

```
                            ┌─────────────┐
                            │  第五层      │  ← 知识决策层
                            │  Regime路由  │     策略选择 / 仓位分配
                            │  策略失效预警 │     环境自适应 / 元学习
                            ├─────────────┤
                            │  第四层      │  ← 洞察分析层
                            │  归因分析    │     Brinson归因 / 因子归因
                            │  绩效评估    │     夏普/回撤/胜率/Alpha
                            │  市场状态    │     BULL/RANGE/BEAR (ETF v5 在用)
                            ├─────────────┤
                       ┌────┤  第三层      ├────┐
                       │    │  策略衍生    │    │  ← 🔴 核心资产层
                       │    │  实盘信号    │    │     signals + pnl_outcome
                       │    │  策略版本    │    │     v1→v5 完整演化链
                       │    │  回测结果    │    │     result JSONB 可复现
                       │    │  交易记录    │    │     trades 实盘成交
                       │    ├─────────────┤    │
                       │    │  第二层      │    │  ← 衍生数据层
                       │    │  因子数据    │    │     74 因子 × ETFs/股票
                       │    │  复权价格    │    │     前复权日线
                       │    │  市场状态    │    │     market_state_daily
                       │    ├─────────────┤    │
                       │    │  第一层      │    │  ← 基础数据层
                       │    │  日周月分钟  │    │     A股/ETF/指数
                       │    │  财务三表    │    │     利润/资产/现金流
                       │    │  基础信息    │    │     股票/公司/行业
                       └────┴─────────────┴────┘
```

### 3.2 各层关键更新

#### 第一层：基础数据（无变化）

Tushare 40+ 接口全覆盖。日均新增 5-10 万行。

#### 第二层：衍生数据（7 月更新）

- `factor_data`：因子从 42 个扩展到 **74 个**（新增下跌加速度 `drawdown_accel`、波动率收缩 `vol_contraction` 等）
- `market_state_daily`：5166 天历史数据，ETF v5 策略的 regime 判定直接消费此表
- 财务数据 PIT 正确性：`f_ann_date <= query_date` 约束已生效

#### 第三层：策略衍生（🔴 核心资产 — 7 月重大进展）

**策略演化路径 v1→v5 完整保存**：
```
v1 (+11.8%, Sharpe 0.45): 基线
v2 回归 (失败): 回归模型路线中止
v2 分类 (+4.1%, Sharpe 0.60): 74 特征 + 扩展训练
v3 (+4.9%, Sharpe 0.67): 移除低效 ETF
v4 (+2.7%, Sharpe 1.10): ATR 止损 + 量能确认
v5 (+13.2%, Sharpe 1.08): 线性仓位最终版
```

**实盘数据积累（7/26 启动）**：
| 表 | 积累速度 | 当前量 | 一年后 |
|:---|:---|:---|:---|
| `signals` | ~10 条/交易日 | 0 | ~2500 |
| `trades` | ~2 条/交易日 | 0 | ~500 |
| `strategy_daily_performance` | 2 条/交易日 | 0 | ~500 |
| `risk_events` | ~0.2 条/交易日 | 0 | ~50 |

**signals 表增强**：
```sql
ALTER TABLE signals 
  ADD COLUMN is_executed BOOLEAN DEFAULT false,
  ADD COLUMN pnl_outcome NUMERIC(10,4);
```
每条信号都标注了是否执行、结果是赚是亏——这是模型未来迭代的核心训练数据。

#### 第四层：洞察分析（激活中）

- ETF v5 的分市场绩效已在回测中验证（牛/熊/震三层拆分）
- 实盘运行后，第四层将开始积累真实的牛熊表现数据

#### 第五层：知识决策（设计就绪）

- Regime 路由组合策略设计方案已完成
- 需要实盘运行数据来验证分配比例
- 策略失效预警等能力依赖实盘信号积累

## 五、数据资产"护城河"评估

### 5.1 不可替代性矩阵（不变）

| 资产 | 可替代性 | 护城河深度 | 说明 |
|:---|:---|:---|:---|
| 第一层：市场数据 | 高可替代 | 浅 | 公开数据源 |
| 第二层：衍生数据 | 中可替代 | 中 | PIT 正确性 + 历史回填不易复制 |
| 第三层：策略衍生 | **低可替代** | **深** | v1→v5 演化 + 实盘信号 = 只有你有 |
| 第四层：洞察分析 | **低可替代** | **深** | 基于你的策略和数据的归因结论 |
| 第五层：知识 | **极低可替代** | **最深** | 环境自适应知识无法复制 |
