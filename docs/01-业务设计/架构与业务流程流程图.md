**通信机制**：

|:---|:---|
| Service → Repository | 同步直接调用 |
| 模块间（如 strategy → trade） | 仅通过 EventEngine 异步事件 |
| Engine 之间 | EventEngine 发布/订阅 |

## 四、实盘交易业务流程（信号 → 风控 → 执行）

```mermaid
flowchart TD
    A["行情推送 MarketEngine"] --> B["StrategyManager.handle_bar_batch()<br/>遍历所有 running 策略"]
    B --> C["strategy.on_bar(bar)<br/>生成 TradingSignal"]
    C --> D["_publish_signals()<br/>发布 StrategySignalEvent"]
    D --> E["SignalEngine 订阅事件"]

    E --> F["持久化 signals 超表<br/>signal_status = pending_manual"]
    F --> G{"执行模式?"}

    G -->|"semi_auto 半自动"| H["信号挂起 pending_manual<br/>推送微信/钉钉通知"]
    H --> I["人工在交易台确认成交"] --> J["执行引擎下单"]

    G -->|"auto 全自动"| K["RiskEngine.check_signal()<br/>风控 19 规则"]
    K --> L{"检查结果?"}
    L -->|"error/critical"| M["发布 RiskViolationEvent<br/>信号 rejected"]
    L -->|"warning"| N["缩减订单量 50%<br/>至少保留 100 股"]
    L -->|"通过"| O["ExecutionEngine.execute_signal()"]

    N --> O
    J --> P["订单 → 成交 → 持仓<br/>PositionEngine 仓位管理"]
    O --> P
    P --> Q["回写信号状态 executed + order_id"]
    Q --> R["SettlementEngine 日终结算<br/>绩效回填 strategy_daily_performance"]
    R --> S["signals.pnl_outcome 盈亏回填<br/>→ 数据资产闭环"]
```

**信号类型**：`ENTRY` / `EXIT` / `STOP_LOSS` / `TAKE_PROFIT`
**事件命名**：`{module}.{domain}.{action}.{status}`，如 `trade.order.submitted`
**交易模式**：半自动为主（策略生成信号 → 人工确认 → 执行），全自动可选

## 五、回测业务流程

```mermaid
flowchart TD
    A["前端发起回测<br/>选择策略实例 + 参数 + 区间"] --> B["创建 backtest_tasks 任务"]
    B --> C["BacktestEngine.run()"]
    C --> D["DataFeedEngine<br/>历史数据加载 + 逐日迭代<br/>(PIT 约束: f_ann_date <= query_date)"]
    D --> E["StrategyManager<br/>策略信号生成 on_bar"]
    E --> F["Sizer 计算股数<br/>Weight / CloseAll / HalfClose / Quantity"]
    F --> G["BacktestBroker 虚拟券商<br/>T+1 / 涨跌停 / 佣金+印花税+过户费 / 滑点 / 100股最小单位"]
    G --> H["资金校验三层防护<br/>L1 宽松门 → L2 自动缩减 → L3 开盘价最终校验"]
    H --> I["成交记录 backtest_trades"]
    I --> J["绩效计算<br/>Sharpe / MDD / WinRate / Alpha / Beta"]
    J --> K["结果 JSONB 写入 backtest_tasks.result<br/>可复现"]
    K --> L["前端 ECharts 展示净值曲线/回撤/月度收益"]
```

**Broker 撮合规则（模拟 A 股真实环境）**：
- T+1：当日买入，次日开盘方可卖出
- 涨跌停：主板 ±10%，科创 ±20%，ST ±5%；涨停不买、跌停不卖
- 费用：万一佣金（免五）、0.1% 印花税（仅卖出）、0.002% 过户费（双向）
- 滑点：买入 ×(1+0.1%)，卖出 ×(1-0.1%)
- 最小交易单位：100 股（1 手）

## 六、策略开发生命周期与热更新

```mermaid
flowchart LR
    A["模板 seed 机制<br/>启动时 import .py → inspect.getsource<br/>幂等写入 strategy_templates"] --> B["基于模板创建实例<br/>复制源码 → strategies.code<br/>复制参数 → strategy_parameters"]
    B --> C["开发环境回测验证<br/>(DB=quant_signals_dev)"]
    C --> D["生产库新建实例<br/>(DB=quant_signals)"]
    D --> E["生产库回测确认"]
    E --> F["旧实例 → paused<br/>新实例 → running"]
    F --> G["观察 1-2 周<br/>稳定后删除旧实例"]

    H["模型升级<br/>训练 → 复制到 storage/models/<br/>_find_latest_model() 自动发现<br/>出错删除文件即回退"] -.-> D
```

**关键约束**：
- 实盘策略代码 = 创建时的快照（`strategies.code`），不随 .py 文件修改而变化
- 策略实例升级 = 新建实例 + 验证 + 切换
- 模板随重启自动更新，策略实例不自动更新

## 七、模块职责总览

| 模块 | 核心引擎 | 职责 |
|:---|:---|:---|
| **data** | SyncEngine / CleanEngine / QualityEngine / ResearchEngine | 数据同步、因子计算、研究服务 |
| **market** | MarketEngine | 实时行情、交易日历 |
| **strategy** | StrategyManager / StrategyRegistry / CapitalAllocator / DataFeedEngine | 策略管理、信号生成 |
| **risk** | RiskEngine | 风控 19 规则（止损、仓位上限） |
| **trade** | SignalEngine / ExecutionEngine / PositionEngine / RiskEngine | 信号→订单执行、仓位管理 |
| **backtest** | BacktestEngine / BacktestBroker / Sizer / OptimizationEngine / ReportEngine | 历史回测、参数优化、绩效分析 |
| **account** | SettlementEngine | 多账户管理、资金流水、日终结算 |
| **analysis** | AnalysisEngine | 绩效归因、Sharpe/MDD 指标 |
| **monitor** | AlertEngine / SystemMonitor / RiskMonitor / BusinessMonitor | 系统监控、钉钉/微信通知 |
| **system** | — | JWT 认证、系统配置 |

## 八、核心业务闭环总结

```mermaid
flowchart LR
    A["① 策略研究<br/>因子管线 → 回测 → 训练 → 参数优化"] --> B["② 策略执行<br/>信号 → 风控 → 订单 → 成交 → 持仓"]
```

**系统定位**：实盘验证期（v4.0）——2 个实盘策略（ETF 底部 v5 防守型 + 低吸轮动 v3 进攻型），通过 Regime 路由组合，正在积累独有数据资产。

**里程碑**：2026-08 实盘满 1 月偏差分析 → 2026-09 Regime 路由上线 → 2026-12 组合实盘满 1 季度 → 2027-Q2 实盘信号 > 1000 条 → 2027-Q4 策略工厂 v1。

## 附录：核心事件一览（代码实证）

| 事件 | 发布方 → 订阅方 | 说明 |
|:---|:---|:---|
| `StrategySignalEvent` | strategy → trade.SignalEngine | 策略信号 |

| `SystemStartedEvent` | MainEngine → 各引擎 | 系统启动完成 |
| `monitor.trading.signal` | trade → monitor | 实盘信号推送通知 |
