# 二、核心假设
1. 板块轮动的驱动力是状态变量（资金流向、估值分位、景气度、热度、拥挤度），而非日历本身；月份效应只是制度噪声，降级为辅助特征
2. 多时间尺度规律并存：不同回看窗口捕捉不同频率的驱动（短窗口=资金/情绪，长窗口=估值/景气）
3. 板块存在热度先行信号：涨停结构/成交额异动领先于指数价格（资金行为先于价格）
4. 上述规律可统计验证（历史多次复现），且未被完全套利消化

# 三、数据需求

| ---- | ---- | ---- | ---- |
| 申万一级行业指数日线（31个） | 日 | 聚宽/米筐/Tushare | 主数据 |

时间跨度：≥10年（2013–2024），不足10年用尽可能长，至少覆盖一个完整牛熊。

# 四、数据与特征工程
## 4.1 基础数据表

```
表: daily_industry

表: daily_limit_up

```

## 4.2 特征定义（多时间尺度特征。预测时刻t=每日收盘后，窗口终点恒为t，起点多档）
特征全家桶（每变量2–3个窗口，总特征控制在≤15个之内）：

| 特征 | 定义 | 窗口 | 频率属性 |
| ---- | ---- | ---- | ---- |
| m | 月份（1–12, one-hot） | — | 辅助（不再为主轴） |
| mom_{s/m/l} | 收益率：5日 / 20日 / 60日 | 3档 | 动量（短/中/长） |
| vol_20 | 过去20日年化波动率 | 1档 | 风险 |
| amount_ratio_{s/l} | 成交额异动：5日/20日累计 ÷120日均量 | 2档 | 资金异动（快/慢） |
| limit_up_{s/l} | 板块涨停家数：近1日 / 近5日累计 | 2档 | 热度先行（快/慢） |
| linked_high | 板块内最高连板数（近5日） | 1档 | 资金主攻方向 |
| premium_5d | 近5日板块涨停次日溢价均值 | 1档 | 情绪温度 |
| inflow_{s/l} | 主力净流入：近1日 / 近5日累计 | 2档 | 资金流（快/慢） |
| pe_percentile | 板块PE估值在近3年/5年中的百分位 | 1–2档 | 估值均值回归（慢） |
| turnover_percentile | 板块换手率历史百分位 | 1档 | 拥挤温度（中） |
| roe_change_q | 板块最新季度盈利增速环比变化 | 1档 | 景气度（慢） |

降维原则：同变量的多个窗口，先经P2层合成一个分（IC加权或PCA），31×多窗口全量特征不直接进模型，避免过拟合。

```
2 |   = ln(close_{t+20} / close_t)
```

# 五、新模型设计（V1.1多时间尺度状态模型）
## 5.1 模型架构总览（四层流水线）
```
P1 感知层（每日）：计算31行业 × 多窗口特征（终点=today，起点多档）
↓
P2 合成层（每日）：同变量多窗口 → IC加权合成单分 → z-score归一化
↓
P3 决策层（每日）：三信号分工合成 → 综合分 → 排名
↓
P4 执行层（每周）：连续确认 + 变动阈值 → 生成动作（每天算，周末动）
```

## 5.2 P1感知层：多时间尺度特征（终点=今天，起点=可变）
```
对每个行业 i，在每个交易日 t（=今天）：
特征矢量 X(i,t) = [merch窗口各算一遍]

窗口配置（每变量限2–3档）：
快手指标（资金流/热度）：5日 / 20日
慢变量指标（估值/景气）：3-5年分位（分位天然是长窗）
动量：5日 / 20日 / 60日（备选收缩）

关键规则：
1. 窗口终点永远 = t（今天），永不使用旧信息
2. 当天数据未更新完 → 短窗口特征记无效，不参与合成
3. 每年重算估值分位基线（防老化）
```

## 5.3 P2合成层：多窗口降维
```
对每个“变量族”（如动量族：mom_5/mom_20/mom_60）

方法A（推荐起步）：IC加权
S_动量 = Σ (IC_i · 标准化(mom_i)) / Σ IC_i
其中 IC_i = 该窗口历史IC（滚动24个月计算，月度更新权重）

方法B（进阶）：PCA第一主成分

输出：每个“变量族”一个合成分（约6-8个合成特征）
从 ~20个原始窗口特征压缩到 ≤8个，防过拟合
```

## 5.4 P3决策层：三信号分工合成（权重+分工）
三个角色各司其职（不是简单相加）：

| 信号 | 构成 | 角色 | 方向 |
| ---- | ---- | ---- | ---- |
| S1 | 估值分位 × 资金流 | 骨架（选板块） | 正向 |
| S2 | 景气度 × 热度 | 增强（确认） | 正向 |
| S3 | 拥挤度 × 反转 | 风控（排除） | 负向，有否决权 |

合成公式：
```
综合分(i) = w1·S1(i) + w2·S2(i) − w3·S3(i)  (i ∈ 31行业)

权重更新: w_i = 各自历史IC / ΣIC（月度滚动重算，数据驱动不拍脑袋）
```

信号合成前强制“相关性体检”：
```
1 计算 S1/S2/S3 两两相关矩阵:
2 · 任何两信号相关 > 0.6 → 信息重叠，合并或删除其一
3 · 体检通过才可加权，否则权重=重复计算
```

S3否决权（硬规则，优先于一切权重）：
```
1 拥挤度百分位 > 95 且 盈利见顶(roe_change_q < 0) → 该行业直接剔除,
2                                         不进Top5, 不参与加权
3 风控信号宁可错杀, 不可漏杀
```

## 5.5 排名与信号输出
每日输出（P3）：
```
rank | industry | 综合分 | S1 | S2 | S3 | 信号是否合格
1    | 煤炭     | +2.31  | +3.1 | +1.2 | -0.4 | 合格
…
31   | 计算机   | -1.85  | -2.0 | -0.5 | +0.3 | 合格
```
每周四复核信号 → 周五执行 → 每日信号仅参考不动手

## 5.6 基线模型对照（Champion）
层次1保留为基线：三维热力图（行业×月×收益）+ ANOVA显著性检验，作为新模型的最笨但稳健的下限，与新模型长期对照，防止新模型过拟合。新模型无参。

# 六、滚动预测与验证（核心工程）
## 6.1 每日滚动 + 时序交叉验证（禁止泄漏）
| 训练窗口 | 空白期 | 预测日t |
| ---- | ---- | ---- |
| 2013.01–2021.12 | 1个月 | 2022.02.01 ← 用t−1日数据预测 |
| 2013.01–2022.01 | 1个月 | 2022.03.01 ← 逐日/逐周滚动 |
| … |  | 持续到2024.12 |

回测粒度：每日生成信号 → 每周执行 → 按周结算

规则:
1. 特征窗口终点恒为t日收盘（用t及之前数据），预测t之后20交易日收益
2. 训练截止到T日，验证从T+21日开始（空白期≥20交易日，防泄漏）
3. 每日滚动计算信号；回测中每周四评估、周五模拟执行（与实盘节奏一致）
4. 模型每季度重训一次，但信号每日更新（模型参数量级，特征输入日级）

## 6.2 信号稳定化（核心新增：每天算→周末动）
防止“信号每天变→换手率爆炸→成本吞噬收益”：
```
动作触发条件（满足其一才调仓）：
A. 连续确认法：Top5名单连续 N≥3 个交易日指向同一板块，才纳入调仓
B. 变阈值法：新排名与当前持仓差异率 > 20% 才调仓
C. 周执行法：周一确认的前一周信号，周五执行（计算每天，动作周末）

执行纪律: 任一交易前先预估成本，超额 < 成本 → 不动手
```

## 6.3 预测输出
每周五的策略信号表：
```
rank | industry | 综合分 | model_conf | 动作(买/持/卖)
1    | 煤炭     | +2.31  | 0.87       | 买入
2    | 银行     | +2.10  | 0.82       | 持有
…
31   | 计算机   | -1.85  | 0.41       | 卖出
```

## 6.4 评估指标
| 指标 | 合格门槛 |
| ---- | ---- |
| IC（综合分与未来20日真实收益Spearman相关） | 均值 > 0.05 |
| 周Top5行业 vs 全行业均值超额 | > 0.4%/周 |
| Top vs Bottom 多空差 | > 0.8%/周 |
| 胜率（方向正确比例） | > 55% |
| 换手率（月均） | < 40%（控成本） |
| 信号稳定性 | Top5名单周环比保留率 > 60% |

Champion-Challenger：V1.0基线（日历热力图表）vs V1.1新模型，同一滚动窗口互比，IC更高且回撤更小者上线。新模型若3个月跑不赢基线 → 回滚。

# 七、信号转交易（决策层）
```
1 每日: P1→P2→P3 生成信号（实时，不执行）
2 每周四: 复核周信号 + 连续确认（6.2 稳定化规则）
3 每周五: 生成交易单 → 执行

交易单流程:
rank表 → 1.过滤（剔除日均成交<5000万行业）
        → 2.权重分配（风险平价 or 按综合分加权，总暴露≤80%）
        → 3.与当前持仓对比 → 差异率<20%或未连续3日 → 不动手
        → 4.生成交易单（行业ETF 或 行业指数基金为宜）
        → 5.执行: 周五开盘附近，一次完成
```

强制规则:
1. 全市场综合分中位数<0 → 仓位降至≤30%（现金为主）
2. 单周信号强度不足（Top5平均conf < 0.6）→ 不调仓
3. 任何交易前计入双边成本（万分之2.5 × 换手率），若超额 < 成本 → 不交易
4. S3风控否决权：拥挤度极值+盈利见顶的行业，一票否决，不进Top5

# 八、上线后监控（每周体检）
每周IC报告：
```
周次 | Top5组合 | 本周超额 | 累计IC | 信号保留率
W1   | 煤炭/银行/… | +0.5% | 0.07 | 70%
W2   | … |
```

熔断条款:
1. 连续4周IC < 0 → 暂停模型，查原因（市场结构变化/特征失效）
2. 最大回撤超15% → 降杠杆至50%，复盘
3. 单周超额<0且持续8周 → 回滚到V1.0基线（日历查表）
4. 特征有效性监控：任一合成特征连续8周IC为负→该特征降权/删除
5. 日历效应年际衰减监控：若"12月银行"近3年均值<历史均值→该格子降权

# 十、防坑清单（红线）
1. 前视泄漏：特征窗口终点恒为"今天"，预测未来20日；训练截止T、验证从T+21开始；短窗口特征必须有数据新鲜度校验
2. 过拟合：多窗口特征必须先降维（P2 IC加权/PCA），合成特征≤8个，禁止全量裸特征进模型
3. 幸存者偏差：行业指数用可回溯的申万历史口径
4. 成本侵蚀：所有回测含双边2.5成本；换手率>40%的策略直接毙；信号稳定化（连续确认/变动阈值）是标配不是可选项
5. 信号频率错配：每天算 ≠ 每天动；计算每日、执行每周，二者必须解耦
6. 日历衰减：月份特征只作辅助，权重低；连续监测年际趋势，被市场消化的规律降权
7. 风控否决权被越过：S3拥挤极值必须一票否决，任何权重不得覆盖
8. 懒于验证：任何模型上线前必须过6.4全部门槛 + 样本外滚动 + 跑赢V1.0基线

# 十一、一句话总结
V1.1模型以多时间尺度状态变量为轴（终点=今天，起点=多窗口），每日计算信号、每周执行动作；三信号分工合成（骨架S1×增强S2−风控S3，S3有否决权）；IC加权降维防过拟合；信号稳定化防换手爆炸；与V1.0日历基线长期对照，跑不赢就回滚。目标是成为主系统的板块择时模块，不是替代主策略。
