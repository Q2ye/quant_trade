# C4 绩效口径统一方案（待确认）

> 2026-08 | 依据 06 报告 §7.3（PERF：GIPS 一致性原则）
> 核心问题：同一平台的夏普/年化/回撤/日盈亏存在多套公式，历史绩效数字不可比、部分公式有维度错误。

---

## 一、现状实况（4 套分裂公式，代码实证）

### 1. 夏普比率（4 处，3 种算法）

| 位置 | 公式 | 问题 |
|:---|:---|:---|
| `pnl_calculator.py:355-368` | `mean(return - rf/252) / std × √252` | ✅ 公式正确，但 `np.std()` **ddof=0**（总体标准差，统计惯例应为 ddof=1） |
| `financial_calculator.py:216-241` | `(年化收益 - rf_日化) / 年化波动率` | 🔴 **维度错误**：年化收益减的是日化 rf（`rf^(1/252)-1`） |
| `exposure_calculator.py:467-471` | `mean/std(ddof=1) × √252`，rf=0 | 🟡 标准公式但**硬编码 rf=0** |
| `performance_service.py:125-131` | `mean/std(ddof=0) × √252`，rf=0 | 🟡 ddof=0 + rf=0 |

### 2. 年化收益率（3 处）

| 位置 | 公式 | 问题 |
|:---|:---|:---|
| `financial_calculator.py:178-187` | `(1+R)^(trading_days/n) - 1` | trading_days 默认值待确认（252 或 365.25） |
| `pnl_calculator.py:324-328` | `(1+R)^(365/自然日) - 1` | 🔴 **365 自然日**基准，与其他处不一致 |
| `performance_service.py` | 不年化（只存累计收益） | 展示层另算 |

### 3. 最大回撤符号（2 种并存）

| 位置 | 存储值 |
|:---|:---|
| `exposure_calculator.py:474-477` | **负值**（-0.15 = 回撤 15%） |
| `performance_service.py:118-122` | **正值**（0.15 = 回撤 15%） |
| 后果 | `comparison_service.py:440-444` 按"越小越好"升序排序 → 两种符号混排时**排名方向反转** |

### 4. 日盈亏口径（含累计浮盈）

`pnl_calculator.py:182-195`：`position_pnl = Σ 持仓量 × (最新价 - 成本价)`——这是**累计浮盈**，不是"当日盈亏"（应为：今日市值 - 昨日市值 + 当日已实现）。日收益被历史浮盈污染。

---

## 二、统一标准（推荐：GIPS 一致性口径）

| 指标 | 统一公式 | 说明 |
|:---|:---|:---|
| **夏普** | `mean(daily_excess) / std(daily_excess, ddof=1) × √252`，`daily_excess = r - rf/252`，**rf 默认 2% 统一可配置** | 以 pnl_calculator 正确公式为底，std 改 ddof=1 |
| **年化收益** | `(1 + 累计收益)^(252/交易日数) - 1` | **252 交易日**基准（GIPS 惯例），365.25/365 全部废弃 |
| **最大回撤** | **统一存储负值**（-0.15），展示时 `abs()` | comparison 排序"越小越好"保持不变 |
| **日盈亏** | `当日已实现盈亏 + (今日持仓市值 - 昨日持仓市值)`，**不含历史浮盈** | mark-to-market 日变动口径 |
| **胜率/盈亏比** | 保持现状（无分裂） | — |

## 三、影响范围与风险

| 项 | 影响 | 风险等级 |
|:---|:---|:---|
| 历史绩效数字 | **全部变化**（夏普/年化/回撤/日收益） | 🟡 需新旧对照表确认合理 |
| 策略绩效展示 | 数字变化但趋势/排名基本不变 | 🟢 |
| 日终结算写入 | 日盈亏口径修正后 `account_daily_performance` 数据变化 | 🟡 |
| 回测结果 | 若回测复用 financial_calculator → 回测绩效数字变化 | 🟡 |
| 前端 | 展示层需加"口径标注"（如"夏普：日频×√252，rf=2%"） | 🟢 |

**注意**：本次**不改动结算逻辑本身**（资产差分法公式正确），只统一**指标计算层**。
