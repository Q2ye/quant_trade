# 14 — D 批死代码引用验证清单

> 生成日期：2026-08（A/B/C 类修复完成之后）。本文档是对 `11-系统级修复实施方案.md` D 类 11 项的**逐目标重新验证**——因为 A/B/C 修复已改动过部分文件，审查报告（01~09）的部分"零引用"结论已过期，本文以**当前代码**为准。
>
> 验证方法（每目标三查）：① grep 全库静态引用（排除目标自身与所在包 `__init__.py` 再导出）② 动态加载（exec/importlib/getattr/字符串 import/路由懒加载/全局注册/config.yaml 开关/celery 调度）③ 启动接线（main.py / 模块 `__init__.py` initialize / 路由注册）。
>
> 判定口径：**delete-safe**＝零引用可删；**keep**＝有真实调用方保留；**needs-runtime-check**＝依赖运行时/配置确认后才可动；**move-to-C**＝不能当死代码删、需行为级处理（回测对账或功能实现）。
>
> ⚠️ 执行总纪律（沿用 11 方案）：删除前**必须再跑一遍本清单对应 grep 复核**（本清单与执行之间可能有新改动）；每批独立 commit；每批后 `pytest` + 启动冒烟；前端批每小组删除后 `pnpm build`。
