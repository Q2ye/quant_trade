## 1. 依赖方向核查（依据：Clean Architecture — Dependency Rule）

### 🔴 1.1 core 层反向依赖 modules（架构红线违规）

`modules/ → core/` 单向依赖被破坏：核心层 `main_engine.py` 直接 import 业务模块并在日终调度中调用业务服务。

| 位置 | 代码 | 违规内容 |
|:---|:---|:---|
| `core/engines/system/main_engine.py:221-222` | `from modules.data.services.sync_service import DataSyncService` | core → modules.data |
| `core/engines/system/main_engine.py:263-264` | `from modules.data.services.market_state_classifier import ...` | core → modules.data（市场状态分类日终任务） |
| `core/engines/system/main_engine.py:271-272` | `from modules.data.services.etf_factor_daily import ...` | core → modules.data（ETF 因子日终任务） |
| `core/engines/system/main_engine.py:285` | `from modules.account.tasks.settlement_tasks import ...` | core → modules.account（结算任务） |
| `core/engines/system/main_engine.py:340` | `from modules.strategy.services.composite_service import CompositeService` | core → modules.strategy |

**修复方案**（依据：控制反转 IoC + 注册机制）：
- 方案 A（推荐）：MainEngine 只保留"调度框架"，通过**回调注册表**/事件订阅机制让各模块自行注册日终任务（`register_daily_task(coro)`），MainEngine 遍历执行——依赖反转，core 不再感知具体模块。
- 方案 B：将日终调度迁至各模块自己的 tasks（模块在 `SystemStartedEvent` 后自行启动 asyncio 定时任务），MainEngine 删除相关代码。

### 🟡 1.2 跨模块直接 import（依据：架构约束"模块间仅通过 EventEngine"）

| 依赖 | 位置 | 用法 | 判定 |
|:---|:---|:---|:---|
| strategy → trade | `strategy_manager.py:34` `from modules.trade import OrderFilledEvent` | 仅订阅事件类（L1025 subscribe） | 🟢 可接受（事件订阅是 EventEngine 通信的必要组成） |
| backtest → data/strategy | backtest 模块 | 待子代理 04 确认 | 🟡 |
| trade → data/risk | trade 模块（signal_engine.py:59 订阅 StrategySignalEvent；L14-15 注入 execution/risk engine） | 部分为构造注入 + 事件订阅 | 🟡 |
| monitor → risk | monitor 模块 | 待子代理 06 确认 | 🟡 |

**建议**：在 CLAUDE.md 架构规则中明确"允许 import 事件类用于订阅，禁止 import 并直接调用对方 Engine/Service"的细则，消除灰色地带。

| 依赖 | 现状 | 问题 |

**建议**：grep 确认 PyQt5 引用后移除；未用依赖全部清理（减小安装体积与攻击面）。

### 🟢 4.3 元数据未维护

`pyproject.toml` authors = "Your Name <your.email@example.com>"、license 声明 MIT 但无 LICENSE 文件（待确认）。

| 位置 | 读取方式 | 风险 |
|:---|:---|:---|
| `shared/config/config_manager.py:221` | pydantic-settings（TRADE.SIMULATED_TRADING） | 主路径 ✅ |
