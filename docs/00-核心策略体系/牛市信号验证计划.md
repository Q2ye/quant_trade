## 八、板块级验证口径（2026-09-07 定稿）

> 解决遗漏 #4 基准、#6 相对强度、#8 验收线三个「待定义」项。

### 基准口径（#4）

采用**相对超额口径**（不对比绝对收益）：
- 满仓基线 = 满仓板块指数相对大盘的累计超额；
- MA250 基线 = 板块 close>MA250 择时 相对 满仓大盘的超额；
- 核心对比 = 「择时板块 vs 满仓板块」的超额，回答「择时是否跑赢死拿板块」。

### 相对强度口径（#6）

三种算法都测，方向用「转正」：
- ① 累积比值 RS = 板块指数 ÷ 大盘指数，牛市 = RS 创 N 日新高；
- ② 相对动量 RS_mom = RS[t] ÷ RS[t−N] − 1，牛市 = RS_mom > 0；
- ③ 超额收益 = 板块 N 日收益 − 大盘 N 日收益，牛市 = 超额 > 0。

### 验收线（#8）

板块级用「**择时超额年化 ≥ 10%**」（相对超额口径），而非全市场级的「择时绝对年化 ≥ 15%」。
