| 里程碑 | 内容 | 验证 |

## 五、风险与原则

| 风险 | 缓解 |
|:--|:--|
| 微盘/恐慌回测可能不成立 | **反例统计前置**，验证通过才实现 |
| 对冲逻辑不成立 | M2b 回测验证，不假设 |
| 卫星池越打越小 | 铁律3：年度再平衡 |
| 多账户路由改造复杂 | M1b 单列，先设计后开发 |
| 失效监控误报 | warning/stop 分级，仅 stop 停用 |

**核心原则**：所有新策略**先验证后实现**——用数据证明逻辑成立，再写代码。这是从 7.1→8.0→8.1→9.0 反复迭代中最重要的教训。
