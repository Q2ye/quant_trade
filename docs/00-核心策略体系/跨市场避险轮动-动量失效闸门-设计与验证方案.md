## 0.5 验证结果（2026-09-12 完成，**否决**）

实现：`_momentum_efficacy()` + `momentum_efficacy_threshold` / `momentum_efficacy_lag` 两个参数，
触发时本次调仓改持防御标的 511010。**实现正确性已自检**：策略内 eff 与离线口径逐位一致（8/8 日期），
触发次数与离线触发率吻合（−0.03 → 528/1846 = 28.6% vs 离线 28.7%）。

**18 次回测（6 臂 × 3 段）**：

| 臂 | 全窗口 2019-01~2026-09 | 段 A 2019-01~2021-01 | 段 B 2022-02~2026-06 |
|:---|:---|:---|:---|
| **OFF（基线）** | 427.84% / 0.946 / 39.02% | **62.23% / 1.068 / 16.03%** | **543.67% / 1.785 / 14.92%** |
| GATE th−0.03（触发 28.6%） | 279.29% / 0.839 / 25.62% | 39.27% / 0.774 / 21.74% | 245.14% / 1.343 / 15.46% |
| GATE th−0.04（触发 23.9%） | **198.05% / 0.683 / 21.69%** | 35.26% / 0.707 / 20.32% | **174.51% / 1.074 / 17.09%** |
| GATE th−0.05（触发 19.6%） | **471.83% / 1.075 / 21.50%** | 61.20% / 1.092 / 14.98% | 321.56% / 1.524 / 17.15% |
| **PLACEBO（lag60，无预测力）** | 312.17% / 0.900 / 32.56% | 47.84% / 0.922 / 19.88% | 383.54% / 1.752 / 18.40% |
| LEV 0.3（恒定低仓位） | 83.38% / 0.781 / 14.69% | 18.75% / 0.887 / 5.54% | 92.35% / 1.614 / 5.20% |

**判据逐条核对（预注册于 §6.3）**：

| 判据 | 结果 |
|:---|:---|
| 1. 段 A/B 收益降 ≤15% 且夏普不降 | ❌ **两段都不满足**（段 A 夏普 1.068→0.707；段 B 543.67%→174.51%） |
| 2. 段 C MDD 改善 ≥5pp 且收益降 ≤10% | ⚠️ MDD 满足；收益：−0.03 降 35%、−0.04 降 54%（**仅 −0.05 上升**） |
| 3. ON 显著优于安慰剂/降杠杆对照 | ❌ **不满足**：同阈值 −0.04 下，真实信号 198.05%/0.683 **差于**安慰剂 312.17%/0.900 |
| 4. 阈值邻域方向一致 | ❌ **严重不满足**：279% → 198% → 472%，非单调 |

**红线命中（§6.4）**：全窗口唯一表现好的 th−0.05（471.83%/1.075/21.50%），在段 A 只是持平（61.20 vs 62.23），
在段 B 大幅变差（321.56 vs 543.67）→ **其优势完全来自动机区间 → 判为曲线拟合。**

### 为什么失败（机制）

1. **闸门削减的是"在场时长"，而收益极度集中**：触发率 19.6~28.6% 的交易日，且每次触发后切国债并被
   `min_hold_days=3` 锁 ≥3 天。策略全部盈亏由 **Top 10 笔**（2.6%）决定 —— 削减在场时长 = 大概率错过它们。
2. **安慰剂臂证明了这一点**：lag60 用 60 天前的 eff（分布相同、对齐被破坏、**无任何预测力**），
   全窗口 312.17%/0.900、段 B 383.54%/1.752 —— **与真实信号相当甚至更好**。
   → 闸门的"效果"等于**随机的有时不在场**，信号本身没有增量价值。
3. **§3.3 的日频预测力是真的（t=4.35、逐年 8/8），但无法转化为可交易改进**：
   日频统计测的是"触发日次日收益为负"，而落地要付两次换手、且第一天切走后后续触发日空转
   （不产生额外收益），真实可捕获的部分远小于统计口径。
   叠加策略本身的路径混沌（见 memory：0.6% 决策日 → 147pp 差异），信号贡献被噪声淹没。

## 1. 问题定义（证据）

### 1.1 两段回撤的解剖

| | 2021-01-22 ~ 2022-01-27 | 2026-06-25 ~ 2026-09-10 |
|:---|---:|---:|
| 持续 | 247 交易日（12 个月） | 56 交易日（2.5 个月） |
| 幅度 | −39.02% | −23.18% |
| 段内日波动（年化） | 24.28% | 低于常态 |
| 常态日波动（年化） | 25.29% | — |
| 往返笔数 / 胜率 | 59 笔 / 40.7% | ~16 笔 / 多数亏 |
| 市场背景 | A股核心资产崩 + 中概腰斩 | **横盘**（沪深300 +0.80%） |
| 诱因 | **所有资产同跌** | **没有趋势，动量选出已涨完的** |

**共同点**：都是「持续磨损」而非「单次爆仓」——段内波动率**不高于**常态。这排除了一整类对策（见 §2）。

### 1.2 2026 型的机制直接证据

2026-08 连续 6 笔全亏，逐笔查入场时标的的状态：

| 入场日 | 标的 | **信号日涨幅** | 前 5 日 | **前 25 日涨幅** | 结果 |
|:---|:---|---:|---:|---:|---:|
| 08-05 | 512690 酒 | −0.91% | +0.23% | **+9.80%** | −0.93% |
| 08-10 | 513050 中概 | +1.29% | −0.42% | **+14.52%** | −4.04% |
| 08-13 | 512690 酒 | +0.67% | +3.46% | **+17.23%** | −3.15% |
| 08-18 | 513030 德国 | −1.31% | +4.24% | **+11.27%** | −3.88% |
| 08-24 | 518880 黄金 | +1.87% | +5.47% | **+14.98%** | −3.81% |
| 09-01 | 512400 有色 | −0.92% | +2.06% | **+11.46%** | −0.74% |

**前 25 日涨幅全部 +9.8% ~ +17.2%（选股逻辑没坏），但买进去 3~8 天全部回落。**

→ **不是日频追高**（信号日涨幅全在 ±2%，一笔都触发不了 5% 的入场门），
→ **是月频动量在该段失效**（momentum crash）。

这也解释了为什么「入场涨幅门」结构上不可能有效——已在 [[strategy-oos-validation-standard]] 的两轮 A/B 中实测否决。

## 2. 可行性验证（已完成，先做验证再设计）

设计了 3 个候选信号，**先验证它们在那两段是否会触发**。结果 2 个被否决。

| 候选信号 | 2021 回撤段 | 2026 回撤段 | 其余时间 | 判定 |
|:---|:---|:---|:---|:---|
| **S1 横截面动量价差** | 均值 +0.011 / 负占比 49.0% | 均值 **−0.053** / 负占比 **74.5%**（8 月 100%） | +0.015 / 44.3% | ✅ **抓 2026** |
| **S2 指数效率比 ER(20)** | 0.155 / <0.10 占比 38.9% | 0.116 / 45.5% | 0.235 / 23.9% | ⚠️ 两者都偏弱但区分度不足 |
| **B 全球池自身宽度**（"A股弱+全球也弱→切国债"） | 0.504 / 双弱 13.0% | 0.489 / 双弱 19.6% | 0.555 / 双弱 17.3% | ❌ **无区分度，2021 甚至低于平时** |

> **闸门 B 的否决值得单独记一笔**：它看起来是最直观的方案（"A股和全球同时弱就真避险"），
> 但数据说 2021 那段全球池的宽度（0.504）跟平时（0.555）几乎一样——**当时的海外/商品并没有同步走弱**。
> 如果没先做这一步就动手写代码，会浪费一整轮实现 + 回测。

**结论：只保留 S1，只针对 2026 型。**

## 3. 信号定义（精确，无未来函数）

### 3.1 计算

每日收盘后（时刻 `t`）：

```
1. 对候选池每只 ETF（全球池 11 + 中国池 17，不含 511010），
   取最近 25 个交易日的日收益（etf_daily.pct_chg，Tushare 口径已含分红调整），
   复利得 mom25[c] = ∏(1 + pct_chg) − 1
2. 剔除当日无行情的标的；有效标的 < 8 只 → 本日信号不可用，沿用上一有效状态
3. 按 mom25 排序，取 Top3 与 Bottom3
4. spread[t] = mean( Top3 在当日 t 的收益 ) − mean( Bottom3 在当日 t 的收益 )
   ← 排序用的是 t-1 收盘的 mom25，收益是 t 当日的 → t 收盘即可知，无未来函数
5. eff[t] = Σ_{s=t-19}^{t} spread[s]        （滚动 20 个交易日的价差之和）
```

### 3.2 为什么用「价差」而不是别的

它直接度量**"按动量排序是否还有区分度"**——这正是 2026 型回撤被破坏的东西。
不用策略自身的盈亏（那等价于回撤刹车，滞后且自反），也不用指数方向（2021 型里指数方向变了但动量排序仍有效）。

### 3.3 预测力验证（已做，这是设计成立的前提）

对齐：`eff[t]`（t 收盘已知）→ 策略 `t+1` 的日收益（持仓由 t 收盘决策，t+1 生效）。

| 阈值 | 触发日数 | 触发日次日均值 | 未触发日次日均值 | 差 | t 值 | 逐年「未触发>触发」 |
|:---|---:|---:|---:|---:|---:|---:|
| eff < −0.03 | 523 (28.7%) | **−0.135%** | **+0.199%** | +0.334%/日 | **4.35** | **8/8** |
| eff < −0.05 | 344 (18.9%) | −0.143% | +0.161% | +0.303%/日 | 3.50 | 6/8 |
| eff < −0.08 | 185 (10.2%) | −0.223% | +0.140% | +0.363%/日 | 3.19 | 6/7 |

**三个阈值都显著、方向一致**——不是阈值挑出来的。**逐年 6~8/8 一致**——不是单靠 2026 那一段。

### 3.4 阈值触发率（决定误触代价）

| 阈值 | 2021 回撤段 | 2026 回撤段 | 2026-08 | 其余时间 |
|:---|---:|---:|---:|---:|
| 0.00 | 49.0% | 74.5% | 100.0% | 44.3% |
| **−0.03** | 32.4% | 58.2% | 90.5% | **27.0%** |
| **−0.05** | 23.1% | 49.1% | **71.4%** | **17.1%** |
| −0.08 | 17.0% | 34.5% | 42.9% | 8.2% |

**取值区间 `[−0.05, −0.03]`**：目标月触发 70~90%，平时误触 17~27%。低于 −0.05 抓不住目标，高于 −0.03 误触过大。

## 4. 执行设计

### 4.1 闸门行为

```
if eff[t] < momentum_efficacy_threshold:
    目标仓位系数 = dormant_scale      # 默认 0.3
else:
    目标仓位系数 = 1.0
```

作用点：`_compute_position_weights()` 产出的权重**统一乘以该系数**，
再走既有 sizing（`min(capital × weight, available)`，见 `策略资金与仓位契约.md` §2.1）。

剩余资金留在现金。**不切换到 511010**——理由：切国债需要额外一次买卖（换手成本），
而闸门是"临时降暴露"而非"换防御标的"，现金更干净、退出更快。

### 4.2 与现有 regime 判档的关系

**正交叠加，不替代**：
- regime 判档决定**从哪个池选**（走弱期 = 全球池；正常期 = 全球+中国池）
- 动量失效闸门决定**选出来之后下多少仓位**

两者叠加。需要验证叠加后不冲突（见 §6 判据 5）。

### 4.3 恢复条件

`eff[t] >= threshold` 即恢复满仓系数。**不加额外的确认天数**——理由：
本策略已实测证明「去抖有害」（`weak_confirm_days` 单调恶化，见 memory）；
且 §3.3 的预测力本身就是日频的，加确认天数会滞后。

## 5. 参数（只暴露 2 个）

| 参数 | 默认 | 说明 |
|:---|:---|:---|
| `momentum_efficacy_threshold` | `-0.04` | 触发阈值，取值区间 `[-0.05, -0.03]`；调低 → 更少触发 |
| `dormant_scale` | `0.3` | 触发时的仓位系数，取值 `{0.0, 0.3, 0.5}`；0.0 = 完全空仓 |

**固定的常量（不暴露为参数，减少过拟合面）**：动量窗口 25 日、Top/Bottom 各 3 只、价差滚动 20 日。
这三个值取自策略自身的既有口径（`lookback_days=25`）与常用默认，**不做扫描**。

总参数数 = 2（对比：现有 `DEFAULT_PARAMS` 已有 40+ 个，但这是新增的机制，2 个已经不少）。

## 6. 验证方案

### 6.1 核心约束（必须先说清楚）

**2021 和 2026 是 motivating examples，在样本内。** 任何"全窗口跑赢"都可能只是贴住了这两段。

→ **真正的检验是：在不含这两段的时期，它是否也不亏。**

### 6.2 切分

| 段 | 区间 | 性质 |
|:---|:---|:---|
| **段 A** | 2019-03-12 ~ 2021-01-21 | **前置，不含两段** ← 最重要 |
| **段 B** | 2022-02-01 ~ 2026-06-24 | **中置，不含两段** ← 最重要 |
| 段 C | 全窗口 2019-01-31 ~ 2026-09-11 | 含两段（可比总账） |
| 滚动起始日 | 12 个（沿用 `scripts/backtest/rolling_start_analysis.py` 口径） | 分布 |

**臂**：
- `OFF`：`momentum_efficacy_threshold = 有效值之外`（如 −1.0，永不触发）= 基线
- `ON@0.3`：threshold −0.04、dormant_scale 0.3
- `ON@0.0`：threshold −0.04、dormant_scale 0.0（完全空仓，看上限）
- `LEV@0.3`：**对照组** —— 全期恒定 `single_etf_max_position=0.3`（纯降杠杆，无闸门）

> `LEV@0.3` 这一臂是关键：它把"闸门的贡献"与"单纯降杠杆的贡献"分开。
> 若 `ON@0.3` 不显著优于 `LEV@0.3`，说明闸门没用，只是杠杆。

### 6.3 成功判据（预先写死，事后不得修改）

1. **段 A 与段 B**：收益相对基线下降 ≤ 15%，**且夏普不下降**（两段都要满足）
2. **段 C**：最大回撤改善 ≥ 5pp，且收益下降 ≤ 10%
3. **`ON@0.3` 显著优于 `LEV@0.3`**（同样的平均仓位下，闸门应带来更高收益或更低回撤）
4. **阈值邻域** `{−0.05, −0.04, −0.03}` 方向一致（不得只有一个值好）
5. **`dormant_scale` 邻域** `{0.0, 0.3, 0.5}` 方向一致
6. **滚动起始日**：MDD 中位数改善 ≥ 5pp，收益中位数下降 ≤ 15%

### 6.4 失败判据（红线）

- **若改善只出现在 2021/2026，而段 A 或段 B 变差 → 判为曲线拟合，立即放弃。**
- 判据 3 不满足 → 闸门无增量价值，退化为降杠杆，放弃。
- 判据 1 任何一段不满足 → 放弃。

**放弃后不留半成品**：参数保留在代码里但默认关闭，并在注释里记录否决理由（沿用该文件既有惯例）。

## 8. 已知风险

| 风险 | 说明 |
|:---|:---|
| **样本内设计** | 2021/2026 是动机来源。缓解：§6.2 的段 A/B + §6.4 红线 |
| **现金拖累** | 触发日持现金（0 收益）。若触发日占比 20%，年化拖累约等于"20% 仓位闲置" |
| **换手上升** | 闸门进出各产生一次调仓。策略已 50 次/年换手，需监控 |
| **与 regime 的交互** | 两套状态机叠加可能产生意料外的状态组合。缓解：判据 5 |
| **信号自身的稳定性** | 横截面动量价差是市场微观结构现象，可能随市场参与者变化而衰减 |
| **不能解决最大回撤** | 见 §0。若用户的真实目标是 −39%，本方案无法交付 |

## 9. 备选（若本方案失败）

1. **常态降杠杆**：`single_etf_max_position` 0.9 → 0.6，MDD 约 39% → 26%，收益等比下降。
   免费、可量化、随时可调，但 Sharpe 不变——是自助，不是优化。
2. **组合分散**：唯一能"不牺牲收益降回撤"的路径。需引入低相关策略（见 `多策略整体架构规划.md`）。
3. **接受现状**：把 39% 回撤 / 2.3 年修复期写进实盘预期管理。
