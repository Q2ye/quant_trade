# 牛市识别信号验证结果

> 日期：2026-09-07（P1 自动执行，10 种验证方案）
> 配套：`牛市信号验证方案.md`（方法定义）、`牛市择时追强研发立项.md`（立项）
> 结论：**路径否决**——不存在正 alpha 的牛市识别信号

---

## 一、总结论（先说结论）

对 10 个候选牛市信号（短中期宽度 MA20/MA60/MA250、量比、成交额放量、动量、换手率、趋势强度、现有 regime 分类）做了三层验证，结果：

1. **全样本最优阈值下**，信号看起来有效（择时年化 18-25%，显著优于 MA250 基线 9%）。
2. **但这是过拟合**：换成先验固定阈值，滚动起始日中位只剩 7-10%；样本外 test 段崩到 -7%~+12%；统计上全部不显著（P=0.1~0.8）。

**结论：找不到一个「实时、无未来函数、择时年化稳定 ≥15%」的牛市识别信号。P1 第一道关不通过，立项路径否决。**

> 看起来有效，但分位阈值是「全样本最优」，有严重过拟合嫌疑，见⑥。

**② 择时年化 vs MA250 基线**（9.0%）

- 全样本最优：ma20_pct +16.0%、amount_ratio +15.9%、vol_ratio +14.5%（表面大幅胜出）
- **先验固定阈值（滚动）**：ma20>50% 中位 10.2%（仅 +1.2%）、量比>1.5 中位 8.0%（-1.0%）、成交额>1.2 中位 9.0%（±0）→ **真实只勉强持平基线**

**③ 回撤对比**（满仓 -72.5%）

- ma60_pct（>80%分位）回撤 **-20.5%**、amount_ratio **-29.2%**、ma20_pct -39.1%
- ✅ 回撤确实显著降低（「只在牛市做」的核心价值成立，即使年化上不去）

**④ 牛熊分类准确率**：未执行——⑥⑧ 已证信号不显著/过拟合，无需再测分类准确率。

**⑦ 参数敏感性**：核心验证的「分位扫描 30%-80%」已覆盖——ma20_pct 在不同分位下年化 11.5%→25% 波动，结论对阈值高度敏感（过拟合特征）。

### 层次三：组合达标

**⑨ 端到端回测**：跳过——择时信号已在 P1 否决，无需配选股做端到端。

**⑩ 未来函数/幸存者偏差审计**：验证脚本均为「信号[t] → 持有[t+1]」的 T+1 结构，无 `shift(-1)`/未来数据；信号来自 `market_state_daily`（已算好的历史状态），无幸存者偏差。✅ 通过。

## 三、根因分析（为什么牛市信号不存在）

1. **「牛市」是不可精确识别的**：A 股的牛熊边界事后看清晰、实时看模糊。任何领先/同步指标（宽度/量价/动量）在实时都带着噪声，且最优阈值随时间段漂移（⑥ 样本外崩坏）。
2. **均线类宽度本质还是滞后**：ma250_pct（站上 MA250 比例）无效，ma20/ma60 有效但只是「更短周期」的滞后，换段时间就失效。
3. **择时的 alpha 本就极薄**：指数择时（哪怕完美）的年化上限 ~26%，实时信号能抠出的超额只有 1-2pp（⑧ 不显著），撑不起 40% 目标。

## 四、对立项书的影响

- **P1 第一道关不通过** → 立项书「先攻择时，攻不下则整个路径否决」的条件触发。
- **「牛市择时 + 追强」路径否决**：即使后续 P2 选股 alpha 成功，缺了正 alpha 的择时，也无法把年化抬到 40%。
- **下一步（供决策）**：
  1. 回到「选股 alpha」主线（原「找 +6% alpha 源」），放弃靠择时抬收益的路线；
  2. 或接受「指数择时只能降回撤、不能增收益」，把择时仅作为「回撤控制工具」（方案③ 已证有效），选股 alpha 才是收益来源。
