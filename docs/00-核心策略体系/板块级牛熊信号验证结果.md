## 五、最终结论

1. **全市场级牛熊识别：死路**——14 个信号（宽度/量价/动量/情绪/新高新低/涨跌家数/PE/波动率）固定阈值下均无实质 alpha。
2. **板块级牛熊识别：活路**——**新能源（电力设备）板块**的牛熊可被「趋势 MA60 / 相对动量转正 / 成交额放量」识别，择时超额中位 11-14%、滚动下四分位 >10%、样本外不崩。
3. **特征**：成长板块（新能源、计算机）+ 周期板块（有色）有效，防御/金融（银行）无效——符合「成长板块有独立景气周期、更可识别」的假设。

## 六、遗留局限（诚实说明）

- **bootstrap 显著性 P=0.13**（边际）：14 年样本量不足，需更多数据或实盘验证。
- **多重比较**：8 行业 × 9 信号 = 72 测试，「新能源」可能是部分幸存者；但滚动下四分位 >10% 已大幅降低此风险。
- **交易标的**：申万指数不可交易，落地需映射到「新能源行业 ETF」（如 515790 光伏 / 516160 新能源 / 159516 半导体设备）。
- **板块内宽度**（Phase 3 原计划）：成分股数据较重，未做，留待后续。

## 七、追加发现（2026-09-07 分时代诊断 + 组合验证）

> 用户指出「全市场判断需做组合、不同时期用不同指标」。追加验证证实了这一点，并修正了「全市场级无 alpha」的结论。

### 7.1 分时代诊断（证实「时代平均化」）

4 个时代分别测各指标的择时超额（vs 满仓），发现**每个时代的「最有效指标」不同**：

| 时代 | 满仓 | 最有效指标 | 超额 |
|:---|:---|:---|:---|
| 06-10 | 44.8% | 宽度20 | +13.8% |
| 11-15 | 15.7% | 涨跌家数比 | +19.7% |
| 16-21 | -3.2% | 量比 | +16.6% |
| 22-26 | -1.0% | 宽度20 | +18.1% |

**关键**：没有任何单一指标在所有时代都最有效——这正是「20 年单一指标测出无 alpha」的原因（时代平均化抹平）。

### 7.2 涨跌家数比（相对阈值）是唯一跨时代为正的信号

| 时代 | 涨跌家数比超额 |
|:---|:---|
| 06-10 | +6.3% |
| 11-15 | +19.7% |
| 16-21 | +8.6% |
| 22-26 | +10.2% |

**根因**：之前用「绝对阈值 >0.5」测出超额仅 +0.7%，改用「相对阈值 >滚动500日中位数」就显出了 alpha（滚动中位 +7.5%、下四分 +5.5%）。**问题不在指标，在阈值口径**。

### 7.3 组合（简单投票）不提升

| 规则 | 滚动中位超额 |
|:---|:---|
| 单一涨跌家数比 | +7.5% |
| 组合≥2票 / ≥3票 / ≥4票 | +7.3% / +5.0% / +7.1% |

**原因**：涨跌家数比已是「全市场涨跌聚合」的综合宽度，与宽度20/60 冗余。要提升需「不同维度」信号（资金流/估值），但数据不足（北向仅 3 个月、PE 仅 2018 起）。

| 信号 | 中位超额 | 下四分 | 结论 |
|:---|:---|:---|:---|

### 北向净流入的稳健性（关键）

- 样本外：train(14-20) **-5.9%** → test(20-26) **+11.1%**（严重分化）
- bootstrap：P=0.306（不显著）

**结论**：北向净流入的 alpha 是「时代依赖」的——北向成为「聪明钱」是 2019 之后的事（2014-2016 是配置型外资）。它的 +11.1% 主要来自 2020-2026，不是跨时代稳健信号。

### 补数据的终极认知

1. 全市场级不是无 alpha，而是「缺资金流维度」——补北向后 alpha 显出来了；
2. 但所有信号都是时代依赖的：涨跌家数比跨时代较稳（+7.5%），北向依赖 2019 后（+11.1% 但样本外分化），两融无效；
3. 板块级（新能源）仍是最稳健的（样本外两边正）。
