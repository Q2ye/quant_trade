> 信息仅供参考，不构成投资建议
> 2026-08-21 首版 · 2026-08-21 架构评审修订
> 整合 5 份设计文档，形成「主策略 + 卫星策略」双层资金架构的总体规划

## 一、架构总览

**核心思想**：总资金按比例切成两个**永不互通**的资金池——

- **主策略资金池（75%）**：日常常态运行，承担主收益（牛市进攻 / 震荡防守 / 熊市空仓）
- **卫星策略资金池（25%）**：平时闲置（现金/货币基金），仅在特定信号触发时出击

```
总资金（以 20 万为例，按实际资金等比缩放）
├─ 系统基建层（回测增强 + 策略失效监控）── 支撑所有策略，非资金层
│
├─ 主策略资金池：15 万（75%）
│   市场状态判断模块（regime）
│   ├─ 牛市进攻策略     ── 7.1 高波动动量（已上线）
│   ├─ 震荡/熊市防守策略 ── ETF 底部防守（已上线）
│   └─ 增强槽位：空置（V2 已评估删除：收益不达标 + 与 7.1 动量同质）
│   > 目标：总收益 +350%（回测），最大回撤可控
│
└─ 卫星策略资金池：5 万（25%）—— 独立账户，订单路由隔离
    ├─ 进攻型卫星：微盘股策略（常态仓位 + 双指数择时）
    ├─ 事件型卫星：极端事件归零博弈（恐慌抄底）── 先落地
    └─（资金 ≥50 万触发）股指期权押注（IV 接入后）
    > 平时：现金 / 货币基金；触发时：按子仓出击
    > 目标：不追求年化——追求单次进攻倍数（一次大机会博 1.3x~10x）
```

**与现有文档体系的关系**（4 份）：

| 层 | 文档 |
|:--|:--|
| 规划 | 本规划（架构/资金池/策略定位） |
| 策略设计 | `策略设计.md`（恐慌抄底 + 期权 + 微盘） |
| 基建设计 | `基建设计.md`（回测增强 + 失效监控 + 实盘监控） |
| 实施 | `策略设计实施计划.md`（阶段/里程碑） |

本规划把已有/在研的策略统一归置到双层架构下，明确每个策略的**资金归属、触发条件、交互规则与落地优先级**，避免各策略各自为战。

## 二、系统基建层（支撑层，非资金层）

> 对应 `基建设计.md`，是所有策略验证与监控的基础，**P0 先行**。

| 能力 | 服务谁 | 状态 |
|:--|:--|:--|
| 回测报告增强（卡玛/分年度/回撤区间/连续亏损/持仓天数） | 主策略、卫星策略、全部新增策略的回测验证 | 后端已实现（2026-08，5 指标入 to_dict）；前端卡片/分年度表待 A2 |
| 策略失效监控（healthy/warning/stop 三级） | 对**两个资金池内所有运行中策略**每月体检，事前预警 | 已实现（2026-08，策略健康端点 healthy/warning/stop） |
| 实盘监控（当日盈亏/总回撤/可用资金三个数） | 组合层，防单策略失效拖垮整体 | 部分实现（当日盈亏/可用资金已展示；阈值预警待 B4） |

**为什么放最高层**：卫星策略（恐慌抄底/微盘）的"反例统计"，全部依赖增强后的回测报告；失效监控则是"组合长期不出大问题"的保障。

## 三、主策略资金池（75%）

### 3.1 市场状态判断模块

复用现有 `market_state_classifier` + `market_state_daily`，输出 regime：

| regime | 含义 | 主策略动作 |
|:--|:--|:--|
| 0 熊市 | 大盘年线下 | 空仓/退守防御 |
| 1 震荡 | 无趋势 | 防守优先 |
| 2 牛市 | 年线上且趋势向上 | 进攻满仓 |

> 该模块同时被卫星策略共享（见 §4.1），是全系统统一的"环境感知层"。

### 3.2 主策略体系（已上线）

| 条线 | 策略 | 适用 regime | 定位 | 资金分配 |
|:--|:--|:--|:--|:--|
| 进攻 | 7.1 高波动动量（`HighVolMomentumStrategy`） | 牛/震荡 | 右侧追强，第一性原理 | `REGIME_BASE_ALLOCATION`：熊 0.1 / 震 0.8 / 牛 1.0 |
| 防守 | ETF 底部策略（`LightGBMBottomStrategy`） | 熊/震荡 | 控制回撤，价值承接 | 熊 0.9 / 震 0.2 / 牛 0.0 |

**组合机制**：`CapitalAllocator` 按 regime 在进攻/防守间分配主策略池资金，每日 rebalance 同步 `allocated_capital`。

**组合回测效果**（2021-2026 实测）：
- 主策略组合：**+348%** / Sharpe 1.41 / **MDD 18.9%**（7.1 单独：+354% / MDD 24.7%）
- 防守策略把回撤压低 ~5.8pp，代价是收益微降——组合形态优于单进攻

> 规划文档中"总收益 +350%、最大回撤 -14%"为规划目标口径，实际回测数据以组合实测为准（+348%/18.9%）。

### 3.3 主策略增强槽位（2026-08-21 修订：V2 删除，微盘归卫星池）

| 候选 | 结论 |
|:--|:--|
| ~~全球资产动量 V2 增强~~ | **已删除**（2026-08-21）：收益不达标（宣称年化 40-60% 实际不佳）+ 与 7.1 同属动量追强、风格同质。「同槽轮换」原则保留——未来新增动量策略与 7.1 同槽，不并行满仓 |
| ~~微盘股策略~~ | **移入卫星池**（进攻型卫星，见 §4.4）——微盘有独立崩盘风险，不该用主池资金承担 |

> **关键修正（2026-08-21 评审）**：微盘策略**不放主池**。其 2024-01 式独立崩塌风险，若用主池 75% 资金的一部分承担，会击穿主策略 MDD 目标。归入卫星池后，微盘危机只影响卫星池 25%。

## 四、卫星策略资金池（25%）

### 4.1 定位与资金规则（评审修订：子仓结构）

| 项目 | 内容 |
|:--|:--|
| 资金 | 总资金 25%（5 万/20 万），**独立账户** |
| 平时状态 | 现金 / 货币基金，**不参与主策略任何持仓** |
| 市场状态判断 | **共享主策略的 regime 模块**，不重复造轮子 |
| 触发原则 | 只在特定信号确认后出击，平时零敞口 |
| 目标函数 | **不追求年化**——平时闲置可接受，追求单次博弈回报倍数（恐慌 1.3-1.6x / 期权 3-11x） |

**子仓结构**（评审修订：卫星池不是单一策略，按风险特征分两个子仓）：

| 子仓 | 策略 | 仓位特征 | 触发特征 |
|:--|:--|:--|:--|
| **进攻型卫星** | 微盘股策略（§4.4） | 有常态仓位 + 双指数择时 | 市场允许时持续运作 |
| **事件型卫星** | 恐慌抄底（§4.2） | 平时空仓，信号后全仓 | 恐慌信号触发，事件性 |

> **为什么分两仓**：微盘"平时持仓、择时避让"，恐慌抄底"平时空仓、事件出击"，两者行为模式完全不同，且同一资金池内由子仓 allocator 协调（微盘危机时：微盘避让 → 恐慌抄底接棒，时间互补）。

### 4.2 事件型卫星：极端事件归零博弈（恐慌抄底）——先落地

> 对应 `策略设计.md` §二（恐慌抄底），数据**全部齐备**（stock_daily + market_state_daily + index_daily），可回测、与主策略时间互补。

**与 ETF 底部策略的定位差异**（2026-08-21 澄清：不构成重复 alpha）：

| 维度 | ETF 底部（主池防守） | 恐慌抄底（卫星事件） |
|:--|:--|:--|
| 目标 | **熊市防守**，胜率优先，控回撤 | **博翻倍**，赔率优先，事件博弈 |
| 触发 | 日常滚动（LightGBM 概率 >0.54） | 极端恐慌事件（每年 1-3 次） |
| 风险-收益 | 高胜率 / 低赔率 | 低胜率 / 高赔率 |

> 两者是**不同风险-收益定位**的主池防守阀 + 卫星高赔率事件博弈，不视为"同一超跌反转下双注"。但恐慌日可能同买超跌 ETF → 组合层需**标的冲突检测**，或恐慌抄底偏向超跌个股分工。

**触发（三重确认 + 年线门）**：

```
【门控前置】年线门：CSI500 收盘 < MA250 → 熊市恐慌 = 趋势中继，直接放弃（2018/2022 教训）
T 日        条件A 恐慌指数 = |全市场跌幅中位数| × 下跌比例 > 阈值
            条件B 沪深300 年线下5% / 距前低3% / 5日跌8% 任一
T+1 日      条件C 抛压衰竭：成交额 < 恐慌日 80%，且恐慌指数未再创新高
T+2~T+6 日  真恐慌确认：恐慌指数回落 < 1.5 或沪深300 收阳
→ T+7 日开盘执行买入
```

**买入**：候选池（超跌股 5 日跌 >15% + 质量分加权 或 指数 ETF），Top 5-10 只，单票 ≤10%。
**卖出**：阶梯止盈（15%/30%/50% 三档 + 恐慌指数回 <1.0 清仓 + 20 日时间兜底）；止损单票 15% 即走。
**仓位**：事件型子仓全仓出击（方案 A 分散 10 只×10%，或方案 B 集中 3-5 只×20-30%）。

**前置验证（反例统计，必做）**：2019-2025 恐慌信号逐日回放，统计**假恐慌占比**（信号后 20 日下跌比例）**与收益分布尾部**（不只均值）。假恐慌占比 <30% 才实现；年线门过滤效果同时验证。

### 4.3 期权：股指期权集中押注（资金 ≥50 万触发 IV 接入）

> 对应 `策略设计.md` §三（期权）。**当前数据缺失（无 IV 数据源）**，为远期规划。
> **2026-08 里程碑修订：当实盘资金达到 50 万时，接入 IV 数据源，期权从远期转为可实施** —— 期权（单次 3-11x）是冲刺 500 万目标的唯一大增量工具（`系统目标与投资哲学.md` §2.3）。
> 核心结论不变：`HV 无法代理 IV`，proxy 仅作研究、**不构成期权可行性依据**。IV 数据接入前不做任何期权功能开发。详见 `策略设计.md`。

### 4.4 进攻型卫星：微盘股策略 + 双指数择时（评审修订：从主池移入）

> 对应 `策略设计.md` §四（微盘股）。**归入卫星池**（进攻型子仓），理由：微盘有独立于大盘的崩塌风险（2024-01），用卫星池 25% 承担，而非主池 75%。

| 项目 | 内容 |
|:--|:--|
| 核心逻辑 | 微盘股低定价效率 + 壳价值提供阿尔法；择时规避微盘系统性崩塌 |
| 选池 | circ_mv < 50 亿 + 退市/流动性过滤（近 20 日成交额 > 3000 万）+ 营收/市净率门槛，市值最小 50 只，每月重选 |
| 择时 | **双指数确认**：门控1 大盘 regime（BULL）+ 门控2 中证2000 收盘 > 20日均线（防微盘独立崩塌）——双门同时通过才买入 |
| 买入 | Top 10-20 只等权，单票 ≤5%，总仓 ≤80% |
| 风控 | 单票止损 10%；任一门关闭 → 整体空仓；浮盈 30% 减半 |
| 与恐慌抄底联动 | 微盘危机：门控2 关闭 → 微盘避让空仓 → 恐慌指数飙升 → 恐慌抄底（§4.2）接棒 → 先避让 + 后抄底 |

**前置验证（反例统计，必做）**：微盘阿尔法真实存在（跑赢沪深300）+ 门控2 能防 2024-01 危机（危机前触发空仓）+ 2019-2023 微盘池数据完整性。

## 五、两资金池交互规则

### 5.1 三种运行状态

| 状态 | 卫星池 | 主策略池 |
|:--|:--|:--|
| **正常（平时）** | 现金 / 货币基金（进攻型微盘可有常态仓位） | 按 regime 正常运行 |
| **触发时（恐慌/变盘）** | 事件型子仓全仓出击（抄底 / 期权） | **不受影响**，按原计划运行 |
| **极端（灾难级恐慌，如 2024-01）** | 微盘避让 + 抄底接棒，可能赚钱 | 回撤加大（主策略此时大概率已止损空仓） |

### 5.2 三条铁律（评审修订：铁律2 修正、新增铁律3）

```
铁律1：卫星资金 ↔ 主策略资金 永不互通
  - 主策略亏损不挪用卫星资金，卫星策略爆亏不拖累主策略净值
  - 触发抄底时，主策略资金（75%）不参与、不接棒、不补充
  - 注意：卫星收益留在卫星池 → "对冲"是组合净值层面摊薄，非"救主池"（见 §5.3）

铁律2：单次事件博弈亏损上限 = 卫星池的 40%（修订）
  - 事前：每笔抄底 ≤ 事件型子仓 60%（留现金防连跌停补仓）+ 单票 ≤10%
  - 事后：-40% 强制清仓（预留 10% 缓冲，应对流动性枯竭无法即时成交的滑点）
  - 修订原因：原"-50% 红线"是事后止损线，恐慌抄底在连跌停时无法执行止损，会击穿 → 改事前仓位上限 + 事后强制线双保险

铁律3（2026-08 修订）：卫星池滚动复利 + 规模上限
  - 修订前：每年末卫星池恢复至总资金 25%（盈利全额回流主池）——抑制卫星复利，与"卫星补缺口"矛盾
  - 修订后：卫星池利润**滚动复利，不强制年度回流**；仅当卫星池规模 > 总资金 40% 时，超出部分回流主池（规模上限防风险失控）；亏损后维持现状（不注资、不补足）
  - 目的：让卫星池具备 5 年滚动复利能力（冲刺 500 万的关键，见 `docs/01-业务设计/系统目标与投资哲学.md` §2.4），同时用规模上限约束暴露
  - ✅ 已代码化（2026-08 阶段 4d）：`modules/strategy/engines/satellite_allocator.py`（check_reflow / check_panic_position / allocate 子仓分配），单测 9/9 通过；策略实例已绑定卫星账户（恐慌抄底-卫星 / 微盘-卫星，模拟盘 draft）
```

### 5.3 极端事件对冲逻辑（评审修订：需回测验证，非假设）

**为什么卫星池在 2024-01 能对冲主策略**：
1. 主策略（7.1 追强）在暴跌中天然止损空仓 → 回撤加大
2. 恐慌指数飙升（≈8.0）触发卫星抄底信号 → 卫星资金抄底微盘/超跌股
3. 2 月反弹（微盘 +30%~+60%）→ 卫星池大赚
4. 恐慌消退（指数回 <1.0）→ 卫星清仓落袋

**定量修正**（评审）：若主池回撤 20%、卫星满仓赚 50%：
```
组合 = 75%×0.8 + 25%×1.5 = 97.5 → 仍亏 2.5%
```
对冲只**摊薄组合回撤**，不转亏为盈。且"主策略恐慌时大概率已空仓"是**假设**——若主策略实际未空仓（历史 MDD 24.7%），定量完全不同。

> **⚠️ 必须回测主策略在 2024-01/2022-04 恐慌期的实际行为**（是否空仓、实际回撤幅度），验证对冲逻辑成立，不能假设。此项列入实施计划（见 §七）。

## 八、风险与原则

### 8.1 风险

| 风险 | 说明 | 缓解 |
|:--|:--|:--|
| 卫星策略收益不确定 | 恐慌不触发时 25% 资金长期闲置 | 闲置资金放货币基金，接受机会成本 |
| 假恐慌误抄底 | 半山腰接飞刀 | 三重确认 + 年线门 + 真恐慌确认（反例统计前置） |
| 卫星单次亏损超限 | 抄底抄在半山腰 / 流动性枯竭 | 铁律2：事前 ≤子仓60% + 事后 -40% 强制清仓 |
| 卫星池越打越小 | 连亏后规模萎缩 | 铁律3：年度再平衡恢复至总资金 25% |
| 主策略增强劣化 | 未来新增策略拉低 7.1 组合表现 | 对照回测 + 不劣化才占用增强槽位 |
| 对冲逻辑不成立 | 主策略恐慌期未空仓 | M2b 回测验证，不假设 |
| 资金池隔离落地复杂 | 现有系统为单资金池 | M1b 订单路由改造单列，先设计后开发 |
| 失效监控误报 | 自然回撤误判失效 | warning/stop 分级，仅 stop 停用 |

### 8.2 核心原则

1. **先验证后实现**：所有新策略（微盘/恐慌抄底）先用数据证明逻辑成立，再写代码——吸取 7.1→8.0→8.1→9.0 反复迭代的教训。
2. **资金永不互通**：三条铁律是架构地基，任何收益诱惑都不破坏隔离。
3. **风险归属正确**：高波动独立崩盘风险（微盘）放卫星池，主池只承担 regime 切换风险。
4. **优先成熟方案**：恐慌抄底数据齐备、可回测、与主策略互补，是事件型子仓的第一落地策略；期权等数据接入后评估。
5. **卫星策略以单次倍数为目标**：不追求年化——平时闲置可接受，博一次大机会让收益最大化。
6. **目标排序（2026-08 更新）**：系统进入**前期资金快速膨胀期**——三档制目标（底线 ≥3x / 基准 5-8x / 冲刺 10x+ = 500 万）；主策略实证年化 36.67%（7.1 实盘组合）为底线保障；**卫星策略不追求年化、只追求单次进攻收益**；资金 ≥50 万触发 IV 接入 → 期权转可实施（冲刺唯一大增量）。目标唯一真相源：`docs/01-业务设计/系统目标与投资哲学.md`。
