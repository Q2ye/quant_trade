## 〇、一句话

**问题**：`loss = 0.97`（3 日内任一日跌 3% 即剔除）对全池 29 只共用。标的年化波动从 **1.5%（国债）到 38.0%（通信）**，同一绝对阈值在低波动标的上形同虚设、在高波动标的上过度触发。
**假设**：把该阈值按标的自身波动缩放，能在不劣化回撤的前提下减少无效剔除。

## 一、假设

| # | 假设 | 可证伪观测 |
|:--:|:---|:---|
| H1 | 3 日跌幅门在高波动标的上过度触发 | 通信/半导体/新能车的"因 loss 门被剔除"天数显著高于国债/黄金 |
| H2 | 过度剔除造成的是"误杀"，不是"正确避险" | 被 loss 门剔除后的 20 日，高波动标的平均收益 > 0（即剔错了） |
| H3 | 按波动缩放后，总收益不降、回撤不升 | 见 §三判据 |

> **H2 必须先单独验证**：若被剔除后的高波动标的继续下跌，则门是有效的，本方向直接作废，不必做 A/B。

## 二、实验臂（单变量推进）

| 臂 | 改动 | 说明 |
|:--|:--|:--|
| **BASE** | 无 | 现状 `loss=0.97, ma_threshold=1.0` |
| **A（loss 缩放）** | 3 日跌幅阈值改为按 60 日波动缩放 | 主方案 |
| **B（MA 缓冲）** | 均线门加波动相关缓冲 | 备选，单独测 |
| **A+B** | 两者同开 | 仅当 A、B 各自通过才测 |

### 2.1 公式（写死，不留自由度）

```
σ_i(t)      = std(日收益, 60) × √252        # 不足 60 根 → 本标的退回未缩放（fail-closed）
σ_d_i(t)    = σ_i(t) / √252
loss_thr_i  = k × σ_d_i,   k = 0.03 / (0.20/√252) = 2.3810
              # 参考波动 20% 时恰好复现 -3%，保证基准点不变
ma_buffer_i = max(0, 0.02 × (σ_i/0.20 − 1))
              # 参考波动及以下 = 0（与现状逐位一致）；越高波动给越大缓冲
```

参考点校验：`σ=20%` → `loss_thr=3.0%`、`ma_buffer=0` → 与 BASE 完全相同。

各标的的阈值（用 2026-11-11 的 60 日波动）：

| 标的 | σ | loss 阈值 | ma 缓冲 |
|:--|--:|--:|--:|
| 国债 511010 | 1.5% | 0.23% | 0 |
| 黄金 518880 | 29.2% | 4.4% | 0.9% |
| 通信 515880 | 38.0% | 5.7% | 1.8% |

## 三、判据（跑之前冻结）

### 3.1 前置检验（不过则不做 A/B）

- **P1**：被 `loss` 门剔除的样本，剔除后 20 日平均收益 > 0（即"误杀"多于"避险"），且在高波动组（σ>25%）显著。
- **P2**：高波动组被剔除频次 ≥ 低波动组的 3 倍。

### 3.2 主终点（全部满足才通过）

| # | 判据 | 口径 |
|:--:|:---|:---|
| 1 | `total_return` 不低于 BASE | 2021-09-20 → 2026-09-19 |
| 2 | `max_drawdown` 不劣于 BASE + 1pp | 同上 |
| 3 | `calmar_ratio` 不低于 BASE | 同上 |
| 4 | 两段样本外同向（观察段 2021-07~2023-12、验证段 2024-01~2026-09） | 均不劣于 BASE |
| 5 | 12 个滚动起始日：收益中位数与下四分位均不低于 BASE | `backtest-rolling-start-standard` |
| 6 | **安慰剂**：把 σ 随机错配到其他标的（保持分布、破坏对齐）10 次，取中位 | A 臂须优于安慰剂中位 |

### 3.3 次终点（不满足需解释）

| # | 观测 |
|:--:|:---|
| 7 | 高波动组（σ>25%）被剔除天数下降 |
| 8 | 黄金 2026 的三笔交易是否改善（−847,476，胜率 0） |
| 9 | 国债 511010 是否被新阈值误杀（应为否：其阈值 0.23% 只在真正的异常日触发） |
| 10 | `num_trades` 变化幅度（预期 ±15% 内） |

### 3.4 红线

- 默认关闭（`enable_vol_scaled_gates=False`）时与 BASE 不逐笔一致 → 作废
- 出现未来函数（σ 用到 t 日之后的数据）→ 作废
- 收益集中度恶化（前 5% 交易贡献 >45%）→ 不通过
- MDD 恶化 >1pp → 直接否决，不进邻域

- 邻域（仅通过后做）：`vol_lookback ∈ {40,60,90}`、`vol_ref ∈ {0.15,0.20,0.25}`

1. 前置检验 P1/P2（用现有回测逐日诊断，不跑回测）。
2. BASE 复跑，须与 task `5a43816c` 逐笔一致。

## 八、前置检验结果（2026-11-14 已跑，判据未改）

脚本：`quant_server/scripts/_diag/_loss_gate_probe.py`。口径：复权价；样本为「动量 0~5 + R²>0.47」已通过的 9,341 条（2021-03 ~ 2026-10）。

### P2（剔除频次）—— **通过**

| σ 组 | 样本 | 被剔除 | 剔除率 |
|:--|--:|--:|--:|
| 低（<15%） | 2,516 | 3 | **0.12%** |
| 中（15~25%） | 3,474 | 79 | 2.27% |
| 高（>25%） | 3,351 | 422 | **12.59%** |

高/低 = **105 倍**，远超 3 倍门槛。

### P1（剔除后 20 日收益）—— **不通过原判据**

| σ 组 | 被剔除：均值 / 中位 / 正收益占比 | 通过：均值 / 中位 / 正收益占比 |
|:--|:--|:--|
| 低（<15%） | +7.94% / +8.75% / 100%（3 笔） | +1.26% / +0.41% / 65.4% |
| 中（15~25%） | **−0.73% / −1.67% / 32.9%** | +0.78% / +0.17% / 50.9% |
| 高（>25%） | **+0.19% / −0.78% / 44.8%** | +0.17% / −0.31% / 48.2% |

- 高波动组：被剔除 vs 通过 **差 +0.01%** → **无判别力**，不是"误杀"。
- 中波动组：被剔除 −0.73% vs 通过 +0.78% → **门在该组有效**。
- 原判据要求"高波动组剔除后收益 >0 且显著"，**+0.01% 的差不算显著 → P1 未通过**。

### 结论修订

原假设「高波动标的上过度触发 = 误杀」**不成立**。真实结构是：

1. 剔除率随波动单调上升（P2 成立）；
2. 但在高波动组，被剔除的样本与通过的样本后续表现**没有差别** → 这道门在该组**只消耗样本、不提供信息**；
3. 在中波动组，门**确实有效**（剔对了）。

→ 波动归一化的价值从"救回误杀"改为"**去掉高波动组的无信息剔除、同时保住中波动组的有效剔除**"。原 §三 判据 1–6 仍然适用，但**优先级下调为 P1，且必须在 `REQ-20261112-whipsaw` 之后单独跑**（两者都作用于出场/过滤，同期会互相干扰）。
