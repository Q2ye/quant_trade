# 卫星策略分析（微盘 + 恐慌抄底）

> **定位**：策略层级专项分析，仅覆盖两个卫星策略（微盘·进攻 / 恐慌抄底·事件）。
> **回测分析方法论**（通用规范，适用所有策略）见 `docs/06-标准规范/04_回测分析标准流程.md`。
> **2026-08 实测基线**：数据空洞修复 + 宇宙修正 + 等权对照后。

---

## 一、两卫星定位与目标

| | 微盘（卫星·进攻） | 恐慌抄底（卫星·事件） |
|:---|:---|:---|
| 收益来源 | 流动性溢价 + 壳价值 | 恐慌修复（极端情绪反转） |
| 设计目标 | M3：双门年化 22.6%，贡献组合 +5.7pp | M2：单次 +5%+，大恐慌 1.3-1.6x，胜率 73% |
| **2026-08 实测** | 等权 **+31%/5yr ≈ 5.5% 年化** | overshoot-v3 **+23.4%/5yr ≈ 4.5% 年化** |
| 实测单笔 | 胜率 46%、盈亏比 ~1.5 | 胜率 64%、单次 +5.1%、盈亏比 1.38 |

**共同判定**：两卫星"单笔经济学"健康，但**年化天花板低（4-5.5%），远低于卫星定位所需的 15%+**。设计目标（M2/M3）不可达，主因设计报告高估（幸存者偏差 / 指数代理 / 门控增益不实），详见标准流程 §1.3。

---

## 二、微盘策略分析

### 2.1 根因链条（2026-08 三轮回测实证）

```
M3 设计 22.6% 年化（幸存者偏差 + 方法学高估）
   ↓
① 实现偏离：加入"20日动量Top15"（M3 本是等权）
   ↓  实测：动量 +1.24% vs 等权 +31% → 动量 = -30pp 巨大负贡献 ✅已修
② 门控（大盘BULL + 微盘>MA20）：实测去门控 50% 处 -9.87% vs 带门控 -1.20%
   ↓  → 门控净正，保留 ✅
③ 宇宙：兜底1000（深市主板子集）vs 全微盘3794 → 必须修复 ✅已修
   ↓
结论：真实微盘 alpha（修正后）≈ 5-9% 年化，M3 22.6% 不可达
```

### 2.2 优化方向

**已验证**：

| 杠杆 | 实测 | 判定 |
|:---|:---|:---|
| 动量 Top15 选股 | +1.24% vs 等权 +31% | 🔴 **必须等权**（已修） |
| 门控 | 去门控 50% 处 -9.87% vs 带门控 -1.20% | ✅ 保留 |
| 宇宙 | 全微盘候选 3794 只 | 🔴 必须修复（已修） |
| 止损 -10% | 高波动微盘频繁触发 | ⚠️ 待验证（可能负贡献） |

**候选改进**（防 2024-01 流动性危机，未验证）：
1. **流动性过滤**：市值后 10% + 日均成交额>2000万 + 5日无连续跌停 + 换手率>1%
2. **微盘择时**：中证1000>沪深300(20日) 且 全市场成交额>8000亿 → 满仓；否则减半/暂停
3. **危机信号**：中证2000 连续5日下跌 / 全市场成交额<6000亿 / 微盘指数单日跌>3% → 清仓转现金
4. **持仓宽度**：Top15 vs 全池50（M3 满仓口径更优，待验证）

### 2.3 结论
真实微盘 alpha 上限 ~5-9% 年化。**不加流动性过滤 + 择时，撑不起进攻卫星 15%+**。二选一：重构（加防御层）或降级定位（防守/稳健仓）。

## 三、恐慌抄底策略分析

### 3.1 根因链条（2026-08 trades 配对实证）

```
M2 设计：每年 1-3 次大恐慌 × 单次 1.3-1.6x
   ↓
① 事件频率：2021(0)、2023(0) 无恐慌 → 年化天花板受"恐慌不可制造"限制
   ↓  实测：恐慌年份 2022 +14.6%、2024 +4.5%、2025 +5.4%——事件年能达标
② 单次收益：+5.1% 达标 M2(+5%)，但 70 笔无一笔超 +30%
   ↓  根因：ATR 移动兜底(1.5×ATR)过早砍赢家，阻止到达 +40/60% 阶梯档
③ 宇宙：兜底1000 选股（"全市场超跌"被扭曲）→ 已修，待复验
   ↓
结论：事件年收益达设计，但 5 年中 2 年零触发 → 年化 4.5% 是事件型策略固有宿命
```

### 3.2 优化方向

**已验证**：

| 杠杆 | 实测 | 判定 |
|:---|:---|:---|
| 单次收益 | +5.1%/次（达标 M2 +5%），胜率 64%（设计 73%） | ✅ 单笔经济学健康 |
| **离场机制** | **70 笔无一笔超 +30%**（ATR 移动兜底过早） | 🔴 可优化：放宽让赢家到 +40/60% |
| 宇宙 | 兜底1000 选股 | 🔴 已修（全市场非ST），待复验 |
| 事件频率 | 2023 全年 0 触发 | ⚠️ 固有：恐慌不可制造 |

**候选改进**（对齐 M2 笔记，未验证）：
1. **逐次检验四大恐慌**：2022-03 / 2022-04 / 2022-10 / 2024-01，逐个信号回放——抓住几次？后 20 日反弹多少？
2. **恐慌指数核对**：跌幅中位数（非均值）× 下跌比例（0-1 换算）
3. **卖出规则**：目标涨幅 15-20% 到点就走 + 10 日不涨也走（当前 20/40/60 阶梯 + ATR 兜底）
4. **标的取舍**：超跌个股（+20~50%/次，波动大）vs ETF（+5~15%/次，稳）

### 3.3 结论
事件年（2022/2024）可达 8-12%，但年化受"恐慌频率"约束（2023 类年必然 0）。**放宽离场是明确 +2-4pp/年 的杠杆**；触发频率是市场固有上限，无法优化。

## 四、卫星策略通用优化清单

| 改进 | 适用 | 说明 |
|:---|:---|:---|
| 流动性过滤 | 微盘 | 排除僵尸股 / 流动性枯竭标的 |
| 市场择时 | 微盘 | 小盘风格占优 + 成交额阈值 |
| 离场放宽 | 恐慌 | 别让移动兜底过早砍掉大赢家 |
| 逐次事件检验 | 恐慌 | 每个信号回放，定位漏报/误报/执行失败 |
| 宇宙修正 | 两者 | 严禁兜底子集（命门，已修） |
| 设计目标校准 | 两者 | 反推数学可行性，警惕 M2/M3 口径高估 |

---

## 五、结论（2026-08 基线）

1. **两卫星单笔逻辑都健康**（微盘等权胜率 46%/盈亏比 ~1.5；恐慌胜率 64%/单次 +5.1%）——**不是"不会做"，是"机会/alpha 撑不起高年化"**
2. **继续优化的边际收益有限（+2-4pp/年）**，无法达到卫星定位的 15%+
3. **建议**：
   - 恐慌放宽离场（1 个参数，值得做）
   - 微盘停在等权版（5.5%，稳健）
   - "进攻卫星"职责转给已实证的高波动动量轮动 7.1（+297%/5yr），微盘/恐慌按事件/防守仓定位
