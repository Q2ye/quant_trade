## 一、策略全景与定位

按设计哲学（Alpha 域）归置到「主池 + 卫星池」双层资金架构下：

| 策略 | Alpha 域 | 资金归属 | 定位 | 状态 |
|:--|:--|:--|:--|:--|
| 7.1 高波动动量 | 动量/趋势 | 主池（进攻） | 右侧追强，主收益 | 实盘 |
| ETF 底部 | 超跌反转·防守 | 主池（防守） | 熊市控回撤 | 实盘 |
| **恐慌抄底**（§二） | 超跌反转·事件 | 卫星池（事件型） | **博翻倍**，赔率优先 | 设计完善 |
| **微盘股策略**（§四） | 另类因子（小市值） | 卫星池（进攻型） | 微盘阿尔法 | 设计完善 |
| 期权押注（§三） | 事件/尾部 | 卫星池（资金 ≥50 万触发） | 低波彩票 | 远期（等 IV） |

**与 ETF 底部的定位区分**（恐慌抄底不视为重复 alpha）：
- ETF 底部 = 熊市防守，胜率优先，控回撤（高胜率/低赔率）
- 恐慌抄底 = **博翻倍**，赔率优先，事件博弈（低胜率/高赔率）

## 二、事件型卫星：极端事件归零博弈（恐慌抄底）

> 原 `两大事件驱动策略.md` 策略一，含 2026-08-19 评审完善。

### 2.1 定位

| 项目 | 内容 |
|:--|:--|
| 类型 | 事件驱动 + 恐慌抄底 |
| 市场 | A 股全市场 |
| 数据 | stock_daily + market_state_daily + index_daily（**全部齐备**） |
| 与主策略 | 时间互补——主策略暴跌止损空仓时，恐慌抄底接棒 |
| 资金 | 卫星池事件型子仓（平时现金，信号后出击） |
| 目标函数 | **不追求年化**——追求单次进攻倍数（博翻倍），平时闲置正常 |
| 核心逻辑 | 极端恐慌时系统性折价 → 买入错杀 → 情绪修复后卖出 |

**核心假设**：
1. 恐慌是暂时的（A 股历史每次极端恐慌后都修复）
2. 恐慌时好股坏股一起跌（钟摆式）
3. 修复第一波速度最快（情绪驱动反弹）
4. 国家队/机构在极端恐慌后入场托底

### 2.2 恐慌指数（复用现有数据，不重复造轮子）

```
恐慌指数 panic_idx = |全市场跌幅中位数(%)| × (下跌家数 / 总家数)
- 跌幅中位数：当日全市场涨跌幅中位数（负数取绝对值）
- 下跌比例：1 - market_state_daily.breadth_ratio（直接复用）
```

| 档位 | panic_idx | 动作 |
|:--|:--|:--|
| 正常 | < 0.5 | 不动作 |
| 轻度恐慌 | 1.5-3.0 | 关注（预置候选池） |
| 中度恐慌 | 3.0-5.0 | 准备（确认条件 B） |
| 极度恐慌 | > 5.0 | 出手（三条件全确认） |

### 2.3 触发（三重确认 + 年线门，时间错开的递进确认）

> **2026-08 M2 反例统计修订**（详见 `恐慌抄底反例统计报告.md`）：条件 A 阈值明确 **panic_idx ≥ 3.0**；条件 C **去掉成交额缩量要求**（V 型底 T+1 为放量续跌，成交额条件漏掉 2020-02/2024-01 两次最佳机会）。

```
【门控前置】年线门：CSI500 收盘 < MA250 → 熊市恐慌 = 趋势中继，直接放弃
  （熊市恐慌多为趋势中继（2018/2022），非错杀；只在牛市/震荡市急跌错杀出手（2020-02/2024-01））

T 日        条件A 恐慌指数 ≥ 3.0（M2 实证最佳工作点）
            条件B 沪深300 年线下5% / 距前低3% / 5日跌8% 任一
T+1 日      条件C 恐慌指数未再创新高（2026-08 修订：取消成交额 <80% 要求）
T+2~T+6 日  真恐慌确认：恐慌指数回落 < 1.5 或沪深300 收阳
→ T+7 日开盘执行买入
```

**评审关键改进**：
1. **年线门**：恐慌抄底仅限牛市/震荡市急跌错杀，熊市恐慌直接放弃（与主策略"熊市停买"哲学一致，避免趋势抄底覆辙——项目教训：关闭年线门 5 年期 -53%）
2. **真恐慌确认**：T+1 抛压衰竭只证明"卖压暂歇"，增加 T+2~6 恐慌回落确认——牺牲第一波反弹（5-8 交易日）换确定性，过滤 2018/2022 式持续阴跌
3. **时间错开**：三重确认跨 7 个交易日，消除同源性问题

### 2.4 选股（质量权重评分，防"接飞刀"）

```
候选得分 = 超跌分（5日跌幅，越深越高）
          × 质量分（恐慌前 ROE>5% 加 1.5x，营收>1亿 加 1.2x，非ST 必需）
          × 流动性分（日均成交额，>5000万 加 1.5x，>1000万 加 1.2x）
          × 机构分（北向持仓 加 1.3x，【数据存疑】实现时若不可得则降级/去除）
→ 取 Top 5-10 只，单票 ≤ 10%
```

基础过滤：5 日跌 >15% + 日均成交 >500 万 + 非 ST + 营收 >5000 万 + 市净率 >0。
替代方案：指数 ETF（最稳妥）/ 可转债（价格 <90 元 + 正股无退市风险）。

### 2.5 买入

- T+7 日开盘买入（开盘直接涨停/大涨则放弃——抢跑盘太多）
- 方案 A（分散）：10 只 ×10%；方案 B（集中）：3-5 只 ×20-30%

### 2.6 卖出（阶梯止盈 + 严格止损）

```
止盈（分批，让利润奔跑）：
  阶段1（反弹 0-3 日）：持有不动，吃第一波最强反弹
  阶段2（盈利 15%）：卖 1/3
  阶段3（盈利 30%）：卖 1/3
  阶段4（盈利 50% 或恐慌指数回 <1.0）：清仓
  时间兜底：持仓 20 交易日未达目标 → 清仓

止损（严格，快速）：
  单票亏损 15%：立即止损
  指数再创新低（恐慌加深）：减半仓
  流动性枯竭连续跌停：持有等恢复（本策略最大风险，需心理准备）
```

### 2.7 收益预估

| 场景 | 触发频率 | 单次收益 | 成功率 |
|:--|:--|:--|:--|
| 小恐慌（指数跌 2-3%） | 每年 2-3 次 | +5%~+10% | 65-70% |
| 中恐慌（指数跌 4-6%） | 每年 1-2 次 | +10%~+20% | 70-80% |
| 大恐慌（指数跌 7%+） | 每 2-3 年一次 | +30%~+60% | 80-90% |

> **评估口径：不按年化**，按单次进攻倍数——小恐慌 1.05-1.10x / 中恐慌 1.10-1.20x / 大恐慌 1.30-1.60x（博翻倍场景）。平时不触发 = 正常，不追求年年有收益。

### 2.8 前置验证（反例统计，必做）

> **2026-08 已完成**（`恐慌抄底反例统计报告.md`）：**假恐慌占比 26.7% < 30% 达标**，年线门必要性实证（关闭后 75% 假恐慌），触发条件已修订（阈值 ≥3.0、条件 C 免成交额缩量）。推荐配置 2019-2025 共 15 次信号，后 20 日 mean +2.6%、胜率 73.3%、尾部无极端负值（min -10.3%）。

1. 恐慌指数逐日计算，2019-2025 所有信号日 ✅
2. **假恐慌占比** = 信号后 20 日下跌比例——**<30% 才实现** ✅ 26.7%
3. 收益分布**尾部**（不只均值）——单次事件幸存者偏差检查 ✅
4. 年线门过滤前后对比（验证门控必要性）✅ 必要
5. 重点回放：2020-02 / 2022-03 / 2022-04 / 2024-01 四次历史事件 ✅ 2020-02(+10.3%) / 2024-01(+8.6%) 命中

## 三、期权：股指期权集中押注（波动率博弈，资金 ≥50 万触发）

> 原 `两大事件驱动策略.md` 策略二。**当前数据缺失（无 IV 数据源）**，远期规划。
> **2026-08 里程碑修订**：实盘资金达到 **50 万** 时接入 IV 数据源，本策略从远期转为可实施（冲刺 500 万目标的唯一大增量工具，见 `docs/01-业务设计/系统目标与投资哲学.md` §2.3）。

### 3.1 数据可得性（关键前置）

| 需要 | 现状 | 判定 |
|:--|:--|:--|
| 沪深300 隐含波动率 IV | **无数据表、无数据源** | ❌ 不可落地 |
| 期权合约价格/权利金 | 无 | ❌ |
| 沪深300 日线（技术形态） | ✅ index_daily | ✅ |

### 3.2 核心结论（评审 2026-08-19）

- **HV 无法代理 IV**：期权收益 = 方向 × IV 变化 × 时间价值衰减。历史波动率反映过去，隐含波动率反映市场预期（含升贴水/情绪/供需），proxy 方案**不构成期权策略可行性依据**
- proxy 仅用于研究"低波动 → 变盘"市场规律（可选），不作为期权功能开发依据
- **IV 数据接入前不做任何期权功能开发**

### 3.3 触发（等 IV 数据接入后）

```
条件A IV 极低位：当前 IV 处于近 3 年 20% 分位以下，或 IV < 15%
条件B 变盘前夜：布林带收窄（近1年10分位）+ 均线粘合（MA5/20/60 极差<2%）+ 缩量（<近1年均量）
条件C 方向：复用 market_state_classifier regime —— BULL 看涨 / BEAR 看跌 / 震荡不动 / 不明双买
```

### 3.4 仓位与风控（防单次亏光）

```
首次触发：卫星资金 20%（权利金上限）
方向确认（浮盈 50%）：加仓至 30%
极端信号（A+B 极致 + 双买）：至多 50%

单策略风控：
  单次最大损失：总资金 5%（权利金亏 70% 即止损）
  年最大损失：总资金 15%（连续 3 次止损即暂停）
  到期前 7 天无条件清仓（时间价值加速衰减）
  合约：次月平值或轻度虚值（距离到期 30-45 天），收盘前 30 分钟买入
```

### 3.5 收益预估（保守分层）

| 场景 | 概率 | 单次收益 |
|:--|:--|:--|
| 大行情 + 方向对 | 5-10% | +200%~+1000% |
| 小行情 + 方向对 | 15-25% | +50%~+200% |
| 方向不对 | 35-45% | -50%~-100%（权利金） |
| 横盘至到期 | 25-35% | -100%（时间价值归零） |

> **评估口径：不按年化**，按单次倍数——大行情 3-11x、小行情 1.5-3x。定位"尾部一次性爆发"，平时空仓等待是常态，不追求年年有收益。

### 3.6 落地路径

```
阶段 1（先行）：恐慌抄底（§二）——数据齐备，先回测验证
阶段 2（proxy）：历史波动率 proxy 研究"变盘时点"规律（不验证期权收益）
阶段 3（实盘）：【资金 ≥ 50 万】接入 IV 数据 → 实现真实期权交易
```

## 四、进攻型卫星：微盘股策略 + 双指数择时

> 原 `微盘股策略与择时设计方案.md`，归入卫星池（进攻型子仓）。

### 4.1 定位

| 项目 | 内容 |
|:--|:--|
| 类型 | 小市值微盘股 + 大盘择时 |
| 市场 | A 股全市场（微盘池） |
| 数据 | 日线 + circ_mv（已验证：<50亿 2534 只/2024-06）+ 中证2000 ETF + regime |
| 与主策略 | 独立进攻策略，专注微盘阿尔法 |
| 资金 | 卫星池进攻型子仓 |
| 核心逻辑 | 微盘低定价效率 + 壳价值提供阿尔法；择时规避微盘系统性崩塌（2024-01） |

**为什么归卫星池**：微盘有**独立于大盘的崩塌风险**（2024-01 大盘没崩、微盘崩了），用卫星池 25% 承担，而非主池 75%。

### 4.2 选池（定期重选）

```
【选池规则】每月初重选
  微盘池 = 流通市值 circ_mv < 50 亿
          AND 非 ST / 非退市
          AND 近20日日均成交额 > 3000 万（流动性下限）
          AND 最近一期营收 > 1 亿（排除烂壳）
          AND 市净率 > 0（不资不抵债）
→ 按流通市值升序，取市值最小 50 只
```

**生存底线**：纯按市值最小选会选中"快退市烂股"，必须配**退市风险过滤 + 流动性下限**。

### 4.3 择时（双指数确认——设计核心）

```
【门控 1：大盘 regime】复用 market_state_daily
  BULL → 允许买入；BEAR → 空仓（防系统性熊市）

【门控 2：微盘自身指数】中证2000 ETF（563300）近20日均线
  中证2000 收盘 > 20日均线 → 微盘趋势健康，允许买入
  中证2000 收盘 < 20日均线 → 微盘趋势破坏，空仓避让（防 2024-01 式独立崩塌）

→ 双门同时通过才买入；任一门关闭 → 空仓
```

**门控 2 是本策略特有**——专门防"大盘没跌、微盘崩了"的独立危机（2024-01 正是这种），是微盘择时核心差异点。

### 4.4 买入 / 风控

```
【触发】双门通过（大盘 BULL + 中证2000 > 20日均线）
【选股】微盘池按动量/质量评分选 Top 10-20（20日动量正 + 换手适中 - 涨停次数 - 退市风险分）
【买入】等权 Top 10-20，单票 ≤5%，总仓 ≤80%（留 20% 现金防流动性枯竭）

【止损】单票亏损 10% → 止损
【择时退出】任一门关闭 → 整体空仓
【动态】单票浮盈 > 30% → 减半
【流动性枯竭】连续跌停无法卖出 → 接受风险（微盘固有），靠分散 + 现金缓冲
```

### 4.5 与恐慌抄底联动（时间互补）

```
微盘危机 → 恐慌指数飙升：
  门控2 关闭 → 微盘策略空仓避让
  恐慌消退后 → 恐慌抄底（§二）在恐慌日抄底微盘股
→ 两个策略在微盘危机中形成"先避让 + 后抄底"的时间互补
```

### 4.6 关键参数

```python
DEFAULT_PARAMS = {
    # 微盘池
    "max_circ_mv": 50e8,          # 流通市值上限 50 亿
    "pool_size": 50,              # 微盘池大小（市值最小 50 只）
    "min_volume": 3000e4,         # 日均成交额下限 3000 万
    "min_revenue": 1e8,           # 最近一期营收下限 1 亿
    "rebuild_pool_freq": 20,      # 每 20 交易日重选池
    # 择时
    "use_market_gate": True,      # 门控1：大盘 regime
    "use_micro_gate": True,       # 门控2：中证2000 20日均线
    "micro_index": "563300.SH",   # 微盘代理指数（中证2000 ETF）
    "micro_ma_window": 20,        # 微盘择时均线
    # 买入
    "holdings": 15,               # 持仓数量（分散）
    "max_single_weight": 0.05,    # 单票上限 5%
    "max_total_weight": 0.80,     # 总仓位上限 80%
    "momentum_window": 20,        # 选股动量窗口
    # 风控
    "stop_loss": -0.10,           # 单票止损 10%
    "profit_reduce": 0.30,        # 浮盈 30% 减半
}
```

### 4.7 回测验证方案

```
对照组：
  ① 微盘策略 无择时（满仓微盘）→ 验证微盘阿尔法是否存在
  ② 微盘策略 + 大盘门（仅门控1）
  ③ 微盘策略 + 双门（门控1 + 门控2）← 完整设计
  ④ 微盘策略 + 双门 + 恐慌抄底联动

验证重点：
  1. 微盘阿尔法是否真实存在（① 是否跑赢沪深300）
  2. 择时是否降低回撤（②③ vs ① 的 MDD）
  3. 门控2 能否防住 2024-01 微盘危机（关键）
  4. 与恐慌抄底联动的组合收益
  5. 2019-2023 微盘池数据完整性（circ_mv 数据分时段核对）
```

### 4.8 风险与局限

| 风险 | 说明 | 缓解 |
|:--|:--|:--|
| 流动性枯竭 | 微盘危机连跌停无法卖出 | 分散 + 20% 现金 + 择时提前避让 |
| 择时滞后 | 20日均线确认慢 | 加"3日跌幅 > 5%"快速关闭 |
| 壳价值消失 | 退市新规趋严 | 严格退市风险过滤 |
| 中证2000 代理偏差 | ETF 有溢价 | 用指数而非 ETF 净值，或自建市值分位指数 |
| 样本回测偏差 | 2024 前 vs 后生态不同 | 分段验证（壳价值期 / 退市新规期） |
