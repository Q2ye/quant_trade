# 量化策略发展方向可行性分析

> 归档日期：2026-07-18
> 背景：低吸轮动 v6.9 定稿进入实盘验证 + 全球轮动 V2 启动调研 + 2 周密集实证迭代的经验校准
> 状态：**方向性分析，供后续规划引用**

## 一、来自 14 天密集实证的校准基准

在评估任何新方向之前，先建立"当下能达成的水平"作为参照系：

| 标杆 | 数值 | 性质 |
|:---|:---|:---|
| 低吸轮动 v6.9 | 5 年 +47.5% / 夏普 0.51 / MDD 27.7% | 单个策略的上限（7 轮实验 + Phase 1 三方对照打磨） |
| 选股引擎右尾 | 前 5% 回合贡献 61% 毛利，>30 天持仓全胜均 +56.8% | 纯粹选股 α 的上限 |
| 每轮实验改善 | 最有效单次改动（regime→csi500）=88pp、"降级震荡市"式改动 = 净负 | 改动方向的重要性远大于参数粒度 |
| "调参数到满意"的风险 | 3 次 regime 假设 + 6 轮实验才定稿 | 多重比较折扣的基准线 |
| 年线门 | 规则标准无阈值，跨 3 年窗一致 | 如何设计一个不会过拟合的机制 |

**基本原则**：任何新策略的 5 年回测夏普 ≥1.0 的声明，在未经过 3-5 年真样本外验证之前，按此经验打 4-6 折看待。

## 二、方向一：传统信号派

### 2.1 趋势跟踪 + 均值回归

| 维度 | 评估 |
|:---|:---|
| **与本平台的适配度** | ⭐⭐⭐⭐⭐ 最高——完全基于 OHLCV，数据管线完整，无新依赖 |
| **实施难度** | 低~中——现有 `technical/` 目录已有 MACD/MA 等基础实现 |
| **可期待收益** | 年化 8-12%，MDD 15-25%（单标的中低频日线趋势策略的合理上限） |
| **过拟合风险** | 中——参数数量是关键，建议 ≤3 个核心参数 + 预注册 + 三窗口验证 |
| **本轮教训的直接应用** | ✅ 年线级尺度做 regime 刹车（已证有效）；✅ "降级"式半力度刹车无用；✅ 出场检查每日执行不可与调仓耦合 |

**落地建议**：低吸轮动本身就是这个方向的产物——它不是"要不要做"，而是"已经做到了什么程度"。增量空间在：
- 把均值回归引入入场时机（当前六条件全是动量同向，低吸带 0.0015 名不副实）→ 改进已在 Phase 1 教训中记录；
- 出趋势跟踪×均值回归分层切换——两仪四象的 EF 自适应周期思想可跨资产复用。

### 2.2 多因子打分模型

| 维度 | 评估 |
|:---|:---|
| **与本平台的适配度** | ⭐⭐⭐⭐——因子计算模块（`modules/data/services/factor_service`）已就绪，需新的选股策略类 |
| **实施难度** | 中——核心工在因子定义/权重/组合，而非管道代码 |
| **可期待收益** | IC 0.03-0.06（A股权重股日频多因子的行业公允水平），组合夏普 0.8-1.2 |
| **过拟合风险** | **高**——这是典型易过拟合方向（因子数量 × 权重自由度），必须严格执行"因子分 样本内/样本外 两端、回溯定义逻辑而非数据、IC 衰减监控" |

**落地建议**：这是低吸轮动的自然进化方向——当前六条件本质是一个**固定权重、AND 组合的规则型因子模型**。进化的阶梯是：
1. 六条件拆成独立因子（趋势/动量/成交量/低吸位/质量/MACD），允许**或加权或排名**组合，替代当前全 AND；
2. 引入新因子（波动率/流动性/行业动量）——从"1 个策略"变为"1 个因子框架驱动多个策略变体"；
3. 因子评估基础设施（IC/RankIC/分层回测）先行——没有评估体系之前不加因子。

### 2.3 通道突破

| 维度 | 评估 |
|:---|:---|
| 适配度 | ⭐⭐⭐（数据完整） |
| 可行性 | 中等——单标的通道突破在A股噪音大，建议做**指数级别**的 ETF 通道突破策略而非个股 |

## 三、方向二：机器学习派

### 3.1 树模型（LightGBM / XGBoost）

| 维度 | 评估 |
|:---|:---|
| **与本平台的适配度** | ⭐⭐⭐——需新的机器学习 compute 模块，但特征工程可复用 `factor_service` |
| **实施难度** | 中~高——模型训练本身成熟，真正的工在**防止标签泄露/幸存者偏差/前视偏差**的穿越验证体系 |
| **可期待收益** | A股日频树模型 IC 0.02-0.05，方向正确率 52-55%（基于行业经验，非宣传数字） |
| **过拟合风险** | **极高**——高维特征空间 + 每日样本的伪重复性（相邻日高度相关）= 传统 K 折交叉验证严重高估 |
| **本平台的特有坑** | 当前 `stock_daily` 无退市/ST 变迁历史 → 训练集里只活到今天的股票 = 严重的幸存者偏差（正确做法是训练集包含已知退市股、验证集排除） |

**落地建议**：起步不要做端到端 ML 策略。**最高成功率的路径是元标记（meta-labeling）**：
- 低吸轮动选股引擎输出候选 + 初始置信度；
- 树模型对候选做二次过滤（"这个候选在这个市场状态下成功率如何"）；
- 好处：人工规则兜底（不会出荒谬信号）+ 模型只做增量判断 + 数据需求从全市场降为"历史候选集"。

### 3.2 深度学习（LSTM 等）

| 维度 | 评估 |
|:---|:---|
| 适配度 | ⭐⭐——需 GPU 环境、数据量级要求高 |
| 可行性 | **当前不建议**——单日线数据对序列模型样本极度稀缺（3000 只 ×5 年 ≈对 NLP 模型而言仅是一次训练的万分之一量级）。宣传的"年化 46%"背后通常是分钟级数据 + 高频交易成本的乐观假设，与本平台「日线中低频」定位不符 |

### 3.3 验证体系调整（机器学习方向部署的前提）

- 裁切交叉验证（Purged Walk-Forward）：防止同股票相邻日泄漏；
- 分阶段训练/验证/测试（必须留至少 2 年 never-seen 测试期）；
- IC 衰减曲线监控（部署后每月重算 IC，连续 3 月衰减 >30% → 模型失效，停止使用）；
- **前提**：`stock_daily` 须补全退市历史 + 名称变更历史表（没有这个之前不做 ML）。

## 七、一个重要的框架经验

这 14 天反复验证了三条规律，适用于评估任何新方向：

1. **改动的方向比改动的粒度重要 50-100 倍**：一个正确方向的简单改动（regime→csi500：+88pp）远大于同一错误方向上精调 10 个参数（bullish_pct 阈值：+9pp；EF 门/宽度门：-10~-20pp）；
2. **"永远在场"在 A 股是毒药**：任何不分牛熊都满仓的策略，回撤必然 >40%。两个机制被反复证明有效——年线级慢周期刹车 + "停买"（不是半仓）的坚决力度。任何新策略评估时首先看它怎么处理这个问题；
3. **过拟合的防御性成本远低于事后补救**：每改一个参数就重新回测的习惯，积累到第 7 次就不可逆地失去了样本外验证能力。预注册标准 → 一次回测 → 冻结参数，是必须铁血执行的规则。

这三条对方向二（ML 的"多少个特征、多少个超参"）尤为重要——ML 的过拟合容积极大（高维 + 非参数），必须用更严格的裁切交叉验证 + 预注册标准来对抗，否则训练集上的夏普 3.0 是训练精心制造的幻觉。
