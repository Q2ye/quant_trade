# 策略过拟合检验标准（标准规范）

> **适用范围：所有策略的参数选择、因子采纳、机制改动**（含主池 / 卫星 / ETF / ML）。
> **定位：回答「这个结论是真的 alpha，还是我们试了太多次挑出来的」。**
> **制定：2026-09-15**
> 与既有文档的关系（引用不复制）：参数扰动口径见 `04_回测分析标准流程.md` §6；样本外两段范式见 `.claude` 记忆 `strategy-oos-validation-standard`（**本文件把该纪律从"记忆"固化为"规范"**）；准入判定见 `06_策略实盘准入标准.md` §二 G4。

## 〇、为什么需要这份标准（现状，诚实盘点）

本项目**已经在做对照实验**，而且量级不小。以跨市场动量避险轮动策略为例（代码注释与验证文档实证）：

| 实验 | 规模 |
|:---|:---|
| 优化方向 A/B | **10 轮**（仅 1 轮通过） |
| 动量失效闸门 | **18 次回测**（6 臂 × 3 段）+ 12 滚动起始日 |
| 趋势质量 k 扫描 | **8 档**（0.5 / 1 / 2 / 2.5 / 3 / 4 / 8 / 100） |
| R² 阈值邻域 | **5 档**（0.42~0.52）+ 两段样本外 + 6 起始日 |
| 安慰剂（lag）臂 | 多轮 |

**三个缺口**：

1. ❌ **无试验次数台账** —— 试了多少次只散落在代码注释与提交信息里
2. ❌ **无显式的多重检验校正** —— 没有 PBO / Deflated Sharpe 这类工具
3. ⚠️ **安慰剂对照未形式化** —— 它本质是 White's Reality Check 的近似，但目前只是"习惯做法"，没有成文判据

**后果的实证**：跨市场策略的「0.6% 决策日 → 147pp 最终收益差」—— 说明**单点全窗口超额数字不可信**，必须用分布 + 校正来看。

## 一、Step 0：试验台账（**强制，最先做**）

> **这是本文件唯一"零成本、立刻可执行"的一条，也是后面所有校正的前提** —— 没有 N（试验次数），PBO 与 DSR 都算不出来。

每次对照实验**必须**登记一行：

| 字段 | 内容 |
|:---|:---|
| 日期 | YYYY-MM-DD |
| 策略 / 实例 ID | 如 `07651265-...` |
| 改动内容 | 一句话（如「`r2_threshold` 0.40→0.47」） |
| **臂数 N** | 本实验尝试的配置数（含基线） |
| 区间与统计量 | 起止 + 交易日数 + 中位/下四分位/最差 |
| 结论 | 采纳 / 否决 / 待定 |
| 依据 | 回测 `task_id` 或脚本路径 |

- **落库位置**：`backtest_comparisons` 表（已存在）或 `docs/` 下的台账表；**两种都可以，但必须有一处**
- ⚠️ **未登记的实验不算证据** —— 也不能在后续 DSR 计算里被"忘掉"（这正是多重检验失控的机制）

## 二、Step 1：样本外两段（现成，固化）

- 把可用区间切成**不重叠两段**：观察段挑参数/判方向 → 验证段复验
- **判据必须事先定死**：要求**两段同向改善**，不看全区间峰值
- ⚠️ **滚动起始日不能替代样本外切分**（所有窗口覆盖同一段数据）

**红线**：只有全窗口改善、分段有一边变差 → **判为曲线拟合，放弃**（实例：`entry_gain_veto` 观察段 ③>②、验证段 ③<②，方向不一致 → 否决）

---

## 三、Step 2：安慰剂对照（现成，本节形式化）

**定义**：保持策略结构不变，把**真实信号替换为无预测力的同构信号** —— 本项目现行做法是 **lag（滞后错位）臂**。

**判据（形式化，新增）**：

| 情形 | 判定 |
|:---|:---|
| 真实臂**优于**安慰剂臂，且分段一致 | 通过 |
| 真实臂与安慰剂臂**相当** | **判为噪声** —— "效果"等于随机地有时不在场 |
| 真实臂**劣于**安慰剂臂 | **直接否决** |

**实例**：动量失效闸门同阈值下真实信号 198.05% **差于**安慰剂 312.17% → 否决（这是正确的使用）

---

## 四、Step 3：邻域稳健（现成口径）

- 单参数扰动：结果 ±20% 内波动 = **稳健**
- **孤峰**：+30% → −10% 翻转 = **过拟合**
- **上沿检查**：确认无「越大越好」的杠杆效应（实例：k 扫描上沿拐点 k=8~100 确认回落）

---

## 五、Step 4：PBO —— 回测过拟合概率（❌ 新增，未实现）

**定义**：在所有试验过的配置中，"样本内最优"那一个**在样本外落到中位数以下**的概率。

**方法（CSCV，组合对称交叉验证）**：

1. 把 T 个观测切成 S 个不重叠子段（S 取偶数，常用 16）
2. 枚举所有 `C(S, S/2)` 种「一半做样本内、另一半做样本外」的组合
3. 每个组合里：选出**样本内表现最好**的配置，看它在样本外的**相对排名** ω
4. 计算 logit `λ = ln(ω / (1−ω))`，**PBO = P(λ ≤ 0)**

**输入**：`N 个配置 × T 期收益`矩阵（N 来自 Step 0 台账）
**阈值**：**PBO ≤ 0.5** 为可接受（初始值，待校准 —— 见下方 ⚠️）
**实现参考**：Bailey / Borwein / López de Prado / Zhu, *The Probability of Backtest Overfitting*（实现细节以原论文为准，本文件不复制公式）

> ⚠️ **阈值校准说明（2026-09-15 修订）**：本节此前写「**进攻型策略 ≤ 0.2**（因为这类策略的选参数自由度最高）」，**推理方向是反的** ——
> **参数自由度最高的策略，PBO 天然最高**，用比通用线更严的尺子去量它，等于"用最严的尺子量最活的对象"，
> 结果是**几乎必然卡死全部进攻策略**（本项目主策略年化在 26%~354% 区间漂移，PBO 大概率 > 0.5）。
> 而小资金快速膨胀期需要**部署**，一个大概率卡死所有策略的标准只会退化成纸面规范。
> **故本期不设进攻型加严线**：PBO 与 DSR 阈值一律先按通用值执行，并标注为**初始值**。

## 六、Step 5：Deflated Sharpe Ratio（❌ 新增，未实现）

**要解决什么**：观测到的夏普**同时被三件事虚高**——① 试了很多次（多重检验）② 收益非正态（偏度/峰度）③ 样本长度不足。

**校正的三个输入**（都是可算的）：

| 输入 | 含义 | 本项目从哪来 |
|:---|:---|:---|
| **N** | 独立试验次数 | **Step 0 台账** |
| `γ3, γ4` | 收益的偏度 / 峰度 | 回测 `daily_returns`（`backtest_tasks.result` 已有） |
| `V[SR]` | 各配置夏普估计的方差 | 各臂夏普（台账里） |

**输出**：一个概率值。
**阈值**：**DSR > 0.95** 视为显著（对应 5% 水平）（**初始值，待校准**）
**实现参考**：Bailey & López de Prado, *The Deflated Sharpe Ratio*（同上，细节以原论文为准）

> **实操：开跑前先算 SR0（2026-09-19 新增）**
>
> `N`（试验次数）直接决定门槛。零假设（无技能）下的**期望最大夏普**可先算出来：
>
> ```
> E[max Z_N] = (1-γ)·Φ⁻¹(1 − 1/N) + γ·Φ⁻¹(1 − 1/(N·e))     γ = 0.5772（Euler-Mascheroni）
> SR0(年化)  = E[max Z_N] / sqrt(T) × sqrt(244)              T = 日收益样本数
> ```
>
> | N | E[max Z] | SR0 年化（T=2430，约 10 年日频） |
> |---:|---:|---:|
> | 1 | 0.000 | 0（即普通夏普） |
> | 10 | 1.575 | ≈0.50 |
> | 50 | 2.276 | ≈0.72 |
> | **111** | **2.567** | **≈0.81** |
> | 200 | 2.766 | ≈0.88 |
>
> **用途**：任何方向**开跑之前**先算这个数 —— **"打算跑 N 轮"是有代价的，且代价可直接算出来**。
> 跑得越多，事后要通过的夏普门槛越高；若预算的 N 会让门槛超过该策略的现实上限，**就别跑那么多**。
>
> **实测案例（2026-09-19，震荡策略方向 · 台账 RN-17）**：N≈111 → SR0≈0.81，
> 而组合实测夏普仅 **0.600~0.738 < 0.81**，DSR 0.253~0.408 → **方向作废**。
>
> ⚠️ **注意一个关键区分**：**「夏普 < SR0」不依赖 DSR 阈值校准** ——
> 它不是"DSR 有没有过 0.95"这个阈值问题，而是"**跑 N 次噪声平均能得到更好的结果**"的
> 直接结论。**该判断无需等阈值校准即可成立**，与下方过渡期豁免无关。

> ⚠️ **两条校准说明（2026-09-15）**：
> 1. **阈值必须等样本**：本项目的 N 已经很大（单个策略就 10 轮优化 + 18 次闸门 A/B + 8 档 k 扫描 ≈ 40–60 个配置）。N 越大，零假设下的"期望最大夏普"越高 → **DSR 会把项目现有夏普全部打下去**。
>    而目前**一个 PBO/DSR 数字都还没有** —— 阈值需要 3~5 个策略的实际分布才能定。**先有数字，再定线**（与 Step 0 台账同理）。
> 2. **过渡期用法：记录 + 不否决**。在阈值校准完成前，PBO/DSR **算出并登记，但不作为否决依据**；否决仍由 Step 1（样本外两段）、Step 2（安慰剂）、Step 3（邻域孤峰）承担 —— 这三条本项目已有成熟实践。
>    ⚠️ 但**Step 0 台账不在此豁免范围**（它是零成本的基础设施，必须立刻执行）。

> ⚠️ **与「赔率优先」定位的冲突（同一个问题在准入标准 §4.2 B3 已修订）**：DSR 校正的是**夏普** —— 而夏普天然惩罚低胜率、高赔率的收益结构。
> 对**赔率型**策略，应改用**单笔期望 > 0 + 盈亏比 ≥ 2**，不得用夏普类指标卡（依据 `系统目标与投资哲学.md` §三.1）。

> ⚠️ **与准入标准的关系**：准入标准 ①层 B3 要求「夏普 > 1.0」—— 严格来说应为「**Deflated** Sharpe > 1.0」。在 DSR 未实现前，B3 是未校正的近似；实现后应替换。

## 七、Step 6：ML 策略专用 —— Purging & Embargo（❌ 新增，未实现）

**适用**：`etf/bottom_strategy.py`（LightGBM）/ 任何用重叠标签做交叉验证的模型。

**问题**：标签窗口重叠时，训练集与测试集会共享同一段未来信息 → 验证分数虚高。

**要求**：

- **Purging**：剔除训练集中**标签窗口与测试集重叠**的观测
- **Embargo**：测试集之后额外隔离一段（通常取标签窗口长度的 1%）
- **时间轴**：train → val → test **严格前向**，禁止 K 折随机切分

> 现状：`audit-strategy.md` 已要求「时间轴严格分离」，但**未涉及 purge/embargo**；ML 策略的验证口径是当前最大空白。

## 八、一票否决项（红线）

1. **无台账的对照实验不能作为采纳依据**（Step 0 未登记）
2. 只有全窗口改善、**两段样本外方向不一致** → 否决
3. **真实臂不敌安慰剂臂** → 否决
4. 参数邻域**孤峰**（+30% → −10% 翻转）→ 否决
5. **PBO > 0.5** → 否决（**过渡期豁免：阈值校准完成前只登记不否决**，见 §五 ⚠️）
6. **DSR ≤ 0.95** 而仅凭原始夏普达标 → 不得据原始夏普采纳（**同样适用过渡期豁免**）
7. ML 策略**未做 purge/embargo** → 验证结果不可作为采纳依据
8. **未建试验台账（Step 0）→ 不得声称任何对照实验结论**（**此项不豁免**）
