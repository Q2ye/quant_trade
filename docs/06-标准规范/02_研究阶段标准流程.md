## 〇、前提：这份标准到底在防什么

### 0.1 它不是缺步骤，是缺纪律

本项目**不缺步骤清单**：G0–G5、回测 Step 1–7、因子标准流程都已成文。缺的是**研究阶段**，而在没有规范的这段里，实际发生过的事是：

| 已发生的错误 | 性质 |
|:---|:---|
| 先假定信号成立、再调它的参数 | **顺序颠倒** —— 正确顺序是先证"存在可提取的结构性收益"，再问"用什么信号提取" |
| 宣称赚 A+B（时序β/横截面α），**实际全程测的是 C（单标的短期反转）** | **错位** —— 用 C 的结果讨论"策略行不行" |
| 行为层一条都没测，筛选结果反常时无法解释 | **缺层** |
| 看到结果再决定下一步测什么 | **判据不前置** |
| 全程未登记试验次数 | **无台账** → 多重检验校正无从谈起 |

**结论：本标准的重心不是"多几个步骤"，而是"三条纪律 + 一个可被独立复核的记录"。**

### 0.2 它防的是"自我欺骗"，不是"能力不足"

统计工具（IC、分层、样本外）本项目都会用。真正反复出问题的是**判据随结果漂移**、**结论措辞超出证据强度**、**试了很多次却当作试了一次**。这三件事都有标准解法，见 §二。

## 一、总体结构：三段 + 四道门

```
        ┌── 研究阶段（本文档）──────────────────────────────────┐
        │                                                          │
   R0 ──→ R1 ──→ R1.5 ──→ R2 ──→ R3 ──→ │ G0 ──→ G1 … G5 ──→ S1–S2
 前提核实  结构层  标的池  行为层  统计层 │ 立项门   （既有标准）
        │        ↑复核    ↑复核   ↑复核 │
        └──────────────────────────────────┘
              ↑弃     ↑回 R1   ↑回 R2      ↑改目标或弃
```

| 段的性质 | 段 | 一句话 |
|:---|:---|:---|
| **不许开始** | R0 前提核实 | 数据不全，后面全是空谈 |
| **不许跳过** | R1 结构层 | 池子里到底有哪几种钱 —— **此段不涉及任何信号设计** |
| **不许随便定义** | **R1.5 标的池** | **池必须从钱源倒推**（`钱源 → 标的属性 → 可测条件 → 样本外验证`），严禁用成交额/市值排名这类与钱源无关的代理 |

**每段结束、进入下一段之前，必须通过复核**（§四）。**没有复核签字 = 没有进入下一段。**

## 二、三条纪律（硬性，全阶段适用）

### 纪律一：判据前置（Pre-registration）

**每一段的通过判据，必须在跑之前写入《研究记录》并冻结（带时间戳）。跑完不许改。**

- 要改判据 → **本段作废重跑**，原记录保留、新增一条
- 记录格式见 §五
- ⚠️ 这是本文件**最重要**的一条。`05_策略过拟合检验标准.md` Step 1 已对"样本外两段"规定了同类纪律（"判据必须事先定死"），**本文件把它扩展到研究阶段的每一段**

### 纪律二：单变量推进

**每一步只允许改一个东西**，且必须能回答：**"这一步检验的是上一步的哪条假设？"**

- 答不出 → **这不是验证，是参数搜索**
- 多个变量同时改 → 效果不可归因，本步作废

### 纪律三：试验记账

**每一次试验（含失败的）登记入台账。**

- 落库位置：**用已有表**（`backtest_comparisons`）或 `docs/` 下的台账表 —— **两种都可以，但必须有一处**（口径引自 `05_策略过拟合检验标准.md` §一）
- **未登记的试验不算证据**，且**不得在后续 DSR/PBO 计算里被"忘掉"**
- ⚠️ 该条款在 `05_策略过拟合检验标准.md` §八 已被列为**不豁免**项，但**当前未实现** —— 本文件重申并前移到研究阶段

## 三、三段详解

### R0 前提核实

| 项 | 内容 |
|:---|:---|
| **目的** | 排除"数据不可用"导致的伪结论 |
| **做什么** | ① 数据覆盖率与**内部空洞**（`MAX(trade_date)` 查不出空洞） ② 复权口径可用性 ③ 标的历史长度 ④ 交易成本参数 |
| **判据** | 覆盖率 ≥90%；最大断档 <20 交易日；**复权完整**（口径须写明，缺因子区间须显式排除而非静默丢弃） |
| **产出物** | 前提检查表（每项 ✅/❌ + 实测数字） |
| **不通过** | 补数据；**不许带已知缺陷往下走** |

> ⚠️ **反例实证（2026-09-19）**：本项目曾以 `fund_adj_factor` 做复权，改用 `INNER JOIN` "排除未复权污染"时**静默丢掉 2011–2017 共 7 年数据**，而输出仍标注"2011 起"。**复权口径变更必须显式报告数据区间变化。**

### R1 结构层 —— 池子里到底有哪几种钱？

| 项 | 内容 |
|:---|:---|
| **目的** | 先证"资产池里存在可提取的结构性收益"，**再谈怎么捡** |
| **做什么** | 在同一池、同一时间轴、**同一套评价标准**下**并列**测候选结构：<br>**A 时序择时**（按 regime 择时 vs 一直持有）<br>**B 横截面动量**（池内排 Top-K）<br>**C 时序反转**（单标的超卖反弹）<br>**D 横截面反转**（池内排 Bottom-K） |
| **判据** | 五条**全部**满足才算通过：<br>① 超额 > 成本，**且「超额」的对照臂口径必须写进冻结判据**（见下 ⚠️）<br>② **分年度方向一致**（不能只靠 2007/2015 这类单一年份）<br>③ 样本外（前 60%/后 40%）同向<br>④ 至少一种结构达标<br>⑤ **凡涉及择时的结构，强制安慰剂对照**（随机入场 + **完全相同的出场规则**） |
| **产出物** | 结构层对照表：四种结构各自的 超额 / 分年度 / 样本外 + **对照臂口径** |
| **不通过** | **四种全不达标 → 方向作废**，不进 R1.5 |

> ⚠️ **纪律**：本段**不得涉及任何入场/出场信号设计**。只问"池子里有没有钱"，不问"怎么捡"。
> ⚠️ **反例实证（2026-09-19）**：本项目曾跳过本段，直接假定"布林下沿买入"成立并调其参数——而该信号属于 **C（时序反转）**，与宣称的钱源 **A+B** 根本不是同一个东西。**错位不是误差。**
> ⚠️ **反例实证（对照臂缺失）**：同轮研究中，入场信号曾报出「超额 **+3.198%**、分年度 **100%** 为正」。
> 根因是**对照臂与策略不是同一套出场规则** —— 策略用「触及目标即卖 / 否则 60 日时间止损」，
> 对照却用「固定持有 H 天」，于是**出场规则本身的价值被算成了入场信号的价值**。
> 改为**安慰剂对照**（随机入场 + 逐字相同的出场规则）后，同一信号只剩 **+0.140%**（蒸发 **96%**）。
> **教训**：判据里写「超额 > 成本」是不够的 —— **不写明对照臂口径，"超额"可以凭空放大 20 倍**。

---

### R1.5 标的池 —— **必须从钱源倒推**（硬性）

> ⚠️ **反例实证（2026-09-19）**：本轮研究用「`etf_daily` 日均成交额前 200 只」**直接定池**。
> 实测该池含 **债券 22 只 + 货币 13 只 + 商品 10 只 = 22%**（按成交额排的前 60 名里占 **32%**）。
> 货币 ETF 日波动 ≈ **0.006%**、债券 ≈ **0.05%** —— **价格几乎不动、没有"通道"可言**；
> 且带宽极窄会**频繁触发"触及下沿"的假信号**，系统性稀释统计量。
> **后果**：唯一一个"达标"的组合（`frac 全部`，分年度 71%）是池污染撑出来的；
> 改用波动率门槛清洁池后立刻跌到 **67%**，**跌破判据**。

**倒推链（必须逐条写明，缺一不可）：**

```
钱源（R1 结构层选定的效应）
  → 承载这个钱源的标的【属性】
    → 把属性变成【可测的筛选条件】
      → 【样本外】选池验证 + 等权对照
```

**硬性要求：**

| # | 要求 |
|:--|:---|
| 1 | **严禁**用与钱源无关的代理指标定池（成交额、市值排名、代码序）。成交额高可能只说明它是**现金管理工具**，恰恰说明**不该**进池 |
| 2 | 池的定义必须能回答：**"这个属性为什么是钱源的必要条件？"** 答不出 → 不许进池 |
| 3 | 必须有**幅度下限**：通道/价差幅度须能覆盖双边成本，否则效应存在也做不出来 |
| 4 | 必须有**不可逆左尾的处理规则**（退市/ST/暴雷）：均值回归的"跌了会回来"在**会归零**的标的上失效 |
| 5 | **样本外选池**：前 60% 筛 → 后 40% 验；并**同时报告"全候选池等权"**作对照（否则选池=拟合） |
| 6 | 选池所用的每个指标，须在 R1 中**已被证明与钱源相关**；未经证明的指标只能作候选，不得直接用于定池 |

**产出物**：池定义 + **倒推链** + 样本外证据 + 等权对照
**不通过处置**：倒推链写不出 → **回 R1**（说明钱源还没定清楚）

> ⚠️ **反例实证（2026-09-19，判据方向缺陷）**：验证「波动率 / `VR(k)` 能否用于筛池」时，
> 冻结判据写的是「分层超额**单调**，Spearman 秩相关 > 0.5」——
> **"单调"本身没有规定方向**，而实现时写成了 `ρ > 0.5`（只认**递增**）。
> 结果：`VR(k)` 层呈**强单调递减**（`ρ = −1.00`，VR 越低超额越高，正是假设的方向），
> 却被判为"不单调 / 不可用" —— **把最强的筛选条件误判成了无效**。
>
> **教训（硬性）**：任何**分层 / 单调性 / 相关性**判据，**必须写明预期方向**，例如
> 「波动率↑ → 超额↑（`ρ > +0.5`）」「`VR(k)`↓ → 超额↑（`ρ < −0.5`）」。
> 只写"单调"或只写"相关"，等于把方向交给实现者临场决定 —— 那正是判据前置要消灭的东西。
>
> **处置**：判据表述缺陷（非数据变化）→ 用**同一份结果**按正确方向重新解读，**不重跑**，
> 但**必须显式记录**这次缺陷与修正（本条即记录）。

### R2 行为层 —— 机制可观测吗？还在吗？

| 项 | 内容 |
|:---|:---|
| **目的** | 让结论有**可依赖的机制**，而非纯统计 |
| **做什么** | 对 R1 胜出的结构，验证其机制假设：<br>**若胜出 B/D（横截面）**：用成交额/份额变化作资金流代理，测链条「涨幅 → 后续资金流 → 后续涨幅」，**滞后须可测**<br>**若胜出 A/C（时序）**：测跌幅与反弹幅度的**非线性** —— 过度反应应表现为"跌得越多反弹越大，**直到某点转为趋势**" |
| **判据** | ① 机制**可观测**（有可测的中间变量）<br>② **未显著衰减**（样本外/近年的效应量不显著弱于早期）<br>③ 能给出**替代解释并排除**（尤其"收益是否只是 β"） |
| **产出物** | 机制验证报告 |
| **不通过** | 机制讲不通或已衰减 → **回 R1 换结构**，**不是硬调参数** |

> ⚠️ **回 R1 前必须先登记台账，并计入多重检验次数**（2026-09-19 补）。
> 标准原文只说"回 R1 换结构"，但**在未记账的情况下反复换结构 = 在数据上持续搜索** ——
> 每换一次，被选中的组合就虚高一分，而**没有任何东西记录你换了几次**。
> 本项目的反例：震荡策略研究在 R1↔R2 之间来回十余轮、**全程未记账**，
> 事后补建台账才算出 **N ≈ 111**（见 `docs/台账/研究试验台账.md`）。
>
> **硬性**：R2 不通过 → 决定"回 R1"之前，**先把本轮的每个配置登记入台账**。
> 台账里 **N 的增速**本身就是"是否该停止搜索"的信号。

### R3 统计层 —— 信号、参数、止盈止损、标的池

| 项 | 内容 |
|:---|:---|
| **目的** | 在**已确定的结构**上做工程实现 |
| **做什么** | 通道定义、入场规则、出场与止损、持有期、标的池筛选 |
| **判据** | ① 每条参数的选择**能锚在 R1 选定的结构上**<br>② 单参数扰动（对齐 G4①）<br>③ 样本外<br>④ 标的池筛选须**证明筛选后优于未筛选**（样本外），否则**不筛** |
| **产出物** | 信号与参数规格 + 标的池定义 |
| **不通过** | 回 R2 复核机制 |

> ⚠️ **参数必须与结构匹配**：结构是 B/D → 参数是排序窗口/持仓数/调仓频率，筛池标准是**横截面离散度/资金流敏感度**；结构是 C → 参数才是通道/超卖阈值/持有期，筛池标准是**反转弹性**。
> ⚠️ **反例实证（2026-09-19）**：曾用"VR / 往返完成率"筛池（那是**为 C 设计的判据**），却从未先证明 C 是有效结构 → **筛选全部失败，且方向相反**（最"均值回归"的组样本外反而最差 +0.491% vs 全池 +1.675%）。**筛不出来是必然的。**

## 四、复核流程

> **设计前提**：本项目是**单人开发**。业界的"投委会/独立见证人"降维为 —— **由非作者本人执行独立复核**（沿用 `06_策略实盘准入标准.md` §二 G5 的既有做法，**前移到研究阶段**）。

### 4.1 三层复核，逐层可否决

| 层 | 谁做 | 查什么 | 能否否决 |
|:---|:---|:---|:---|
| **L1 合规复核** | **脚本**（可机检） | 判据是否前置并冻结？台账是否完整？数据区间是否与陈述一致？ | ✅ 硬性 |
| **L2 逻辑复核** | **独立 agent**（`.claude/agents/strategy-reviewer.md`，只读，作者不自审） | 见 §4.2 检查清单 | ✅ |
| **L3 裁决** | **人** | 是否继续投入 | ✅ |

**L1 不通过 → L2 不必做。L2 不通过 → 不得进入下一段。L3 不过 → 停止。**

### 4.2 L2 逻辑复核检查清单（**8 项**）

| # | 检查项 | 驳回条件 |
|:--|:---|:---|
| 1 | **判据前置性** | 判据在本段跑之前未写入，或无冻结时间戳，或跑后被改动 |
| 2 | **证据充分性** | 结论中任一断言**无法追溯到具体数字** |
| 3 | **措辞-证据匹配** | 出现"证实""否定""证明"等强断言，而证据只是**单一窗口/单一参数/单一样本**的统计 |
| 4 | **单变量性** | 同时改了多个变量且未做分离 |
| 5 | **反例处理** | 出现与假设相反的结果却未讨论；**或所有结果都与预期一致**（判据可能不严） |
| 6 | **样本外** | 用了样本外但判据未事先定死；或结论基于全样本峰值 |
| 7 | **台账** | 本段试验（含失败）未登记 |
| 8 | **替代解释** | 未考虑替代解释（尤其"收益是否只是 β"） |

> **第 3 与第 5 项是本清单的核心** —— 本项目研究阶段实际发生的错，全落在这两条上。

### 4.3 复核的产出与留痕

- 复核结论**必须落盘**：`通过 / 驳回 + 理由 + 复核人标识 + 时间戳`
- 驳回后修改重跑 → **原记录保留、新增一条**（纪律一）
- **没有 L2 复核签字 = 没有进入下一段**
