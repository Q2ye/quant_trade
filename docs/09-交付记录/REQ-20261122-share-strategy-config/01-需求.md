# REQ-20261122-share-strategy-config 需求卡

> 阶段 S1 ｜ 档位 T2 ｜ 起草 2026-11-22 ｜ 确认人 待用户审批
> 背景：`REQ-20261108-db-env-isolation` 把策略配置也隔离了，导致 dev 看不到生产策略（列表 5 条 vs 51 条），
> 且 dev 回测生产策略时读不到生产参数（`strategy_parameters` 为空 → 回落 DEFAULT_PARAMS，静默失真）。

## 问题与证据

- **现象 1**：dev（8080）策略列表 `total=5`（只有 dev 自有），生产（8888）`total=51`。
- **现象 2（更隐蔽）**：`backtest_service.py:331/:1413` 从 `StrategyParameterRepository` 取策略参数；dev 环境的 `strategy_parameters` 是独立表 → dev 回测生产策略时**参数为空**，静默用 `DEFAULT_PARAMS`，回测结论与实盘不可比。
- **证据（表分布）**：`dev` schema 存在 `strategies`/`strategy_parameters`/`strategy_templates`/`strategy_versions`/`strategy_runs`/`strategy_daily_performance`/`portfolio_strategies` 共 7 张策略相关表；其中前 3 张属于**配置**，其余属于**运行状态/绩效**。
- **不做的后果**：dev 与生产策略体系两套孤岛；任何"用生产参数在 dev 验证"的动作都会得到假结论。

## 目标

把**策略配置三表**（`strategies`、`strategy_parameters`、`strategy_templates`）改为 dev/prod 共享（统一落 `public`），
同时加两道写守卫，保证 dev 不能改到生产在跑的实例。

## 范围

- 包含：
  - dev schema 中的 `strategies` / `strategy_parameters` / `strategy_templates` **改名备份**（不删除），使未限定表名回落到 `public`；
  - 写守卫 1：dev 环境禁止修改/删除 `status='running'` 或 `run_mode='live'` 的策略 → **409**；
  - 写守卫 2：dev 环境新建策略强制 `status='draft'`、`run_mode='backtest'`；
  - 验证 dev 回测能读到生产参数。
- **不包含**：不改回测/账户/信号/绩效的隔离（`backtest_*`、`accounts`、`positions`、`orders`、`trades`、`signals`、`strategy_runs`、`strategy_daily_performance` 保持 dev 独立）；不改 GRANT/search_path；不动 `strategy_versions`（当前全为 None，影响面为零，见假设）。
- **不包含**：不做跨环境数据同步/双向写。

## 验收标准

- AC-1：`curl "http://127.0.0.1:8080/quantTrade/strategy?page=1&page_size=100"` → `total` ≥ 51
- AC-2：`curl "http://127.0.0.1:8888/quantTrade/strategy?page=1&page_size=100"` → `total` = 51（生产行为不变）
- AC-3：dev 对 `07651265`（`running/live`）发 `PUT /quantTrade/strategy/07651265-…` → **409**，且 `public.strategies` 该行 md5 前后一致
- AC-4：dev 新建策略（请求体带 `status=running`、`run_mode=live`）→ 落库后 `status='draft'` 且 `run_mode='backtest'`
- AC-5：`cd quant_server && .venv/Scripts/python.exe scripts/_diag/_verify_dev_reads_prod_params.py`（新建）→ 输出 dev 连接下 `strategy_parameters` 读到 `07651265` 的 6 项参数，且与 `public` 逐项相同
- AC-6：`cd quant_server && .venv/Scripts/python.exe -m pytest tests/modules/test_strategy/test_shared_strategy_config.py -q`（新建）→ exit 0
- AC-7：`cd quant_server && .venv/Scripts/python.exe scripts/quality/check_all.py` → exit 0

## 约束与红线

- **只读迁移**：dev 的 3 张表只**改名备份**（`*_devbak_20261122`），不 DROP、不删数据。
- **生产零变化**：`ENVIRONMENT=production` 时代码路径与现状逐字一致。
- **写守卫必须服务端**：不能只靠前端禁用按钮。
- **回测数据仍隔离**：dev 回测产生的 `backtest_tasks/trades` 不得写 public。

## 假设与未知

- 假设：`strategy_versions` 全为空（报告：所有回测任务 `strategy_version_id` 为 None），共享与否无实际影响，本轮不动。
- 未知：`portfolio_strategies` 仍隔离 → dev 与生产的组合归属不同。当前生产组合已停、无在跑的 combo，暂不影响；若将来恢复组合需重新评估。
- 风险：共享后 dev 新建的 draft 会出现在**生产列表**里（按状态筛选可区分）；已与用户确认接受。
