## 未覆盖与风险

- **全历史回填未执行**：估算 457,278 次（含分页）、15–25 小时；需作为独立运营任务分批跑（`--resume` 可断点续传）。当前库内只有 2026-11-03~07 的样本数据。
- **分页修正了静默截断**：单次调用下 `fund_nav` 只有 10,500 行、`opt_basic` 只有 12,000 行；显式 limit/offset 后实测 `fund_nav` 25,717/日、`opt_basic` 225,535 行。估算已乘分页倍数，但各接口真实页数仍需在运营回填时按日志校准。
- **港美股不可行**：`hk_daily`/`us_daily` 限 1 次/小时、且不做分页（一次调用无法翻页），全历史各 5,304 次 ≈ 221 天，单日结果可能仍被截断。需更高 Tushare 权限或换源。
- **fut_holding/fut_wsr 真实冒烟未完成**：140 次调用 25 分钟未完成，已停止；全历史各约 150,150 次，按实测速度不可行。代码路径由假源测试覆盖，真实数据待按主力品种降级后再验；已从日终清单移除。
- **index_ths_member 无历史**：接口不返回 in/out_date 与 weight，只能从实施日 2026-11-08 起按日快照；区间运行会直接报错，避免伪造历史。
- **P2 事件表**：`fund_manager`/`fund_div` 已改为逐日 `ann_date`、`cb_share` 已改为逐季末、`cb_rating` 已改为逐转债代码（实测 5,235 行）；`stock_new_share` 在样本日无数据，属稀疏表正常空。
- **回滚未演练**：生产库 57 张表已建，`DROP TABLE` 回滚脚本未在沙箱演练；回滚动作见 `02-设计.md`。
- **残余低项**：`sync_daily_base` 在 `_upsert_ext` 内延迟导入 `sync_service._drop_unstorable_records`（base→derived 的局部耦合），功能无影响，记入后续清理。
