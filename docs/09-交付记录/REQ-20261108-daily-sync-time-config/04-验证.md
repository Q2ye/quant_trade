- **未覆盖**：未在真实交易日晚间等待 19:20 观察调度日志（避免长时挂机）；调度器时间解析由 `ScheduleManager` 既有逻辑 + 单测覆盖。

  - `SystemSettings` 新增字段属于配置契约扩展；其他读取 `SYSTEM` 的代码不受影响。
