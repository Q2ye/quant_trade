# REQ-20261108-script-dsn-unification 需求卡

> 阶段 S1 ｜ 档位 T1 ｜ 起草 2026-11-08 ｜ 确认人 用户 ｜ **写法见 `docs/06-标准规范/00-1_S1需求澄清.md`**

## 问题与证据

- 现象：18 个脚本硬编码 `postgres` / `123456` / `quant_signals_dev`；`quant_signals_dev` 即将退役，这些脚本轻则连错库，重则用超管写生产。
- 证据：
  - `grep -rnE "quant_signals_dev|['\\\"]123456['\\\"]|user.*postgres" quant_server/scripts quant_server/modules/data/services/research_service.py` 命中 22 个文件。
  - 典型：`scripts/data/backfill_top100_factors.py:21`、`scripts/data/backfill_valuation_factors.py:21`、`scripts/backtest/backtest_etf_bottom.py:22`、`scripts/ops/sweep_params.py:39`。
- 不做的后果：dev 库退役后脚本全部失败；继续保留超管明文口令违反安全红线。

## 目标

所有脚本统一从 `shared.config` 的环境配置解析数据库连接，不再出现硬编码 DSN；默认写入 prod（行情以 prod 为准），可通过环境变量切换。

## 范围

- 包含：新增 `quant_server/scripts/_db_env.py`；更新 18 个脚本；更新 `modules/data/services/research_service.py` 的命令字符串；更新 `backfill_coverage_gaps.py` 的历史注释。
- **不包含**：
  - 不改脚本的业务逻辑、回测口径、回填范围。
  - 不处理 `scripts/_diag/`、`scripts/_bak/`（已 gitignore）。
  - 不新增角色/权限（沿用 REQ-20261108-db-env-isolation 的 `quant_prod` / `quant_dev`）。

## 验收标准

- AC-1：`cd quant_server && grep -rnE "quant_signals_dev|['\\\"]123456['\\\"]|user.*postgres" --exclude-dir=__pycache__ scripts modules/data/services/research_service.py` → 0 行，exit 1
- AC-2：`cd quant_server && .venv/Scripts/python.exe scripts/data/backfill_breadth_ma250.py --help` → exit 0，不发起 DB 连接
- AC-3：`cd quant_server && PROD_DB_USER=quant_prod PROD_DB_PASSWORD=x PROD_DB_NAME=quant_signals .venv/Scripts/python.exe -c "import sys; sys.path.insert(0,'scripts'); from _db_env import db_kwargs; print(db_kwargs()['user'], db_kwargs()['database'])"` → 输出 `quant_prod quant_signals`
- AC-4：`cd quant_server && .venv/Scripts/python.exe -m pytest -q` → 0 failed

### 判据变更

暂无。

## 约束与红线

- 不向 `.env` / `.git/` 写入；脚本只读取环境变量。
- 脚本默认目标为 prod（`PROD_DB_*`）；不得再默认 `quant_signals_dev`。
- 连接用户不得是 `postgres`（`_db_env.py` 显式拒绝）。
- 业务逻辑不变，只替换 DSN 来源。

## 假设与未知

- 假设：`.env` 将配置 `PROD_DB_USER=quant_prod`、`DB_DEV_USER=quant_dev`、`DB_DEV_NAME=quant_signals`（由用户在部署时手工更新）。
- 未知：部分脚本有独立 `--database` 参数（`backfill_sw_member_history.py`），保留参数但默认值改为统一配置。

- 档位：T1
