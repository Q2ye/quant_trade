## 方案概述

只改**已持仓标的**的均线失效判定：未持仓仍按单日判定（入场口径不变），已持仓需连续 N 个交易日收盘低于 MA10 才判失效。全部由新参数 `hold_ma_confirm_days` 控制，默认 1 = 与现状逐位等价。改动集中在单文件六处，无 DDL、无事件、无跨模块依赖。

（原始问题定位、四趟账本与根因拆解见下文 §〇–§二；方案细节见 §三。）

## 契约

### 1. 参数

| 名称 | 类型 | 默认 | 取值 | 语义 |
|:--|:--|--:|:--|:--|
| `hold_ma_confirm_days` | int | `1` | ≥1 | 已持仓标的需连续 N 日收盘 < MA10 才判均线失效；1 = 现状 |

声明位置：`DEFAULT_PARAMS` 中 `ma_threshold` 行之后（`:169`）。DB `strategy_parameters` 无该键时取默认值。

### 2. 返回结构

`_score_candidate(code) -> Optional[Dict]` 新增键：

| 键 | 类型 | 语义 |
|:--|:--|:--|
| `ma_break_streak` | `Optional[int]` | 连续「收盘 < MA10×ma_threshold」的交易日数；`0`=未破位；`None`=数据不足 |

原有键一律不改名、不改类型（只增不改）。

### 3. 方法

```python
def _passed_ma_gate(self, m: Dict) -> bool:
    """均线门：未持仓 → 严格单日；持仓 → 连续 N 日破位才失效。"""
```

判定规则：

| 情形 | 返回 |
|:--|:--|
| `m["etf"]` 不在 `_holdings` | `m["passed_ma"]`（严格，与现状一致） |
| 已持仓且 `ma_break_streak is None` | `m["passed_ma"]`（fail-closed） |
| 已持仓且 `ma_break_streak is not None` | `streak < hold_ma_confirm_days` |

### 4. 兼容性

- `N=1`：`streak < 1` ⟺ `streak == 0` ⟺ `passed_ma`，与引入前完全一致（AC-3 逐笔验证）。
- 老数据：无影响（纯计算字段，不落库）。
- 老调用方：`_apply_filters` 的步骤元组由 lambda 改为 method reference，其余步骤顺序不变。

## 〇、一句话结论

策略在震荡市被"鞭打"的**主因不是手续费、也不是卖出判断错，而是两个门的时间尺度不匹配**：
入场端用 **25 日动量（月频）** 选标的，出场端却用 **单日收盘 vs MA10（日频）** 判失效。
一次 −2.9% 的普通回调就能把仍有 +3.84% 动量的持仓整仓换掉，于是形成"追高买入 → 单日破线卖出 → 切国债 → 再追高"的循环。

## 二、根因拆解（5 个环节，按贡献排序）

| 环节 | 位置 | 机制 | 后果 |
|:--|:--|:--|:--|
| ① 出场单日快照 | `:1593-1599`、`:1639`、`:910-971` | `passed_ma = current > MA10 × 1.0`；不通过 → 掉出目标池 → `轮动换仓: 不在目标池` 全额卖出 | 一次普通回调即清仓 90% |
| ② 入场右侧追动量 | `:1547`、`:1561` | 25 日动量 + R² 排序，买在动量已兑现的位置 | 买在阶段高位（512690 买入时 25 日 +10.12%） |
| ③ 只有两档仓位 | `:883-885`、`:1771`、`:230` | 有候选 → 单标的 90%；无候选 → 100% 防御标的（511010） | 没有中间态/现金档，防御期收益≈0（511010 25 日 +0.48%） |
| ④ 最小持有期太短 | `:828-830`、`:976-1000` | `_held_days` 在买入当日即 +1；`min_hold_days=3` → 第 3 个交易日即可卖 | 512690 恰好在解锁当日卖出 |
| ⑤ 止损太宽 | `stop_loss_pct=0.08` | 8% 硬止损在 ETF 上几乎不触发；实际出场全靠"掉出池" | 513100 一路 −5.75% 无人拦 |

**因果链**：①造成"卖出频繁且价位差"，②造成"买入价位差"，③使空窗期收益归零，④让①的冷却期只有 3 天，⑤放任单笔亏损扩大。

## 三、解决方案

> 原则：**默认值保持与现状逐位等价**，所有改动以"新增参数（默认关闭/默认 1 天）"的形式落地，便于 A/B 回测与随时回滚。本仓库该文件用 **Tab 缩进**，下列片段贴入时请转换为 Tab。

### 方案 A（P0，必做）：持仓均线去抖 `hold_ma_confirm_days`

**语义**：未持仓标的仍按单日判定（**入场口径完全不变**）；已持仓标的需**连续 N 个交易日收盘 < MA10** 才判均线失效。
`N=1`（默认）= 与现状逐位等价；建议测试值 `N=2`、`N=3`。

**改动 1** — 参数声明（`:169` 附近，紧跟 `ma_threshold` 行）：

```python
"enable_ma_filter": True, "ma_lookback": 10, "ma_threshold": 1.0,  # 站上 MA10
# 2026-11-12：持仓均线去抖。入场仍按单日判定（严格）；已持仓标的需连续
# hold_ma_confirm_days 个交易日收盘 < MA 才判均线失效 → 避免单日破线全仓换手。
# 默认 1 = 与引入前逐位等价。依据 REQ-20261112-whipsaw。
"hold_ma_confirm_days": 1,
```

**改动 2** — `__init__` 读取（`:455` 附近，`self.ma_threshold` 之后）：

```python
self.ma_threshold = float(merged["ma_threshold"])
self.hold_ma_confirm_days = max(1, int(merged.get("hold_ma_confirm_days", 1)))
```

**改动 3** — `_score_candidate` 计算破位天数（`:1593-1599` 段之后插入）：

```python
        # 连续「收盘 < MA(lookback)」的交易日数（0 = 未破位；None = 数据不足）
        ma_break_streak: Optional[int] = None
        if closes.size >= self.ma_lookback + 1:
            ma_break_streak = 0
            for k in range(0, self.ma_lookback):
                seg = closes[-(self.ma_lookback + k): len(closes) - k]
                if seg.size < self.ma_lookback:
                    break
                if float(seg[-1]) < float(np.mean(seg)) * self.ma_threshold:
                    ma_break_streak += 1
                else:
                    break
```

**改动 4** — 返回字典新增字段（`:1614` 的 `"passed_ma": passed_ma,` 之后）：

```python
            "passed_ma": passed_ma,
            "ma_break_streak": ma_break_streak,
```

**改动 5** — 新增判据方法（放在 `_apply_filters` 之前）：

```python
    def _passed_ma_gate(self, m: Dict) -> bool:
        """均线门：未持仓 → 严格单日；持仓 → 连续 N 日破位才失效（去抖）。"""
        if m["etf"] not in self._holdings:
            return m["passed_ma"]
        _streak = m.get("ma_break_streak")
        if _streak is None:          # 数据不足 → 沿用严格判定（fail-closed）
            return m["passed_ma"]
        return _streak < self.hold_ma_confirm_days
```

**改动 6** — `_apply_filters` 的均线步骤（`:1639`）：

```python
                ("均线", self._passed_ma_gate, self.enable_ma_filter),
```

**预期效果（用 1.3 的数据验证）**：`N=2` 时 512690 破位天数=1 → `1 < 2` → 保留在目标池 → **11-11 不产生任何信号**，仓位继续持有。
`N=3` 同理，再多给一天缓冲。

**兼容性**：`N=1` 时 `streak < 1` ⟺ `streak == 0` ⟺ `passed_ma`，与现状完全一致（可用同一份回测数据逐笔对比验证）。

### 方案 B（P1，可选，与 A 二选一或叠加）：持仓均线缓冲带 `hold_ma_buffer_pct`

**语义**：持仓标的的均线门放宽为 `收盘 > MA10 × (1 − buffer)`，例如 2% 缓冲。
与 A 的区别：A 是**时间维度**去抖，B 是**价格维度**缓冲。B 对"贴着均线横盘"的标的更宽容，但对"缓跌"不敏感。

**改动**：

1. 参数：`"hold_ma_buffer_pct": 0.0,`（默认 0 = 现状）
2. `_score_candidate` 返回 `"ma_gap": (current / ma_val - 1.0) if ma_val else None,`
3. `_passed_ma_gate` 增加分支：

```python
        if m["etf"] in self._holdings and self.hold_ma_buffer_pct > 0:
            _gap = m.get("ma_gap")
            if _gap is not None and _gap >= -self.hold_ma_buffer_pct:
                return True
```

> 建议先单独回测 A 与 B，不要一上来就叠加，否则归因不清。

---

### 方案 C（P1，零代码）：`min_hold_days` 3 → 5

纯参数改动（`DEFAULT_PARAMS:234`，或在 `strategy_parameters` 覆写）。
配合 A 使用：A 负责"别因一天破线就卖"，C 负责"买入后至少给 5 个交易日"。
单独用 C 效果有限（只是把换手从 T+3 推迟到 T+5），**必须与 A 同测**。

### 方案 D（P2，可选）：防御仓位上限 `defensive_max_position`

**动机**：无候选时 `:883-885` 直接把 100% 资金切到 511010（国债），而 511010 的 25 日动量只有 **+0.48%**——等于空仓还要付换手成本。
**改动**：`_compute_position_weights`（`:1771`）：

```python
        cap = self.single_etf_max_position if n == 1 else self.max_single_position
        if n == 1 and targets[0]["etf"] == self.defensive_etf:
            cap = min(cap, self.defensive_max_position)   # 新增参数，默认 1.0
        weights = self._apply_cap(weights, cap)
```

参数 `"defensive_max_position": 1.0`（默认不变），测试值 0.5。
**注意**：权重不足 1.0 时剩余资金为现金，需确认 `sizer` 对 `sum(weights) < 1` 的处理是否会产生"未使用现金"告警（回测里体现为低仓位，属预期）。

### 4.4 判定标准（先定，后看结果）

**硬性（不满足即否决）**

1. `max_drawdown` **不高于** BASE（允许持平，不允许恶化 > 1pp）；
2. `num_trades` **下降 ≥ 20%**（这是本次改动的直接目的）；
3. `avg_holding_days` **上升**；
4. `calmar_ratio` 不低于 BASE；
5. 观察段（2021-07~2023-12）与主区间**同向改善**，不允许"主区间变好、样本外变差"；
6. 邻域稳健：`N=2` 与 `N=3` 的结论一致（收益/回撤方向不变），不出现悬崖式翻转；
7. 不允许收益集中在单笔（`trades` 里最大单笔贡献 > 50% 总收益即视为偶然救场）。

**期望（不满足要解释）**

8. `total_return` 优于 BASE（减少 4 趟负期望往返应自然改善）；
9. `max_consecutive_losses` 下降。

**红线（违反即回退）**

10. 出现未来函数（`shift(-`、`.iloc[i+` 新增命中）；
11. 回测日志出现「股票池兜底」/宇宙不一致；
12. `N=1` 的结果与 BASE **不是逐笔一致**（说明改动污染了默认路径）。

## 六、风险与回滚

| 风险 | 表现 | 缓解 |

| 退出变慢，单次亏损扩大 | 破位后多持 1–2 天，若继续跌则多亏 1–2% | 用 A2/A3 对比 MDD；必要时叠加 `stop_loss_pct` 收紧（另议） |
