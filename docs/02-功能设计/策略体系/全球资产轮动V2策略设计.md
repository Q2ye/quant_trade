## 1. 策略定位

**核心定位**（模块 docstring 第 3-4 行）：全球资产轮动策略 V2 — 激进进攻版；**高弹性ETF短周期动量轮动，目标年化 40%-60%**。

**改造点**（docstring 第 5-11 行完整摘录，6 条）：

1. 资产池仅保留最高弹性赛道ETF，放弃大类分散
2. 短周期动量（20日）+ 高频调仓（3交易日），捕捉波段行情
3. 单标的满仓集中，最大化最强趋势的收益贡献
4. R²仅作过滤不乘积削弱，保留脉冲行情的高收益
5. 新增移动止盈，让利润奔跑；8%硬止损严格控亏
6. 修复原版入场价重置、skip_window失效、动量口径不一致三大bug

**决策频率**（类 docstring 第 33-34 行）：每 3 交易日调仓 + 日频止损/止盈。策略类型 `StrategyType.ROTATION`，默认名称"全球资产轮动V2-激进版"。

**与 V1 的关系**（代码注释实证）：本文件为 V2 激进版新类，修复"入场价重置"（`_entry_prices` 永不重置）、"skip_window 失效"（`_calc_log_regression_momentum` 正确截取区间）、"动量口径不一致"（统一对数回归口径）三大原版 bug。V1 退役依据见交叉引用调研文档。

## 3. 动量计算（`_calc_log_regression_momentum`，代码实证）

**口径**：对数价格对时间线性回归，斜率年化：

```
needed      = momentum_window + skip_window        # 21 根
start_idx   = -(momentum_window + skip_window)     # 正确跳过最近 skip_window 天（原版 bug 修复）
end_idx     = -skip_window
valid       = closes[start_idx:end_idx]            # 剔除 ≤0 / NaN
权重         = np.linspace(1, 2, n)                # 线性加权，近期权重更高
slope       = np.polyfit(x, log_prices, 1, w=weights)
annualized  = exp(slope × 250) - 1                 # 年化动量
```

**过滤与惩罚**（顺序实证）：

| 步骤 | 条件 | 阈值（来源） |
|:---|:---|:---|
| 数据有效性 | 有效数据 ≥ `momentum_window × 0.8`（至少 80%） | — |
| 异常值过滤 | `annualized > 5.0` 或 `< -0.8` → 剔除（返回 None） | — |
| **R² 过滤** | 加权 R²（`1 - ss_res/ss_tot`）< `r2_filter_threshold` → 剔除 | < **0.2** |
| 尾端跳水惩罚 | 近 3 日单日跌幅 < `crash_penalty_threshold` → 得分 × `crash_penalty_factor` | <-8% → ×**0.7** |

**关键改造**：R² 仅作过滤不乘积削弱（保留强趋势高弹性）；尾端跳水从"直接剔除"改为"扣分制"（docstring 修复说明）。

**排名与基准**（`_calc_momentum_rankings` / `_run_rebalance`）：

- 对 `effective_pool`（ASSET_POOL 内非 US_PAIR 成员 + 选中的美股，当前即全池 6 只）计算年化动量，降序排名。
- 绝对动量基准：`cash_score = 货基(511990) 同口径年化动量`；`use_absolute_momentum=False`（默认关闭，永远满仓进攻，参数注释"默认关闭绝对动量门"）；开启时 `score <= cash_score` 的标的退守防御。
- 防御资产选择（`_get_defense_asset`）：十年国债动量 > 货基动量 → 退守 511260；否则退守 511990。

## 4. 入场 / 出场（代码实证）

### 4.1 调仓流程（`_run_rebalance`，每 3 交易日一次）

1. **预热检查**：各标的缓存最大天数 < `min_history`(25) → 跳过调仓（`_warmup_warned` 只警告一次）。
2. **动量排名** → 取前 `max_holdings`(1) 名。
3. **槽位分配**（raw_slots）：当日已止损/止盈（`_stopped_today` 黑名单）→ 防御；开盘暴跌过滤（`use_open_crash_filter`，默认关闭，`_is_open_crash` 判今开 < 昨收 ×(1-3%)）→ 防御；数据不新鲜 → 防御；绝对动量门（默认关闭）→ 防御；其余入选。
4. **兜底**：全部被过滤（`sum(raw_slots)<=0`）→ 全仓防御资产。
5. **目标权重**（`_calc_target_weights`）：槽位等权 `w = slots/total_slots`，单标的上限 `max_single_weight=1.0`（当前 max_holdings=1，天然满仓），截断后的剩余权重平均再分配。
6. **新旧持仓对比生成信号**：退出的标的 → EXIT；新进 → ENTRY；**同仓权重调整**：新旧权重相对变化 `abs(new-old)/old > _WEIGHT_CHANGE_THRESHOLD`(模块级常量 **0.20**) → 先平后买。
7. **入场价维护（关键修复）**：仅新建仓标的写入 `_entry_prices`/`_peak_highs`，**已有持仓入场价永不重置**（修复原版"调仓重置入场价 → 止损失真"bug）；已有持仓仅更新当日高点。

### 4.2 日频风控（`_daily_risk_check`，每个交易日收盘执行）

| 规则 | 触发条件 | 阈值（来源） | 信号类型 |
|:---|:---|:---|:---|
| **硬止损**（最高优先级） | `pnl = 现价/入场价 - 1 ≤ stop_loss` | ≤ **-8%** | `STOP_LOSS` |
| **移动止盈** | 浮盈 `pnl ≥ trailing_stop_start` 且从阶段高点回撤 `(peak-现价)/peak ≥ trailing_stop_drawdown` | ≥ **+15%** 启动 / 回撤 ≥ **6%** | `EXIT` |

- 阶段高点：每日更新 `peak_high = max(旧峰值, 现价)`。
- 触发后 `_clear_holding`（清持仓/入场价/峰值）并加入 `_stopped_today` 黑名单 → 当日调仓时该标的退守防御（防"止损后立即重新买入"）。
- 信号字段实证：买入 `confidence=0.85`、卖出 `confidence=0.90`；买入 `amount=1.0`、`quantity=0`（数量由下游执行确定，代码未见具体下单股数模型，待确认）。

### 4.4 信号构造与执行字段（代码实证）

| 信号 | 构造方法 | 字段实证 |
|:---|:---|:---|
| 买入 | `_make_entry_signal` | `signal_type=ENTRY`、`direction=LONG`、`price=当日收盘`、`quantity=0`、`amount=1.0`（占位）、`confidence=0.85`、`reason="{ts_code}: {原因}"`、`weight` 挂载于 `sig.weight` |
| 卖出 | `_make_exit_signal` | `signal_type=EXIT / STOP_LOSS`、`direction=CLOSE_LONG`、`quantity=0`、`amount=0.0`、`confidence=0.90`、`reason` 含触发明细（如"硬止损: 浮亏-8.5%"、"移动止盈: 最高浮盈20.0% 回撤6.2%"） |

- 信号 id 用 `uuid.uuid4()`；`strategy_id = strategy_name = self.name`。
- 调仓退出/权重调整/风控退出的原因文案区分实证：`"调仓退出"`、`"权重调整: {old:.1%}→{new:.1%}"`、`"硬止损: 浮亏{pnl:.1%}"`、`"移动止盈: 最高浮盈… 回撤…"`。
- 下单股数/金额由下游执行确定（`quantity=0`、`amount=1.0` 为占位），代码未见具体数量模型，待确认。

### 4.5 生命周期与状态管理（代码实证）

- **on_init**：`_validate_params()` 校验失败抛 `ValueError`；构建 `_universe`。
- **on_start**：重置全部运行时状态（`_last_rebalance_days=0`、清空持仓/入场价/峰值/缓存/黑名单），随后 `_preload_history` 预热。
- **on_stop**：清空缓存、持仓、入场价、峰值、黑名单。
- **on_bar**：仅接受 `ts_code ∈ _universe` 的 bar，`_append_data` 后记录 `_last_trade_date`（不产生信号）。
- **on_bar_batch_end**：每交易日一次：清 `_stopped_today` → 日频风控 → 满足 `_should_rebalance()`（距上次调仓 ≥ 3 交易日）则调仓并 `_mark_rebalanced()`。
- **关键状态变量**（代码实证）：`_entry_prices`（首次建仓入场价，永不重置）、`_peak_highs`（阶段最高价，移动止盈基准）、`_current_holdings`（目标权重快照）、`_stopped_today`（当日止损/止盈黑名单）、`_reset_warned`（重置告警去重）。

## 6. 与调研方案文档的关系（交叉引用）

调研文档《全球资产轮动V2调研方案-2026-07.md》（归档 2026-07-18，状态"调研方案，待确认后执行"）提出：V1 三大死因（上车慢下车快 / 出场与调仓耦合 / 信号密度过高）、转向"月频整体再评估"经典全球资产配置范式、主候选双动量（Antonacci）骨架 + 防御切换增强、月内 -10% 级硬止损、预注册成功标准（10 年窗年化 ≥6% / MDD ≤20% / 夏普 ≥0.5；5 年窗 Calmar ≥0.29；与低吸轮动日收益相关性 ≤0.4）。

**激进版实现与调研草案的对应/偏离**（对照表，均为代码实证 vs 调研文档实证）：

| 维度 | 调研方案草案 | 激进版代码实现 | 关系 |
|:---|:---|:---|:---|
| 资产池 | 9 类大类资产（美/欧/日/港/A股/黄金/商品/债/现金） | 6 只高弹性赛道 ETF（半导/证券/中概/创业板/纳指/恒生科技）+ 债/现金防御 | 偏离：放弃大类分散（改造点 1） |
| 调仓频率 | 月末调仓 | 每 3 交易日（`rebalance_frequency=3`） | 偏离：短周期高频（改造点 2） |
| 动量 | 12-1 月收益率（标准双动量） | 20 日对数回归年化动量 + skip 1 天 | 偏离：短周期（改造点 2） |
| 持有数量 | top 2-3 | `max_holdings=1` 单标的满仓 | 偏离：极致集中（改造点 3） |
| 绝对动量 | 候选收益 < 货基 → 退守债/现金（核心机制） | `use_absolute_momentum=False` 默认关闭，货基仅作止损落脚与防御基准 | 偏离：进攻版默认放弃防御门 |
