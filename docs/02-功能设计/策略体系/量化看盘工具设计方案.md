## 一、背景与痛点

常规股票软件对一般人不友好：
- 只有日K线 + 经典指标看图，而经典指标很多已失效
- 对大盘和具体标的的**量化统计缺失**：不知道股价偏离均线多少 ATR、250 日滚动乖离率水位
- 大盘情况更难：宽度指标、深度指标、恐慌/贪婪水平都没有现成可视化

已有的策略只能处理一部分行情，缺少**策略 × 行情诊断**：
- 行情匹配但策略仍出错？需要量化指标识别
- 策略空仓时，市场是否到底、能否主观操作？
- 市场当前进攻还是防守、偏爱大市值还是小市值？

因此需要一套**量化看盘工具**，将策略开发中常用的指标可视化，特别是预警指标、风格指标、标的各维度打分。

> **定位**：决策支持工具，不是数据可视化玩具。每个指标必须能回答一个具体的交易/策略决策问题。

## 二、数据资产清单（盘点结果）

### ✅ 已有、可直接用

| 数据 | 表 | 覆盖 | 用途 |
|:---|:---|:---|:---|
| 市场状态 | `market_state_daily` | regime(BULL/BEAR/NEUTRAL) + 宽度(breadth_ratio) + 波动率(volatility_pct) + 动量(momentum_score) + 趋势(trend_strength)，2005 至今 | **大盘状态雷达** |
| 指数日线 | `index_daily` | 沪深300(000300)/中证500(000905)/中证1000(000852) + 数百行业主题指数 | **风格轮动**、regime |
| 指数技术因子 | `index_factor_pro_daily` | BIAS乖离 / ATR / MACD / RSI / MA(5-250) / BOLL / KDJ 等全套指标 | **乖离水位、标的打分** |
| 个股因子 | `factor_data` | 83 因子定义、102 因子 code、2001 标的、2005-2026-08-05（ATR、ma_disparity 均线偏离、price_position_250d、PE/PB 分位、ERP、momentum、volatility_pct…） | **标的打分** |
| 涨跌停 | `stock_daily_limit` | up_limit / down_limit / up_percent / down_percent 每日 | **深度指标** |
| 资金流 | `stock_moneyflow` | 大/中/小单买卖金额、净流入 | 资金流向 |
| 北向资金 | `stock_hsgt` | 北向资金 | 情绪指标 |
| 行业指数 | `index_sw_daily` / `index_sw_classify` / `index_sw_member` | 30 个 SW L1 行业日线 | 行业相对强度 |

### 🟡 需要补算（原始数据在，做聚合）

| 指标 | 做法 |
|:---|:---|
| 涨跌停家数日统计 | 聚合 `stock_daily_limit` 按 trade_date 统计 up/down 家数 |
| 乖离率/ATR 滚动分位水位 | `factor_data` 的 ma_disparity/atr_ratio_20 算 250 日滚动分位 |
| 风格强度 | 000300 vs 000905 vs 000852 相对强弱序列（`index_daily` 价差） |
| 策略×行情诊断 | `signals` 历史后验收益（当前仅 1 条，需积累）+ 回测结果 × `market_state_daily` regime 对照 |

### 关键结论

- **大盘状态雷达的数据基本现成**：`market_state_daily`（regime/宽度/波动率）+ `index_daily`（风格价差）+ `stock_daily_limit`（涨跌停家数）
- **乖离水位**：`factor_data`（ma_disparity/atr_ratio_20/price_position_250d）与 `index_factor_pro_daily`（BIAS/ATR）都可算滚动分位
- **风格轮动**：`index_daily` 三大指数价差即可
- **策略×行情诊断**：依赖信号历史积累，可先用回测结果对照

### 模块详情

#### ① 大盘状态雷达

**回答的问题**：市场在进攻还是防守？策略空仓时市场到底了吗？

| 卡片 | 数据来源 | 指标 |
|:---|:---|:---|
| 牛熊仪表 | `market_state_daily.regime` + CSI500 年线门 | regime + 年线门位置（close vs MA250） |
| 宽度 | `breadth_ratio` + 低吸 `_calc_bullish_pct`（MA5>MA20 占比） | 历史曲线 |
| 深度 | 聚合 `stock_daily_limit` | 涨停/跌停家数曲线 |
| 恐慌贪婪 | `volatility_pct` 分位 + `index_daily` 波动率 | 水位仪表 |

#### ② 风格轮动

**回答的问题**：市场偏爱大市值还是小市值？

- `index_daily` 沪深300(000300) / 中证500(000905) / 中证1000(000852) 相对强弱对比线
- `index_sw_daily` 30 行业相对强度热力图

#### ③ 策略×行情诊断

**回答的问题**：行情匹配但策略出错？

- 每策略卡片：当前 regime、信号数、信号后 N 日收益分布、胜率
- 用 `market_state_daily` regime 历史 × 策略信号时点对照
- 先可用回测结果（如低吸 +32.5%、防守 +14.5%）做基准对照

#### ④ 标的打分

**回答的问题**：标的各维度水位？

- 列表 + 每标的维度分位：乖离水位（ma_disparity）、ATR 偏离、估值分位（PE/PB/ERP）、动量、资金流
- 数据：`factor_data` 因子滚动分位 + `stock_moneyflow`

### 状态覆盖

每模块四状态：Loading(`n-skeleton`) / Empty(`n-empty`) / Error(`n-result` + 重试) / Data

### 后端接口（模块①）

`GET /quantTrade/market/dashboard/state`，一次返回 60 日序列：

```json
{
  "dates": ["2026-06-01", "..."],
  "regime_series": ["NEUTRAL", "..."],
  "breadth": [0.20, "..."],
  "limit_up": [60, "..."],
  "limit_down": [30, "..."],
  "volatility": [0.24, "..."],
  "latest": {
    "regime": "NEUTRAL",
    "year_line_pct": -2.3,
    "volatility_pctl": 0.62
  }
}
```

- `regime_series`/`breadth`/`volatility` ← `market_state_daily`
- `limit_up/down` ← `stock_daily_limit` 按 trade_date 聚合
- `year_line_pct` ← `index_daily` 000905 close 相对 MA250

### 风险与约束

- **范围控制**：只做 4 个模块，每个指标必须回答一个具体决策问题，不做花哨图表
- **信号历史少**：策略×行情诊断模块初期用回测结果，随实盘信号积累逐步精确
- **数据刷新**：大盘状态/风格随每日同步自动更新；因子分位需日终计算后刷新
