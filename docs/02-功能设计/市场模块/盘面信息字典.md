# 盘面信息字典 v0

> **定位**：把「看盘看到的东西」翻译成**可计算、带分位、可回测**的状态量。这是**信息层**，不是页面方案，也不是策略清单。
> **上游**：Tushare 盘后数据（`limit_list_d` / `moneyflow` / `index_sw_daily` / 日线）。
> **下游**：日报（描述现状）→ 研究（条件分布检验）→ 策略（六道门）。
> **前置纪律**（继承 `看盘方向收敛.md`）：
> 1. **分位优先**：任何绝对值必须带 250 日分位才有决策意义；
> 2. **N 消耗器边界**：本字典只描述「此刻是什么」，不含「历史上…后 N 日…」；后者进研究台账；
> 3. **单源**：一个指标只从一张表算，不跨源拼接同一含义。
> **日期**：2026-11-07 ｜ **状态**：v0（口径待核项见 §11）

---

## §0 使用说明

1. **本文只定义口径，不定义阈值**。阈值一律用分位（p05/p20/p80/p95），不用绝对值。
2. **状态列**：✅ 现在可算 ｜ ⚠️ 可算但口径待核 ｜ ❌ 缺数据。
3. **类型列**：`R` = regime（全市场状态，只能做 gate/仓位）｜ `B` = 板块状态 ｜ `S` = 个股截面（可做选股）。
4. **方向列**：`+1` 越大越热/越强 ｜ `-1` 越大越弱/风险越高。仅用于展示归一化，不参与计算。

## §2 A 族口径与边界

- **A1–A4** 直接用 `limit_list_d` 当日行，不做跨日 join。
- **A5**：T-1 的 `U` 集合，取 T 日 `stock_daily.pct_chg`；T 日停牌（无行）不参与均值，但要在 `extra` 里记 `n_missing`。
- **A6**：分母只取 T-1 `limit_times=1` 的首板；分子要求 T 日 `limit_times=2` 且出现在 T-1 首板集合。**不要用 `up_stat` 反推**，口径会飘。
- **A7**：分母为 0 时返回 NULL，不返回 0（0 会被误读为「极弱」）。
- **A8/A9**：阈值 ±7% 是描述性口径，固定即可；不要为了好看改成 ±5% 或 ±9%。
- **A10**：`fd_amount` 与 `float_mv` 的单位必须先核对（见 §11-1），**未核对前不启用**。

## §3 B 族口径与边界

- **B1**：`stock_moneyflow` 的 `buy_elg_amount` 等字段单位为万元时需统一到元；若为元则直接算。**先核对单位再入库**。
- **B3**：连续天数用「自今日往前数，连续 B1>0 的天数」，断一天归零。
- **B6**：2024-08-19 起北向披露口径变化（不再披露实时净买），**2024-08 之后的数据不可与之前拼成一条序列**；回测 2025+ 禁用。
- **B7**：`margin` 表为日频，T 日数据 T 日晚才可得，不用于当日盘中决策。

## §4 C 族口径与边界

- **行业口径**：v0 统一用 `stock_limit_list.industry`（Tushare 行业）；v1 换 `index_sw_member` 申万 PIT。**两套不能混用**，切换时整族重算。
- **C1**：分母为全市场 `U` 总数；板块内 `U` 按 `industry` 分组。
- **C2/C3**：用 `index_sw_daily.amount`，分母为当日全部申万一级行业 `amount` 之和。
- **C5**：「龙头」定义为板块内当日 `pct_chg` 第一（**规则固定，不靠感觉**）；跟风取板块内 `pct_chg` 中位数。
- **C6**：Top5 按 `pct_chg` 排序；重叠个数 0–5。
- **C8**：拥挤度是「高位 + 高成交」的双高，值越高越危险，方向 -1。

## §5 D 族口径与边界

- **D1**：开盘价就是集合竞价的成交价，所以 `open/pre_close − 1` **就是**竞价高开幅度，不需要竞价接口。缺的只是竞价量/撤单，用 **D9** 替代。
- **D2**：`open/pre_close − 1 > 0.03`；剔除当日停牌（无行）。
- **D5**：反包定义为「T-1 跌幅 ≤ -5% 且 T 日涨停」，不含 T-1 跌停但 T 日仅大涨未涨停的情况。
- **D6**：窗口 250 日，`close = max(close, 250)`；新股不足 250 日不参与。
- **D8/D9**：依赖 `stock_minutes`，计算量大，**放到日报之后的第二批**；分钟数据缺失的票记为 NULL。

## §6 E / F 族口径与边界

- **E3**：股东户数为季度披露，`end_date` 对齐后使用，**必须按公告日 PIT**，不能按 `end_date` 直接用。
- **E4**：`float_share × close` 用公告日可见的 `close`；解禁日在未来 30 日内才计入。
- **F1**：`index_dailybasic.pe` 为整体法 PE，分位窗口 250 日。

## §7 数据缺口与替代方案

| 缺口 | 影响 | 替代方案 | 优先级 |
|:---|:---|:---|:---|
| 集合竞价明细 | 竞价量、9:20–9:25 撤单 | **D1 用开盘价算高开幅度**；D9 用开盘 30 分钟量占比 | 低（影响小） |
| 龙虎榜（`top_list`/`top_inst`） | 看不到「谁在买」 | 暂用 B1/B2 净额替代，无法区分机构/游资 | **高** |
| 概念板块（THS/DC） | 看不到题材结构，只有申万行业 | 暂用申万一级行业 | 中 |
| 筹码（`cyq_perf`） | 看不到获利盘/套牢盘 | 暂用 E4 解禁压力替代 | 中 |
| 实时行情 | 盘中无法自动 | 保持人工看同花顺 | — |

## §8 计算依赖顺序

```
stock_daily / stock_limit_list / index_sw_daily
        ↓（T 日截面）
A1–A9, B1–B3, B7, C1–C7, D1–D7, E3–E4, F1
        ↓（T-1 join T）
A5, A6, D5
        ↓（250 日滚动）
全部 pct_250 / z_250
        ↓（分钟线，第二批）
D8, D9
```

**每日调度**：T 日 15:40 拉数据 → 16:00 算 A/B/C/D/E/F → 16:10 写 `market_metric_daily` → 16:15 出日报。

## §9 与策略的接口

- **regime 变量**（A/B/C/D/E/F 中类型 R）：只允许做 gate / 仓位 / 避险，**不得直接选股**。
- **截面变量**（类型 S）：进因子研究流程（`03_因子研究标准流程`），需 IC/ICIR/分层检验。
- **板块变量**（类型 B）：只服务轮动类策略，需先映射到可交易标的（ETF 或板块内龙头）。

## §10 存储

```sql
CREATE TABLE market_metric_registry (
  metric_id         TEXT PRIMARY KEY,
  family            TEXT NOT NULL,        -- A/B/C/D/E/F
  name              TEXT NOT NULL,
  formula           TEXT NOT NULL,
  source_table      TEXT NOT NULL,
  metric_type       TEXT NOT NULL,        -- R/B/S
  direction         SMALLINT NOT NULL,
  window            INT DEFAULT 250,
  decision_question TEXT NOT NULL,
  status            TEXT NOT NULL DEFAULT 'active',  -- active/pending
  downstream        TEXT[]
);

CREATE TABLE market_metric_daily (
  trade_date  DATE NOT NULL,
  metric_id   TEXT NOT NULL,
  value       NUMERIC,
  pct_250     NUMERIC,   -- 0–100
  z_250       NUMERIC,
  flag        SMALLINT,  -- 0 正常 / 1 高分位 / -1 低分位 / 2 缺失
  extra       JSONB,
  PRIMARY KEY (trade_date, metric_id)
);
```

## §11 待定项（必须先定，否则整族不可用）

1. **`fd_amount` / `limit_amount` 单位**：用一只已知涨停股核对「封单金额 ≈ 收盘价 × 封单量」，确认是元还是万元。未定前 A10 停用。
2. **行业口径**：Tushare 行业 vs 申万 PIT，二选一；v0 用 Tushare，但 C 族所有历史值在切换时需整体重算。
3. **北向断点**：2024-08-19 后序列不可拼接，B6 只保留历史描述，不回测。
4. **ST / 新股 / 停牌过滤**：统一规则写进计算层，不在每个指标里各写一遍。
5. **竞价缺失**：已确认无竞价数据，D1 用开盘价替代，不再等待接口。
