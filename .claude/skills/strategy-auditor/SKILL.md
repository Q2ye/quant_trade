# 策略质量门

> 落实 `audit.md`、`audit-backend.md`、**`audit-strategy.md`** 规则到策略领域的自动化检查。
> `audit-strategy.md` 定义了六大审计维度（未来函数/交易逻辑/计算错误/状态机/边界/语法），本 skill 将其转化为可机检的清单。

## 检查清单（按阻断级别）

### 🔴 阻断级（必须修复才能回测）

1. **Look-ahead bias**
   - 扫描策略代码中是否使用 `shift(-1)`、`shift(-2)` 等未来数据
   - 扫描是否用 `.iloc[i+1]` 访问未来行
   - 扫描 `df[col].shift(-N)` 任何形式
   - → 发现即阻断

2. **硬编码凭证**
   - 扫描 `token`、`password`、`api_key`、`secret` 等关键词后跟字符串字面量
   - → 发现即阻断（实际代码 `bottom_strategy.py:76-81` 已有一例）

3. **除零无保护**
   - 扫描 `x / y` 或 `x / (a - b)` 且无 `if y == 0` / `np.where` / `max(eps)` 包围
   - → 阻断

4. **参数越界**
   - 止损比例不在 [-1, 0) 区间
   - 止损比例 > 止盈比例
   - 最大持仓数 ≤ 0 或 > 100
   - 仓位比例 ∈ [0, 1]
   - → 阻断

### 🟡 警告级（建议修复，可选继续）

5. **Survivorship bias 风险**
   - 检查是否只用了当前存活的股票（`ts_code` 列表无 `delist_date` 过滤）
   - → 警告

6. **T+1 合规**
   - 检查买入日和卖出日是否至少间隔 1 个交易日
   - 涨跌停板处理：`pct_change` ≥ 9.5% 的买入、≤ -9.5% 的卖出是否跳过
   - → 警告

7. **数据依赖完整性**
   - 回测期间的 symbol 在 `daily_quotes` 中覆盖率是否 > 90%
   - 所需因子在 `factor_data` 中是否全部存在
   - → 警告

8. **NaN/Inf 传播链**
   - 追踪 `**` 运算前底数 > 0 的守卫
   - `log()` / `sqrt()` 参数 ≥ 0 的守卫
   - → 警告

### 🟢 信息级

9. **策略代码长度**
   - > 500 行 → 建议拆分为多个方法
   - > 1000 行 → 强烈建议重构

10. **硬编码数字**
    - 标记策略代码中非 DEFAULT_PARAMS 范围内的魔术数字
