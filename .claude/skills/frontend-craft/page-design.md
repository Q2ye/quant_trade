# 页面设计方案生成技能

> **与现有规范的关系**：
> - 本技能细化 `.claude/rules/frontend.md` 的阶段0（页面设计方案），提供完整的自动推断与输出流程。
> - 页面视觉质感实现见 `.claude/skills/frontend-craft/SKILL.md`（四层分层规范）。
> - 组件开发标准见同目录 `component-dev.md`（Props/Emits 接口契约）。
> - 本技能输出的方案确认后，进入 `.claude/rules/frontend.md` 的阶段1（开发路径说明）。

## 核心原则
- 每次生成新页面时，必须先输出完整的《页面设计方案》，作为后续代码生成的唯一依据。
- 方案严格遵循 `quant-web/` 前端开发规范中定义的布局、质感、状态覆盖铁律。
- 数据源必须与实际后端 API 或规划中的 API 路径对应，无法确认的标记为「待确认」。
- 禁止跳过此步骤直接编写代码。

## 执行流程

当用户提出“生成XX页面”或“设计XX页面”时，你必须**自动推断并输出**以下完整设计方案，无需用户提供额外细节。推断依据：页面名称关键字、所属模块、前端菜单结构、后端 API 路由、数据库表结构（从项目文档中检索）。

### 1. 页面类型自动推断
根据用户描述中的关键词匹配类型和默认布局：

| 类型 | 关键词 | 默认布局 |
| :--- | :--- | :--- |
| 仪表盘 | 驾驶舱、面板、仪表盘、监控、Dashboard、总览、概览、市场数据、大盘 | Bento Grid 4列 |
| 列表页 | 列表、查询、搜索、管理、历史、日志、记录 | 左侧筛选区(280px) + 右侧表格(flex-1) |
| 表单页 | 新建、编辑、配置、设置、参数、创建 | 单列居中(max-w-640px) |
| 详情页 | 详情、查看、报告、分析、结果 | 顶部摘要卡片 + 下部分栏(Tab/Grid) |

若用户描述中未包含明确关键词，则根据页面在菜单中的位置推断。例如“回测报告”属于详情页。

### 2. 自动检索数据源
- 从项目文档 `量化交易系统-混合架构设计.md` 中查找 `api/routers/` 下的对应路由文件（如 `data_router.py`、`backtest_router.py`），列出可能用到的 API 路径和方法。
- 若找不到对应 API，则在数据来源表中标注「待确认」，并在输出后提示用户补充。
- WebSocket 事件从业务模块内的 `events/` 目录（如 `modules/trade/events/`）查找，前端 WebSocket 封装见 `src/api/websocket.ts`，若需实时推送则注明事件类型。

### 3. 布局与质感强制分配
- **仪表盘**：4 列 Bento Grid（可合并 2/4 列）。核心指标占 2 列，次要占 1 列。可选粒子场背景。卡片 stagger 出现。
- **列表页**：顶部搜索 + 左侧筛选 + 右侧表格 + 底部分页。不使用 3D 背景。用 scroll reveal。
- **表单页**：分组，每组标题分隔。不使用 3D。焦点字段用 hover feedback。
- **详情页**：顶部 Key-Value 摘要卡片，下部分 Tab 或 Grid。可选粒子场。
- **全局**：所有页面 `bg-gradient-mesh` + `bg-noise`，玻璃导航栏，Naive UI 组件（全局注册），所有样式引用 design-tokens。

### 4. 必须覆盖四种状态
- Loading：骨架屏（Skeleton）占位形状描述。
- Empty：无数据时的文案与占位图描述。
- Error：错误提示 + 重试按钮。
- Edge Cases：如非交易时段、阈值告警、权限不足等特殊状态。

## 输出模板（必须严格遵循，不可省略任何章节）

```markdown
## 页面设计方案：[页面名称]

### 页面类型
[仪表盘 / 列表 / 表单 / 详情]

### 所属模块与路由
- 模块：[模块名]
- 路由：/[module]/[page]

### 数据来源
| 数据项 | 来源 | 方式 |
| :--- | :--- | :--- |
| [数据描述] | /api/xxx | GET / POST / WebSocket |

### 区域布局（ASCII 图）
使用简洁的 ASCII 框图展示页面栅格划分，标注区域编号（A、B、C…）和宽度比例。

### 各区域详细说明
- **A. [区域名称]**：内容描述，包含哪些数据字段，数据来源（对应上表），交互行为（点击、筛选、排序、悬停）等。
- **B. [区域名称]**：...
- ...

### 质感与氛围
- 背景：[`bg-gradient-mesh` + `bg-noise` / 粒子场 / 3D]
- 卡片：`card-surface` (玻璃质感) / 纯色卡片
- 动效：[stagger / scroll-reveal / hover-feedback / none]
- 特殊说明：如有图表库选型、配色倾向等在此注明。

### 状态覆盖
- **Loading**：描述各个区域或整体的骨架屏形态。
- **Empty**：描述无数据时的界面表现（文案、图标、引导操作）。
- **Error**：描述网络或服务器错误时的表现（提示文案、重试按钮位置）。
- **特殊状态**：列出业务特有的边缘状态（如非交易时段提示、数据不完整警告、权限拦截等）。
